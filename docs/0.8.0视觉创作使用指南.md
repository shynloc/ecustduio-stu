# EcuStudio 教创工作台 0.8.0：统一视觉创作指南

本版将已有的网页、PPT、动图和配音视频制作升级为可逐页编辑的工作流。所有成果使用同一个视觉项目；页面顺序、正文、配图、步骤、表格和来源随修订保存。

## 一、从哪里开始

1. 在「创作项目」打开已生成的母稿或内容版本，进入「视觉制作」。已有项目可直接点「本项目的视觉制作」中的版本。
2. 也可以在项目页面展开「从网页直接开始视觉制作」，输入公开网页 URL。工作台保存网页正文与来源，并建立一个新的项目。
3. 任务完成后点「打开视觉制作与成果」。无需复制提示词到其他应用。
4. 原始网页的正文进入编辑器；外站脚本、广告、账号状态和原网页样式不会被复制运行。网页过长时先在任务管家中整理摘要，再制作演示。

## 二、逐页修改

左侧选择页面，可以新增、复制、删除、上移、下移，并撤销或重做最近的操作。至少保留一页，最多80页。

每页可编辑：

- 标题、正文和讲者备注。
- 版式：沿用整体、标题封面、正文阅读、左图右文、左文右图、步骤流程、对比卡片、引文重点、数据表格。
- 页面配图、序列播放顺序、独立配音稿、展示时长、配音后停留、GIF 时长和透明画布。
- 已关联的事实引用。修改文案后会标为待复核，不会把新内容自动认定为已核实事实。

步骤与对比版式每行一项，最多8项。表格第一行是表头，使用 `|` 分列，最多6列8行。切换版式保留输入内容，但只呈现当前版式需要的步骤或表格。

编辑后约半秒自动刷新预览，不会自动覆盖已保存版本。点「保存新修订」建立新版本；原始母稿、旧视觉版本及旧成果保留。页面跳转与关闭浏览器会提示未保存编辑。

## 三、让 AI 直接修改

在「让 AI 修改」选择「仅当前页」或「整套页面」，直接输入要求，例如：

> 把当前页改为三个步骤，保留日期、适用条件和原文引用；采用逐项展示动效，配音用适合家长阅读的短句。

> 把整套内容整理为六页讲座：封面、关键变化、适用对象、报名步骤、注意事项、来源。不要补造政策事实。

任务会读取实际安装的 HTML Creator Studio 与 GIF Factory 技能，使用当前未保存编辑及关联内容生成修订。单页修改会强制保留其他页面和整体设计；整套修改可改变整体设计。结果另存，需继续核对文案、引文与画面。

工作台只开放受控内容和素材操作。模型不能执行任意脚本、修改账户权限或自动发布到外部平台。

## 四、共用图片与 GIF

在「共享素材」上传 PNG、JPEG、WebP 或 GIF，或将已生成的 GIF/静态替代图加入素材。再到每页勾选要使用的图片。最多8张，每张3MB、合计12MB。GIF 最多60帧，解码后的全部素材帧合计不超过24MB。

选择「图片序列播放」可按勾选顺序播放已有分镜、角色姿态或插画，通过「前移」调整顺序。生成的 GIF 能重新进入网页、PPT 和视频。网页/PPT 保留媒体对象；视频用确定的帧时间采样。

本版提供已有素材的动效制作；角色新姿态、复杂三维场景和书法笔顺仍需要相应素材或专门生成能力，不会用简单移动冒充这些结果。

## 五、GIF 制作

支持静止、进度线展开、轻微呼吸、轻微摆动、标题与正文揭示、图片缓慢移动、逐项展示、图片序列播放，以及 AI 选择。手动选定动效无需再调用模型规划；AI 选择会读取 GIF Factory。

选择最多6个场景，各自输出 GIF 与静态 PNG，循环时长1–6秒，512×512，10帧/秒。透明选项控制卡片外的画布；取消后采用整体底色。静止 GIF 为用户主动选择，不伪称动画。

GIF 使用固定版本的 GIF Factory 编码器与检查脚本。其原始贴纸检查要求透明且有运动；工作台对明确选择的静止或不透明输出进行对应校验，并在制作记录中保留差异。自动技术检查不等同于人工审美审核。

缺少 Python/Pillow 时，管理员可点「安装动图依赖」。网页、PPT、PDF 和视频不依赖 Pillow；在网页或视频中载入 GIF 帧时也需要此环境。

## 六、可编辑 PPT 和 PDF

在「制作交付物」选择可编辑 PPTX。文字、步骤卡片、基础图形和表格为原生对象，可以在 PowerPoint、Keynote 或其他兼容软件中继续修改；图片和 GIF 仍是媒体对象。讲者备注包含正文、步骤、表格、配音稿与来源。

「外观快照」模式用于保留网页视觉外观，主体是图片，不能逐字编辑。两种模式在界面中明确区分。

演示 PDF 与视觉项目保持同一分页。内容无法完整放入页面时停止并提示拆分，而不是默默裁掉长段落。不同办公软件的中文字体与 GIF 播放能力可能不同。

## 七、配音视频与字幕

每页有独立配音稿，可从当前正文、步骤或表格更新。修改正文不会悄悄覆盖手动写过的配音稿。

1. 选择横屏16:9、竖屏9:16或方形1:1。
2. 选择 DeepSeek 声音与语速，或选择不生成配音。
3. 选择句群字幕、整页字幕或关闭字幕。
4. 选择直接切换、淡入或平移进入。
5. 可上传 WAV/MP3/OGG/FLAC 背景音乐，最多30MB、10分钟，并调整背景音量。
6. 每页先满足设置的展示时长，再加停留时间；真实配音较长时延长页面，保留完整台词。
7. 核对当前文案和画面后生成。成果区域可以直接试听 WAV、播放 MP4，并下载字幕和内容包。

句群字幕按实际分段音频的起止时间生成，并非逐字强制对齐。相同账号的相同文案和声音会复用配音缓存；改变语速通过音频处理生效。配音最多40页、100个句群、10000计费字符，实际视频上限10分钟。

视频预览支持播放、定位和场景跳转。尚未生成时使用估计时间；已有成果且文案未改时使用真实配音时间轴。完整混音效果请播放生成的 MP4。

## 八、导出与追溯

先保存新修订，再选择格式并确认生成。任务完成后下载单文件或 ZIP 内容包。制作记录保存版本、来源、技能版本、动图检查、配音和字幕时间轴；重试复用已经完成的步骤。

网页 HTML 可独立打开，包含必要的图片与页面控制，不依赖登录工作台。分享前检查是否包含不宜外发的内容。来源有新版或母稿已失效时，旧成果保留，但需要从核对后的新版本重新创建视觉项目。

## 九、账号、手机与升级

管理员和创作者可使用视觉编辑；业务员继续保留政策、日报与允许查看的成果能力。私有视觉项目、预览、音频和编辑任务按账号校验权限。

书院为默认主题，曜石主题继续可选。桌面使用多栏布局，手机使用纵向布局和横向页面导航；大预览可单独打开。局域网其他设备使用服务器的局域网地址登录。

0.5.0及以上版本管理员可在「设置 → 检查更新」升级。程序更新保留原有账号、资料、项目、成果和 DeepSeek 配置。跨电脑迁移凭证是另一件事：Windows DPAPI 与 Mac 钥匙串均绑定原本机用户环境。
