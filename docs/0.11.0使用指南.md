# EcuStudio 0.11.0 使用指南

## 第一次打开

登录后进入工作台。在「今天，我们一起完成什么」中写目标，例如“把这份教学材料做成 8 页 PPT，再做一份学生讲义”。添加文件，或点「选择资料」从原始资料和知识库中多选。点击开始，会进入可继续追问的 AI 创作对话。

首页的原始资料、知识库、成果库三张立体卡可以点击。动效旁可暂停。设置里可切换书院和曜石主题。手机布局自动适配；系统开启减少动态效果时，使用静态卡片，不影响操作。

第一次由管理员在设置中连接 DeepSeek 并允许任务所选资料参与 AI 调用。API Key 仅填写在设置页，不需要发到聊天里。未连接 AI 时，仍能导入可本地解析的文件、写笔记、浏览已有内容。

## 1. 输入资料

打开「资料库 → 导入资料」：
- 文字：直接粘贴或编写，使用图标加粗、插表格、插图片；保存到自己的知识库。
- 网址：粘贴公开文章网址。点击开始读取后会显示当前步骤；完成后点击「打开原始资料」，或「整理到知识库」「用这份资料创作」。
- 文件：拖入文档、PDF、图片或录音，或选择文件上传。上传时显示真实上传进度；随后进入识别任务。

原始资料保存团队引用的原件与出处，知识库保存个人整理后的笔记。文字输入和未保存的新笔记有草稿恢复，不必为了看排版反复切换模式。

受限公众号、需登录或验证码的网页可能无法自动读取。页面保留原网址；可以打开原网页，将正文粘贴进来，或上传 PDF/截图。不要在验证码页面反复点击读取。

## 2. 识别、核对和保存

「识别与转写」支持文档提取、图片理解、录音转写和配音。长 PDF 按页分组处理，已完成部分保留，失败部分可重试。界面标出覆盖情况与待核对内容。

识别后先对照原页核对数字、单位、表格和含糊处。模型识别不是原件；不能仅根据文件名判断内容。校正后保存到知识库，或继续事实整理与创作。任务正在运行时可离开页面，回来仍能查看同一个任务。

资料更新页面说明哪些旧内容可能受影响。更新原资料不会偷偷覆盖已经修改过的笔记或成品。

「订阅与日报」显示是否开启、下一次运行和所选来源。电脑和服务必须运行才能执行计划；页面分别提示没有新内容、部分来源失败和全部失败。管理员可调整来源与时间。

## 3. 管理知识库

用右上图标切换卡片或列表，选择会自动记住。左侧分类栏可以收起：
- 文件夹可新建、重命名、嵌套；显示包含的内容数。电脑可拖放移动。
- 标签显示可见内容数量，点标签筛选；可以批量添加、移除或重命名。
- 搜索覆盖标题和正文，支持日期及排序。归档、收藏、回收站都有入口。
- 勾选笔记后，可移动、整理、撤销，或直接带入 AI 对话、开始创作。选择全部筛选结果时，所选集合固定，不会把后来新增的内容误算进去。

编辑笔记直接看到最终排版，修改后自动保存。版本历史可恢复旧正文为新版本。删除进入回收站，恢复后原内容仍在。多个页面同时修改时会提示版本冲突，保留当前文字，不会静默覆盖。

一个对话最多选择 200 份知识；一次整套作品制作最多 20 份。大批资料会按问题挑选相关片段，原始笔记不会被截断。系统给出实际采用情况，不把保存了完整历史等同于模型无限记忆。

## 4. AI 创作对话

左侧可以找回以前的对话，搜索标题或历史内容，按文件夹分类，收藏、归档、重命名。自己的对话草稿、已选上下文和附件会恢复。

输入框上方可以添加文件、网址、原始资料和知识。搜索旧笔记时，可以按目录或标签筛选。选择本地、联网或自动检索后发送。进度中能看到正在读取、检索或制作；回答会逐步显示。停止后保留已经收到的部分，并标明未完成。

回答下方整齐提供复制、保存知识、改写、PPT、Word、PDF、网页、配音、公众号、视频和 GIF 等入口。需要精确修改某个文件时，在那份附件上点击「修改这份」，避免改错另一版。

示例：
1. “根据这些笔记给新老师做一份培训 PPT，并附讲者备注。”
2. “把刚才的讲义改成适合家长阅读，关键数字保留来源。”
3. “把第 2 版 HTML 做成 15 秒视频，保留原网页动效。”
4. “将这段内容写成公众号文章，再给我预览。”

上下文用量中，估算容量和模型实际 token 分开显示；没有返回用量时不会凭空填数。长任务刷新不会重新提交一次生成。

## 5. 制作和修改成品

「内容创作」按目标选：报告与解读、演讲口播、公众号文章、演示 PPT、网页与互动页面、网页转视频、带配音视频、GIF、文字配音和整套内容。

从已选知识进入时，材料会自动带入。私人笔记用于团队项目时，页面会要求确认共享具体版本。模型读取材料自动安排标题、提纲和内容；高级参数按需展开。

项目只有三部分：
- 资料：查看来源，增加或替换原始依据。
- 写稿：连续编辑基础稿，直接看到标题、段落和表格。锁定部分不会被修改；引用和说明在下方可展开。
- 作品：选择生成哪一种成品，查看版本、下载，或继续做网页、GIF、视频。

基础稿修改不会直接覆盖旧成品。生成新的作品版本后，旧文件仍可找到。需要调整图像、章节和讲稿时进入对应作品继续修改。

网页转视频默认保留原网页排版和按时间播放的动画。可先预览并试听，再生成。网页需能保存为离线可用内容；需要登录、运行时联网或人工点击的应用不保证还原。PPT 是可编辑文件，音视频是实际生成的文件；某些预览或转换依赖浏览器、LibreOffice、FFmpeg 或语音服务，缺失时按页面引导安装。

## 6. 公众号文章

可以从知识、AI 回答或空白开始。左侧直接编辑排版好的正文，右侧查看手机效果；手机通过写稿/手机预览切换。主题即时应用，文章自动保存。

管理员在设置里连接公众号一次。创作者选择目标账号，核对手机预览，点击保存草稿并确认。工作台会显示保存任务和回执；断线后先核对原结果，避免重复创建。这里只保存草稿，不自动发布。尚未连接也可复制图文或下载 HTML。

## 7. 成果库和账号

成果库与知识库采用相同的卡片/列表、分类、搜索筛选与批量操作。文档可以分页预览，网页可以预览，GIF/视频/音频可以播放；可下载或打包。点击「来源与修改」回到准确的对话或项目。可读取的文稿也能重新整理为知识；需识别的文件会带入识别页。

管理员管理账号、服务连接和更新；创作者管理自己的知识、对话及创作；业务员仅查看允许开放的政策与成果。通过局域网访问时，由服务器电脑运行服务，其他电脑或手机使用管理员提供的地址登录。

## 8. 更新

管理员到「设置 → 工作台更新」检查并一键升级。原账号、资料和配置保留。升级前等任务完成，升级中不要关闭服务端电脑；完成后页面自动恢复。Windows 和 Mac 的手动步骤见随包升级说明。
