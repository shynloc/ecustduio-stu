# 交给本地 Agent 的安装/升级提示词

请将下方内容与下载包的实际路径一起交给安装电脑上的 Agent。

```text
请帮我安装或升级 EcuStudio 教创工作台 0.8.0。
安装包路径：[填写下载到本机的 ZIP 路径]
原安装目录：[已安装则填写；不知道请自动查找]

先查看包内 README、先读我和安装升级指南，判断本机是 Windows x64、Apple Silicon Mac 还是 Intel Mac。解压到新目录，避免覆盖原安装目录。

如果找到旧版，使用随包升级器，保留原账号、资料、笔记、项目、成果、DeepSeek 配置与本机凭据。先确认备份已创建；不要删除数据目录、初始化新数据库或重新创建管理员。

Windows 新安装运行一键安装.cmd，升级运行一键升级.cmd。
Mac 新安装运行 Install.command，升级运行 Upgrade.command；使用当前登录用户，不使用 sudo。默认位置是 ~/Library/Application Support/EcuStudio。

让安装器检测并准备 Node、依赖和 Chromium；如要生成 GIF，检测 Python/Pillow，必要时运行工作台提供的 setup-gif-runtime.mjs。不要安装或替换不相关的软件，不要泄露或打印 API Key。

完成后启动服务，确认健康接口的版本为0.8.0，打开工作台。旧版继续使用原账号；新安装由用户在本机创建管理员。检查视觉制作页可以打开，说明本机地址、局域网地址和启动/停止方法。

执行包内适用的自检。Mac 请说明钥匙串、Vision OCR、LaunchAgent等原生检查的实际结果；不要把静态检查当成实机通过。涉及真实 DeepSeek 付费调用时沿用本地用户已经授予的授权；没有授权则先告知调用内容和用途。

最后用中文报告安装位置、版本、服务状态、数据保留情况、实际检查结果和需要用户处理的问题。
```
