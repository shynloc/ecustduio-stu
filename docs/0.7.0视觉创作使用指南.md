# EcuStudio 0.7.0 视觉创作使用指南

日期：2026-11-15。本机开发版本，统一网页、演示、动图与视频制作。

## 从哪里开始

1. 打开工作台，进入创作项目。已有母稿、政策解读、讲座稿等均可使用。
2. 保存正文后，点击「制作网页 / PPT / 动图 / 视频」。系统读取 HTML Creator Studio 的设计方法，建立共享视觉项目。
3. 在任务结果中打开视觉项目，检查桌面、手机和网页演示预览。
4. 调整配色、字体、布局和配图，点击保存新设计版本。内容仍来自原有正文版本；修改正文请返回内容编辑器保存新版，再建立新的视觉项目。
5. 选择成果类型、画幅、声音及动图场景，核对文案与画面后点击「生成所选成果并打包」。完成后从任务结果或视觉项目下载。

一句话任务管家和整套内容包也使用同一个视觉项目，不再分别建立互不关联的网页与视频母版。「素材与知识」中的讲座模板可以同时输出 PPTX、网页、演示 PDF，并继续进入视觉制作。

## 每种成果是什么

| 成果 | 能力和使用方法 |
|---|---|
| 网页 HTML | 响应式单文件，配图内嵌，下载后可离线打开。「开始网页演示」切换幻灯片，方向键翻页，Esc 退出。末尾列出依据与来源。 |
| 可编辑 PPTX | 默认模式。标题、正文与基础图形是 PowerPoint 原生对象；配图是图片/GIF 媒体对象。讲者备注包含正文、引用和来源。下载后可在 PowerPoint 修改。 |
| 外观快照 PPTX | 逐页使用网页渲染的图片，适合保留视觉外观。页面主体不可逐字编辑，界面会明确提示。 |
| 演示 PDF | 与共享场景同分页的横版文件。原有内容导出的 A4 讲义仍可使用。 |
| GIF 动图 | 选择最多六个场景，生成短循环图卡及静态 PNG 替代图。当前提供进度线、编号呼吸和轻微摆动三类动效。实际使用 GIF Factory 编码器。 |
| 配音 MP4 | 使用现有 DeepSeek 凭证生成场景配音，按真实音频长度安排画面。横屏 1280×720 或竖屏 720×1280，H.264/AAC，15 fps。另附 WAV、场景字幕 SRT 和制作记录。 |
| ZIP 内容包 | 汇集该视觉版本的成果及制作记录，方便统一交付。 |

## 复用动图、图片和配音

- 上传 PNG、JPEG、WebP 或 GIF 作为共享配图，最多四张，每张不超过 3 MB。配图按场景顺序循环分配。
- 生成动图后，点击成果卡的「加入共享配图」，再保存新设计；不用先下载再上传。网页播放原 GIF，PPT 保留 GIF 媒体，视频按时间读取解码帧。
- GIF 配图最多 60 帧；解码后体积超过限制时会提示缩小素材。不同 PowerPoint 版本可能只在放映模式播放 GIF，可使用附带的静态 PNG。
- 只改变配色、字体、布局或配图，不会重写正文。同一账户、同一台词和音色的配音可以复用；重试会复用已经完成的成果。
- 有声视频的时长取决于实际配音，不会为了满足指定秒数截断台词。选择「无配音」时才采用手工设置的 10–120 秒。

## 依赖与账户

DeepSeek 调用、凭证和声音沿用现有设置。网页、PPT、PDF、视频使用既有 Node、Chromium 和 FFmpeg；动图另需 Python 与 Pillow。管理员可在视觉制作页面点击「安装动图依赖」，建立独立环境，不修改系统 Python 包。机器尚未安装 Python 时，先安装 Python 3.10 或更高版本，再重试；Pillow 版本须受该 Python 版本支持。

管理员和创作者可以制作。业务员沿用原有查看权限，不开放创作、依赖安装、私有视觉预览或私有导出文件。局域网浏览器使用服务器上的制作环境，手机无需安装 Python 或 FFmpeg。

## 来源和版本

制作结果保留草稿标识。生成文件不等于已完成政策核验，也不会自动发布。来源更新后，政策影响页面会列出关联视觉项目；旧成果保留，新制作要求从新内容版本重新开始。设计修订创建新版本，不覆盖旧版下载文件。

在外部 PowerPoint 编辑的内容不会自动回写工作台。外部网页需先经过现有资料导入和内容生成，不能将任意网页无损转为可编辑 PPT。

## 当前范围

当前贯通政策图卡、结构化演示和配音解读视频。GIF Factory 的角色新姿态、书法签名、3D、复杂知识短片等分支未全部成为宿主制作能力；安装技能文件不代表这些能力已经实现。视频字幕按场景定位，不是逐词对齐；未提供拖拽式逐元素排版或视频剪辑时间线。

本轮在 Windows 上进行了真实生成及桌面/手机浏览器验证。代码与打包脚本保留 macOS 适配，但本轮未进行 Mac 实机运行和 PowerPoint 动画播放验收。
