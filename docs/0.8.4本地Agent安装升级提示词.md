# 给本地 Agent 的安装升级提示词

请帮我安装或升级 EcuStudio 教创工作台0.8.4，安装包路径：`在这里填入我提供的ZIP完整路径`。

1. 识别操作系统与架构，先阅读完整解压后的“先读我.html”和“0.8.4发布与升级说明.md”。不要在压缩包内直接运行。
2. 检查是否已安装。旧用户必须使用原安装目录、data和原操作系统登录用户，保留账号、资料、配置和凭据。不要重新初始化账号，不要删除数据库或钥匙串，不要把密钥发到聊天中。
3. Windows旧用户在新解压目录运行一键升级.cmd；新用户运行一键安装.cmd。macOS旧用户运行Upgrade.command；服务停止失败时运行Repair-Upgrade.command。新用户运行Install.command，默认安装到用户Library/Application Support/EcuStudio。不使用sudo。
4. 使用随包脚本检测、安装所需运行环境和生产依赖；升级前等待工作台正在执行的任务结束，确认备份成功。不要手动覆盖data。
5. 启动工作台，检查/health显示0.8.4，使用原账号登录，确认原笔记、资料和DeepSeek凭据仍在。密钥测试使用设置页已有凭据，不读出或打印密钥。
6. 用一份合成小样检查资料输入、富文本保存、任务规划和文件生成。收费API或外部发送遵循用户已有授权。核对Mac原生OCR、钥匙串与Safari表现；记录明确通过与未验证的内容。
7. 若升级失败，保留备份、日志与原目录，报告具体错误编号；不要通过重装和清空资料掩盖问题。
