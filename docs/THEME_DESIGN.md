## 默认主题约定

保留当前暖白墨绿界面的配色、字体、布局、导航和编辑体验，命名为「书院 · Scholar」。新安装、旧配置缺少主题字段以及重新启动时都使用该默认值。设置页明确显示默认主题名称。

本次仅增加默认主题身份，不改写业务数据或AI配置。PPT、PDF、DOCX等导出文件继续使用自己的版式，不跟随未来工作台深浅主题变化，以保证打印和交付的一致性。

## 曜石的设计主线

把「原文 → 事实 → 母稿 → 成果」作为贯穿工作台的视觉母题。四个略有错位的立体卡片，用虚线证据链连接；选中时出现边缘光，并在观察窗显示阶段说明。用户看到的是知识流动的关系，而不是无关的科技装饰。

主底色为深海黑，内容面板比背景抬高一层。冰青用于当前选中、主操作和可追溯关系；琥珀用于待复核与重点数字。错误另用柔和珊瑚红，不能与待核实状态混淆。所有状态同时保留文字及图标。

| 一级面板 | #111923 | 卡片、编辑器、列表 |
| 二级面板 | #151F2B | 悬停、局部强调、弹窗 |
| 边线 | #283747 | 表格与信息层级 |
| 主文字 | #EDF3F6 | 正文与标题 |
| 次文字 | #A0AFBE | 说明与元数据 |
| 冰青 | #7EE7DF | 选中、主按钮、引用关系 |
| 琥珀 | #E6B875 | 待复核、重点与统计 |
| 错误 | #F0978A | 失败及阻断提示，正式接入时补齐状态映射 |

标题使用具有书卷感的衬线字体；正文使用清晰的中文无衬线字体；时间、版本、任务ID与小型标签使用等宽字体。字体优先使用本机，不依赖外网加载。

### 页面落地

| 页面 | 视觉处理 | 操作重点 |
|---|---|---|
| 工作台 | 证据星图、错位卡片、统计细线 | 主操作不被装饰遮挡 |
| 政策情报 | 引文边缘高亮，段落定位使用短暂底色强调 | 阅读区不铺光效或动态网格 |
| 选题策划 | 琥珀评分，核验状态独立标注 | 评分不替代真实性 |
| 创作项目 | 侧边引用轨道、版本标签、稳定深色文稿面板 | 可另开纸面预览，正文不跟随鼠标倾斜 |
| 任务 | 精细阶段线、事件进入动效、工具事件细节 | 仅真实服务端事件推进状态 |
| 成果 | 文件类型、版本、审核状态与下载入口分层 | 草稿和发布状态保持显著 |
| 设置 | 同一结构，主题选择卡并排对照 | 支持预览、保存、恢复默认 |

### 动效规则

- 首次进入：面板由下向上12px淡入，总时长约650ms；四张统计卡间隔60ms。
- 悬停：边线高亮、轻微抬升、低强度光晕；不跟随鼠标大幅摇晃内容。
- 证据链演示：原型点击后依次点亮四节点，约3.5秒完成，可以停止、重置或直接选节点。
- 正式任务反馈：只在新事件到达时短暂流光，不用定时动画伪造任务推进或完成百分比。
- 编辑区域：保持静态，不出现持续粒子、闪烁、扫描线或大面积光晕。
- 减少动态效果偏好：取消位移、轨道动效和过渡，保留状态变化。
- 手机：取消立体视差，统计改为双列，内容纵向排列；不隐藏主要操作。

## 原型使用

打开同目录「曜石主题交互预览.html」。点击「体验证据链」播放节点动效；也可直接点原文、事实、母稿和成果节点。「对照暖白配色」只做同布局下的色彩比较，不替代真实书院界面的截图。

原型中的数量、分数和内容均为示意，顶部持续标记，不连接工作台、数据库或DeepSeek。导航会说明对应页面的设计范围；当前原型重点覆盖首页与证据链交互。

## 正式接入计划

1. 将现有颜色逐步抽为语义变量，先保证默认主题像素和交互不发生意外改变。
2. 在原型方向确定后，接入obsidian主题、独立主题保存接口和设置页选择卡；保存主题不提交其他未保存的配置。
3. 启动时读取已保存主题，切换时即时预览；支持一键恢复书院默认，避免打开页面时先亮后暗。
4. 覆盖工作台、资料、选题、编辑、任务、成果、设置及所有弹窗、禁用、错误与空状态。
5. 验证1440px和390px、键盘焦点、减少动态效果、文字对比度、长文阅读与主题持久化。导出文件独立验收。
