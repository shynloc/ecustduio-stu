# 0.9.0 开发与验证记录

## 数据与兼容

增加迁移 006_pipeline：持久化 ContextRef、分类操作撤销记录、结构化证据块/核对记录、上传会话与配额。lineage_edges 视图从既有资产、媒体任务、笔记修订、素材、事实、项目、母稿、视觉和成果建立来源关系；旧 ID、正文和历史版本不重写。来源新版本和原笔记正文修改会使依赖内容失效，保留旧产物。恢复旧数据库后同样执行所有缺失迁移。

权限在服务端校验：ContextRef 记录所有者，解析时重查来源 ACL/版本/内容哈希；共享笔记需明确确认；部分识别禁止通过勾选核对绕过完整性限制。业务员仍只读政策和可发布成果，不能调用新写接口；创作者不可管理账户、配额或升级。

上传采用 256 KiB 分块、SHA-256、顺序偏移校验及重复块幂等，服务端限制配额和剩余磁盘空间。HTTP 局域网浏览器使用便携 SHA-256 实现，无需 HTTPS SubtleCrypto。完整 PDF 流式落盘，其他文件沿用类型验证。原件最多 200 MB，单篇笔记最多 10 万字符。

## 流程与修复

复用 production/workflows/visual 的既有队列和检查点；新页面连接输入、私人笔记、共享素材、研究、母稿、静态成果及经确认的视觉输出。无材料不选无关资料。结构化 Agent 提供准确的原文 ID 清单；视觉阶段按项目授权原文；错误 ID 作为受限工具错误回传让模型纠正，不泄漏额外内容。

修复新建空笔记编辑状态随首段输入意外退出；只读阅读器不显示编辑入口。中文组合输入结束后触发自动保存。增加批量整理撤销、版本冲突保护、来源更新标记、原页证据核对记录、公众号摘要/封面、本地富文本出口与统一成果打包。

## 验证方法与记录

- `npm run check`：前后端类型检查。
- `tests/pipeline.test.ts`：版本引用、批量分类/撤销、明确共享、部分结果保护、依赖失效、证据页码/核对哈希、上传恢复/幂等/错位/超限、局域网哈希与交叠去重、三类账号权限。
- `tests/pipeline.e2e.ts`：文字输入→笔记→AI 上下文刷新→共享创作→任务刷新、批量撤销、文件续传→识别任务，1440/768/390 宽度与书院/曜石两主题。
- 媒体、文档分片、知识库、账号、工作流、共享视觉输出和更新协议回归沿用定向测试，避免重复调用真实服务。
- `scripts/check-pipeline-live.ts`：真实 DeepSeek，隔离数据库与合成教学材料，生成 HTML、原生可编辑 PPTX、DOCX、PDF、GIF、约 30.88 秒带真实配音的 MP4、WAV、SRT 与整套 ZIP。恢复已有检查点继续执行，完成后移除测试凭据副本。媒体元数据和文件存在检查不等同于逐字听审。
- `tests/online-update-v090.e2e.mjs`：原始公开 0.8.4 安装夹具，管理员页面获取真实签名更新并升级，检查原业务表、三个账号密码、原件、配置及 DPAPI 字节和解密结果；旧 0.5.0 客户端签名兼容另行检查。
- 包内清单逐项 SHA-256 校验；公网重新下载核验；Mac 启动/升级脚本可执行位检查。公开验收记录列出实际完成结果。

## 边界

无 Mac 实机，Mac 原生钥匙串、Vision、Safari/中文输入和服务升级尚未实机验收。未取得学生原 PDF 和失败公众号 URL，相关回归使用格式夹具与合成材料。公众号远端草稿授权按原计划独立后续适配，本版为本地排版、复制和导出。单页交叠采用确定性完全匹配，不进行可能删除独有信息的语义去重。产物默认研究草稿，不代表已核实或已发布。
