本版从体验整改方案提交 3735ce6 接续开发。具体条目见 docs/plans/2026-11-19-experience-progress.md。最终发布验收与包哈希另存公开 Acceptance.json，不能把早期测试记录等同于最终安装包验收。

## 实现

新增 010_workspace_experience.sql，保留旧业务表；新增按账号隔离的分类、文件夹、标签、批量撤销、视图与草稿偏好、对话历史摘要。升级器保留清单同步增加永久表，签名信任链不变。

共用 TipTap 文档 schema、图标工具栏、Markdown/JSON 回环、安全阅读、公式/脚注/嵌入内容保留；迁移文字输入、知识、识别结果、项目连续稿及公众号写稿。图片可上传、调整宽度和说明，选段可交给 AI 修改并核对差异。

任务组件恢复持久事件，显示阶段、上传/分页进度、部分成功、重试与结果入口。对话支持 SSE 增量、多轮工具、原生签名记录、上下文摘取与历史依据。原始推理字段不显示给用户，实际 usage 与估算分开。

分类组件复用于知识/成果，对话单独提供同样的持久管理。10 个成品入口复用已有生成引擎，HTML/视频可在对话和项目中续作。项目采用资料/写稿/作品，连续文档保留 block/claim IDs、锁定与版本。3D 场景用 Three.js 懒加载，关闭/减少动效与 WebGL 不可用时提供可操作静态替代。

## 验证边界

- TypeScript、构建及文档回环、权限、分类、任务/模型协议、网页/多格式本地生成已有自动检查。
- 全量单元/API 首轮 148 项中 145 通过；发现的原生多轮签名保留与 Windows 浏览器回退 3 处失败已修复，对应 13 项复测通过。
- 更新协议和 Mac 停服契约 11 项通过。
- 真实 DeepSeek controlled 路径使用隔离合成教学笔记，模型 deepseek-flash 返回正确引用与流式内容，实际输入1124、输出58 tokens。未发送真实学生资料；这不是全部模型/多模态服务的实测。
- 桌面1440、平板768及手机390视口测试覆盖书院/曜石，浏览器协议夹具与实际本地生成文件分开记录。手机视口不是实体 iPhone 或 Safari 验证。
- 微信草稿使用本地 HTTP 协议夹具。维护者暂未提供真实公众号连接，真实微信草稿仍待用户条件具备时验收。
- 本轮没有附着实体 Mac。Mac 原生 OCR、钥匙串交互、LaunchAgent 在真实用户会话的验收不能用 Windows 测试替代；提供 Mac CI 和客户自检。
