# EcuStudio 教创工作台 0.11.2

DeepSeek 高级设置支持保存输出额度、请求次数和任务时限，刷新后继续生效。

长网页达到单次输出限制时，在任务预算内自动续写。

AI 创作对话直接提供可预览、可下载的 HTML 文件，支持交互网页。

升级保留账号、资料、加密凭据和原有模型设置。管理员可自行启用长任务推荐值。

## 原有工作台怎么升级

1. 用原管理员账号登录，进入 **设置 → 工作台更新**。
2. 选 **检查更新 → 一键升级至 0.11.2**。等待现有任务结束，让工作台自动下载、校验、备份和重启。
3. 页面重新连接后确认版本显示 0.11.2。可以继续用原账号和密码，资料、对话、作品和 DeepSeek 配置均沿用。Mac 请使用原系统登录用户，以便继续读取钥匙串。

## 下载与安装

- [Windows x64 安装与升级包](https://dshdisk.acks.com.cn/ecustudio/0.11.2/EcuStudio-0.11.2-Windows-x64-UpgradeReady.zip)
- [macOS 安装与升级包](https://dshdisk.acks.com.cn/ecustudio/0.11.2/EcuStudio-0.11.2-macOS-UpgradeReady.zip)

Windows 和 macOS 14 及以上均使用联网安装包。Mac 自动识别 Apple Silicon 与 Intel。新用户完整解压后，Windows 双击「一键安装.cmd」，Mac 运行 Install.command。

旧版如没有网页更新入口，请解压到原安装目录之外的新文件夹，Windows 运行「一键升级.cmd」，Mac 在解压目录执行 `bash Upgrade.command`，选择原安装。升级器在原数据目录生成备份。
