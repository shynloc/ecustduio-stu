# EcuStudio 0.6.0 开发说明

## 数据与流程

新增 shared/workflows.ts 定义计划与输出结构；server/workflow-agent.ts 实现白名单工具 read_skill/read_source/search_materials；server/workflows.ts 编排计划、共享研究与母稿、多渠道版本、预审、导出和 ZIP；server/source-review.ts 实现精确引文验证与影响关联；server/visual-studio.ts 实现有界设计规范、固定文案 HTML、真实预览、哈希批准、Chromium/FFmpeg MP4。

004_workflows.sql 只新增 visual_drafts、visual_approvals、source_previews 及索引。现有表及数据不重写。新增任务类型 workflow-plan/workflow/policy-impact/source-review/visual-video 使用已有队列、取消、租约和 checkpoint。内容版本按 job_id/kind 唯一；子文件使用独立阶段键，安全重试复用结果。

## 主要接口

- POST /api/workflows/plan：范围冻结与 ACKS 计划。
- POST /api/workflows/execute：核对计划所有权和授权资料，再创建独立项目。
- GET /api/workflows/skills：版本与来源目录。
- GET /api/impacts；GET /api/impacts/compare；POST /api/impacts/analyze。
- POST /api/source-review；GET /api/source-review/:versionId。
- GET /api/visuals/:id；POST /api/visuals/:id/render。

管理员和创作者可制作；业务员不开放这些接口。任务及视觉预览限制为所有者或管理员。创作者影响追踪仅含自己的笔记。内容稿件继续遵循现有共享创作空间，销售端仅查看已发布成果。

## 证据与渲染

AI 引文按来源段落逐字验证；预审引用必须属于对应内容块。预审不写入事实核实或审核状态。HTML 文案直接绑定冻结版本，设计参数限定枚举与十六进制颜色，模型无任意代码执行权。浏览器渲染禁用外部请求和 Service Worker；预览 iframe 不允许同源权限。导出的 HTML 自包含。

视频批准记录绑定 actor、copyHash、visualHash、画幅、时长；渲染前核对来源是否陈旧。编码器由 @ffmpeg-installer/ffmpeg 的平台可选依赖提供，使用参数数组启动，不经 shell。输出固定 H.264/yuv420p/15fps，第一版无声；制作记录标明真实引擎及限制。

## 打包与更新

Windows/Mac 联网安装包携带源码、构建产物、迁移、两套完整原始 Skill 和文档；排除数据、密钥、node_modules、Python 缓存。新增视频依赖使 0.5.0 更新器在停服前准备新的生产依赖。保持原 Ed25519 验签公钥及 stable.json 地址，发布包先上传并检查哈希，再发布稳定版本签名清单。

对原版 0.5.0 的安装目录使用隔离升级验收，比较升级前后业务表原记录、配置和加密凭据字节，并验证三类原账号登录。Mac 平台的原生服务/钥匙串行为需实机自检。
