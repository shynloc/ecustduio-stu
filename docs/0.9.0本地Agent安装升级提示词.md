# 交给本地 Agent 的安装与升级提示词

请在本机安装或升级 EcuStudio教创工作台 0.9.0。安装包路径：在这里填入用户下载的 Windows 或 Mac ZIP 路径。

先读取包内“先读我.html”和“0.9.0发布与升级说明.md”，识别操作系统与已有安装位置。已有安装必须升级，保留原账号、密码、资料、笔记、历史成果及 DeepSeek 配置。不要删除或移动原 data，不要创建空数据库代替原数据，不要打印凭据。

已有 0.5.0+ 正常运行版本，优先使用管理员页面的“设置→工作台更新→检查更新→一键升级”。无法在线升级时，把新包解压到旧目录之外，调用包中原生升级脚本：Windows“一键升级.cmd”；Mac“Upgrade.command”。Mac 使用原系统用户、不使用 sudo；遵循系统允许打开本地脚本的正常操作，不关闭系统安全保护。

新安装：Windows“一键安装.cmd”，Mac“Install.command”。按安装器检查下载缺失依赖并启动服务，首次设置由用户建立管理员账号，不预设通用密码。局域网只在服务电脑部署，其他设备通过该电脑局域网地址登录。

完成后检查 /health 版本为 0.9.0，原账号可登录，原资料和笔记存在，DeepSeek 显示已配置而不输出密钥。使用合成资料做“资料输入→知识库→多格式成果”的小样测试。真实 API 调用由用户允许的工作台配置控制；不要为了测试修改旧业务资料。升级失败先保留本机备份和日志，查明原因，不执行卸载重装或清空数据。报告实际完成与尚未验收项目，尤其 Mac 原生能力不能用 Windows 测试代替。
