# EcuStudio 教创工作台 0.8.1 升级说明

发布日期：2026年11月16日。本版修复实际创作流程中发现的三处问题：计划页数未传入生成任务、AI步骤字段不一致导致逐项动画为空、整套内容包混入历史版本成果。延续0.8.0的统一网页、可编辑PPT、GIF及配音视频功能。

## 已安装0.5.0及以上：设置里一键升级

1. 管理员登录工作台，进入「设置 → 工作台更新」。
2. 点击「检查更新」，确认最新版本为 **0.8.1**。
3. 点击「一键升级至 0.8.1」。程序会下载并校验安装包，先备份，再更新和重启。
4. 等待页面自动恢复，确认当前版本为0.8.1，使用原账号继续工作。

**原有账号与密码、权限、资料、笔记、项目、已生成成果、主题设置和DeepSeek配置会保留，无须重新创建管理员或录入密钥。** 升级继续使用原安装目录和数据目录。备份位于原安装目录的 `data/upgrade-backups`；失败时更新器会尝试恢复原版，异常中断可在设置中恢复未完成升级。

升级前让正在排队或运行的任务完成。升级期间保持服务端电脑开机；同一局域网里的成员不需要各自安装或升级，服务端更新后刷新页面即可。使用原操作系统登录用户启动服务，以继续读取Windows DPAPI或Mac钥匙串中的凭据。

## Windows 下载、安装与手动升级

[下载Windows 0.8.1安装升级包](https://dshdisk.acks.com.cn/ecustudio/0.8.1/EcuStudio-0.8.1-Windows-x64-UpgradeReady.zip)

- 新用户：完整解压，运行「一键安装.cmd」，按提示完成初始化。
- 旧用户或设置页没有更新入口：将新包解压到原安装目录之外的新文件夹，运行「一键升级.cmd」，确认原安装目录，等待备份、升级和启动。
- 不要删除原安装目录，不要覆盖或替换 `data`，不要按新安装流程创建另一套空数据库。

## Mac 下载、安装与手动升级

[下载macOS 0.8.1安装升级包](https://dshdisk.acks.com.cn/ecustudio/0.8.1/EcuStudio-0.8.1-macOS-UpgradeReady.zip)

- 适配目标：macOS 14及以上，Apple Silicon和Intel。
- 新用户：完整解压，运行 `Install.command`；也可在终端进入解压目录后运行 `bash Install.command`。
- 旧用户：优先使用工作台设置中的更新入口；若没有入口，将新包解压到原安装目录之外，运行 `Upgrade.command`，确认原安装位置。
- 默认安装目录为 `~/Library/Application Support/EcuStudio`。使用原Mac登录用户，不使用sudo，原账号、资料及钥匙串中的DeepSeek配置保留。

两个压缩包都是联网安装升级包，包含源码、构建产物、安装升级脚本和文档。首次安装按需下载运行环境，升级优先复用原依赖，因此压缩包体积较小；包内不包含任何业务数据或凭据。

本轮在Windows完成实际创作流程验证，Mac包进行文件完整性、脚本布局及执行权限检查，未进行Mac实机安装验收。Mac可运行随包的 `Check.command` 做本机检查。

视觉制作方法继续参见《0.8.0视觉创作使用指南》。需要本地Agent协助时，将安装包路径与《0.8.1本地Agent安装升级提示词》一起交给Agent。
