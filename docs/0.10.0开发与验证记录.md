# 0.10.0 开发与验证记录

## 实现

- `server/wechat-client.ts`：固定微信官方 HTTPS 地址，稳定版 access_token、内存缓存、到期更新、可操作中文错误，正文图片上传、永久封面素材、创建与回读草稿。客户端不能传 API 地址、令牌或任意待发送 HTML。
- `server/wechat.ts`：管理员连接和加密存储、创作者私有预览与草稿、自动封面/摘要、配图检查和 JPEG 压缩、版本冻结、持久化任务与恢复。预览直接嵌入本机图片，解决隔离 iframe 不携带登录 cookie 导致的空白配图。
- `007_wechat.sql`：新增公众号连接、预览和草稿记录表，不重建原业务库。升级保留清单新增这三个表。原凭据加密格式和更新签名保持兼容。
- `web/WechatEditor.tsx`：三步操作，默认选项、折叠调整、可恢复保存记录、设置页连接卡片。移动端按选笔记、预览、保存排列。

## 外部写入恢复

发送 draft/add 前持久写入提交意图。若连接中断或进程退出，重试先分页核对最近最多100篇草稿，以标题、摘要、正文和封面完全匹配确认；多个匹配或未找到时保持待确认，不自动重复创建。保存 media_id 后，后续重试只回读，不重新新增。只有微信回读内容与预览对应的文章一致才标为已保存。手动重新发送需要用户先确认目标草稿不存在，并写审计记录。正文、图片和账号在发送前重新校验；权限撤销、换号或笔记变更会阻止新发送。已经在微信开始处理的请求无法在本机撤回。

## 验证

- 8 项公众号接口测试：真实本地 HTTP 协议夹具、令牌失效重取、IP白名单说明、图片格式、自动封面、冻结与幂等、发送后断网恢复、无回执安全恢复、回读不符、已知拒绝、账号重连、三角色权限、Windows 加密保存。
- 19 项知识库/账号回归；8 项 Mac 钥匙串适配和错误处理测试（接口夹具，不是Mac实机）；4 项签名更新协议；7 项 Mac 停服契约测试。
- Playwright：资料输入→保存私人笔记→公众号排版→连接→自动预览→队列保存→回读→刷新恢复，书院/曜石、1440与390宽度，验证预览图片真实加载，无页面脚本错误。
- 双平台包清单逐文件哈希、隐私文件排除、Mac入口执行权限、0.5.0更新验签兼容；发布后公网下载复核与原始0.9.0页面真实升级验证，最终结果见公开Acceptance.json。

没有可用的本机公众号凭据，现有公众号连接插件返回需重新认证。上述 WeChat 保存测试使用隔离的本地 HTTP 服务，未据此宣称真实公众号草稿已创建。没有 Mac 实机；Mac 原生钥匙串、Safari、LaunchAgent 和安装升级需另行实机验收。安装包包含源代码和构建文件，不包含业务库、账号或密钥。
