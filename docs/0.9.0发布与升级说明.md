# EcuStudio教创工作台 0.9.0

本版把资料输入、知识库整理和多格式制作串成连续流程，保留书院默认主题、曜石主题和三类账号权限。

## 下载与升级

- [Windows x64 安装/升级包](https://dshdisk.acks.com.cn/ecustudio/0.9.0/EcuStudio-0.9.0-Windows-x64-UpgradeReady.zip)
- [macOS 安装/升级包](https://dshdisk.acks.com.cn/ecustudio/0.9.0/EcuStudio-0.9.0-macOS-UpgradeReady.zip)

**0.5.0 及以后版本：管理员登录 → 设置 → 工作台更新 → 检查更新 → 一键升级至 0.9.0。**升级完成后页面自动重连。只升级提供服务的电脑；局域网其他电脑和手机刷新页面即可。

升级器先创建本机备份，再停止旧服务、更换程序、迁移数据库并检查启动。保留原账号及密码、资料、笔记、历史成果、设置与 DeepSeek 凭据。不要卸载旧版、删除 data、移动安装路径或更换系统登录用户。Mac 的凭据仍使用原用户钥匙串；Windows 仍使用原用户 DPAPI。错误时保留备份和原数据，不重新初始化。

无法在线升级时，将新包完整解压到**旧安装目录之外**：Windows 双击“一键升级.cmd”；Mac 使用原登录用户运行“Upgrade.command”，不要使用 sudo。新用户分别运行“一键安装.cmd”或“Install.command”。Mac 目标为 macOS 14+，支持 Apple Silicon 与 Intel。包为联网安装包，依赖和运行环境按需下载，不含业务库、账号和密钥。

## 推荐工作流程

1. **资料输入**：直接写文字保存私人笔记；输入公开网址读取正文、配图和表格；上传文档、图片或录音进入识别。网址成功读取的内容为团队共享资料。受限网页会说明失败原因，不生成替代正文。
2. **核对与入库**：在文件与语音页对照原件、页码和识别结果，再保存笔记。长 PDF 自动分片；失败页可续跑，部分识别保留但不能作为完整原件转成素材。单页分区只自动移除完全一致的较长交叠文字，疑似重复保留供核对。
3. **知识库整理**：默认富文本阅读，支持正文编辑、表格、图片、自动保存和版本恢复。可批量移动文件夹、替换标签及用途，并撤销本次整理；其他页面已有新修改时拒绝覆盖。
4. **继续研究**：笔记可载入 AI 探索、配音或多格式成果；交接记录保存在服务端并绑定资料版本，刷新和返回仍有效。原资料改变时要求重新载入。
5. **制作成果**：进入“多格式成果”，选择笔记/共享资料、填写目标、勾选格式。私人笔记转团队创作素材需明确确认。自动提取事实、生成母稿和内容，制作 HTML、可编辑 PPTX、DOCX、PDF。
6. **动图和配音视频**：在同页预览共用设计，核对文案和画面后继续生成 GIF、MP4、配音 WAV 与字幕。视觉制作页可逐页修改；失败重试复用已完成的步骤和文件。
7. **成果库**：按名称/格式查找、下载、返回视觉编辑，选择多个成果打包。来源更新或原笔记正文改动后标记待复核，历史文件不覆盖。自动监测成功新增的资料会进入执行账号的“自动采集”文件夹；系统定时执行时归档到最早创建且有效的管理员账号。失败信源保留失败说明。
8. **公众号排版**：选择笔记、摘要、封面和风格，查看手机预览、复制富文本或下载含图片的 HTML。公众号远端授权与直接写入草稿箱属于独立适配，不包含在本版；无需公众号凭据即可使用本地排版出口。

## 上传与资源限制

PDF 默认最多 200 MB，其他文件最多 50 MB。管理员可在设置调整 PDF 上限和未完成上传总配额。浏览器分块上传；断网或刷新后重新选择同一文件即可续传。超过 7 天的未完成上传在后续上传时清理；磁盘不足会停止接收。超长资料自动归档可分多篇笔记，保留来源和分段标记。

## 已验证与实际边界

已完成定向接口/权限回归、电脑/平板/手机三种宽度与两套主题检查，以及真实 DeepSeek 的笔记→事实→母稿→HTML/PPTX/DOCX/PDF→GIF/带配音视频→ZIP 流程。测试使用隔离数据库和合成教学材料，不污染原工作台。

Windows 的旧版页面在线升级与数据保留检查结果以随附验证记录为准。Mac 包检查文件哈希、启动脚本权限和升级协议兼容；当前环境没有 Mac 实机，Safari 中文输入、钥匙串、Vision OCR 与原生升级仍需 Mac 端验收。学生原始 PDF 和失败公众号链接尚未取得，不能将合成样例测试等同于原故障复现。网页访问限制及上游服务故障仍可能影响读取；识别结果须核对原件。
