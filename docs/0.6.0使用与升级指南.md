# EcuStudio教创工作台 0.6.0 使用与升级指南

## 这次增加了什么

一句话任务管家把要求整理成可编辑计划，串起共用事实提取、内容母稿、多渠道稿件、来源预审和整套 ZIP。政策影响追踪把同一来源的新旧版本与现有项目、稿件、本人可见的创作笔记关联起来。两个随附 Skill 分别用于提示词优化和网页设计。

## 老用户从 0.5.0 一键升级

Windows 和 Mac 都由工作台管理员进入「设置 → 工作台更新」，点击「检查更新」，确认新版为 0.6.0 后点击「一键升级至 0.6.0」。服务端下载并校验签名与文件校验值，准备依赖、创建备份，然后短暂重启。等待页面自动重新连接后，确认页脚版本为 0.6.0。

原有账号、密码、资料、笔记、项目、DeepSeek 配置和授权保留，无需重新录入。客户端电脑和手机刷新页面即可，无需各自安装。保持服务器原安装位置和系统登录用户；Windows 的 DPAPI 凭据、Mac 钥匙串配置继续在原环境使用。本次数据库只新增表。

本次增加视频编码依赖，首次升级需要联网准备相应平台的 FFmpeg 和浏览器依赖。准备期间旧服务继续运行；请不要关机或重复运行安装程序。运行中的制作任务完成后再升级。如果升级失败，界面显示原因，并可恢复未完成的升级。备份保存在原安装目录 data/upgrade-backups。

若设置中没有「工作台更新」，说明尚未接入 0.5.0 的更新器。下载对应平台完整 ZIP，解压到原安装目录之外：Windows 双击「一键升级.cmd」，Mac 运行「Upgrade.command」，选择原安装目录。不要把新包直接覆盖到旧目录。新用户分别使用「一键安装.cmd」或「Install.command」。Mac 使用原登录用户，不使用 sudo。

- Mac：https://dshdisk.acks.com.cn/ecustudio/0.6.0/EcuStudio-0.6.0-macOS-UpgradeReady.zip

## 一句话完成一套内容

1. 在「政策情报」导入资料；文件、图片、扫描 PDF 或音频也可先经已有「文件与语音」流程处理，校对并保存为资料。
2. 打开「一句话任务管家」，输入目标、适用地区、年度、学段和受众。选择资料范围及希望得到的内容，不选输出则由 Agent 建议。
3. 点击「优化要求并规划任务」。Agent 实际读取 ACKS 提示词优化 Skill，并检索所选资料。不选资料时只在最近 150 份资料中检索。
4. 核对计划中的依据资料与待确认事项，调整优化后的要求、输出类型、设计要求和时长，再点击「按此计划制作整套内容」。重新选择资料时返回重新规划。
5. 在任务详情查看阶段进度。完成后下载整套 ZIP，也可分别下载各格式文件。共用母稿只制作一次，各渠道沿用同一组候选事实。

支持政策解读 DOCX/Markdown、公众号 DOCX/HTML、口播 DOCX/Markdown、讲座 PPTX/PDF、分镜 DOCX/JSON、交互 HTML 页面和 HTML 视频母版。内容包包含母稿、所选输出、来源预审与引文记录、交付清单。重复文件名使用短标识区分。失败后可在任务详情从安全位置重试，已完成版本保留。

每个 AI 阶段分别使用设置中的调用预算和 token 上限；整套任务受任务超时限制。复杂任务可延长超时或减少交付物。技能调用至少需要两次模型请求。资料过大时拆分资料或调整管理员的输入预算。

## 政策影响追踪

同一来源 URL 出现新快照后，页面自动列出可对比版本。也可以手动选择两份资料。先查看原文段落增删，再让 Agent 解释变化。每条变化保留对应段落的原文引句；年度或地区不同不自动判定为旧政策失效。

页面列出引用旧资料的项目与稿件，以及当前用户有权查看的笔记。点击项目旁「生成修订任务」会基于新版资料建立新项目，原项目及版本保留；核对后再决定采用哪份稿件。创作者不会看到其他人的私人笔记或制作任务。

## 来源预审

内容包自动包含预审；已有项目可在版本编辑器点击「来源预审」，未保存的编辑需先保存为版本。系统检查引文是否能定位、事实是否已人工核实、地区/年度/学段是否一致、来源是否已有更新，再由 DeepSeek 对各内容块提出支持度及修改建议。

展开预审可查看原文引句并跳转资料。AI 预审不会把事实改成「已核实」，也不会自动通过发布审核。教育政策的条件、日期、数字仍需人工核对。

## HTML 和视频

选择 HTML 或视频输出后，Agent 实际读取 HTML Creator Studio Skill。当前适配器将其设计建议转换为可控的社论长页、卡片或时间轴布局，保留源版本的标题、正文及引用。模型不执行任意脚本、命令或外部资源。

网页工作室提供实际渲染的桌面和手机预览、截图与 HTML 下载。HTML 具有内容目录和返回顶部操作。网页预览隔离运行，不读取工作台登录信息。

制作视频时核对该版本的具体文案和画面，分别勾选两个确认项，选择竖屏 9:16 或横屏 16:9、10–120 秒，点击「生成 MP4 并更新整套内容包」。批准记录绑定文案和视觉哈希，内容或来源发生变化时需重新生成母版并核对。

首版视频由本机 Chromium + FFmpeg 实际逐帧渲染：完整段落按顺序呈现，含进度条，15fps，无配音。画幅不能容纳全文时会明确报错，请缩短内容后重新制作。它不是 Remotion/HyperFrames 导出，也不是任意复杂动画生成器。已有语音功能仍可独立生成配音；本版不自动合成到新视频。

视频完成后再次提供整套 ZIP，包含原交付物、MP4 和制作记录。所有自动交付均为研究草稿，不自动对外发布。

## 平台与验证范围

Windows 支持本机和局域网使用。Mac 安装包支持 macOS 14+、Apple Silicon 和 Intel，按平台联网安装依赖。Windows 上验证共享逻辑和发布包结构，不等于 Mac 原生实机验收；Mac 的钥匙串、Vision、LaunchAgent 与 FFmpeg 原生执行请按随包自检在目标机确认。详细本轮验证见《0.6.0验证记录》。
