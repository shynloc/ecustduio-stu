# EcuStudio 教创工作台 0.7.0 升级说明

0.7.0 统一了网页、可编辑 PPT、演示 PDF、GIF 动图和带配音视频的制作流程。HTML Creator Studio 负责共享设计，GIF Factory 负责受控图卡动效，配音沿用现有 DeepSeek 配置。

## 已经安装的用户

**0.5.0、0.6.0 用户：**管理员登录，进入「设置 → 工作台更新 → 检查更新」，选择「一键升级至 0.7.0」。等待后台完成下载、校验、备份、替换与重启，页面会自动重连。服务器升级一次，局域网用户刷新网页即可。

请先完成或取消排队中的任务，保持提供服务的电脑开机、联网。升级本身不会调用 DeepSeek。管理员可操作更新；创作者和业务员不能修改系统版本。

**没有更新入口或希望手动升级：**下载对应系统的压缩包，完整解压到原安装目录之外的新文件夹。

- Windows：双击「一键升级.cmd」，选择原安装目录。
- Mac：使用原来的 Mac 登录用户，双击 `Upgrade.command`；也可以在终端执行 `bash "/新包解压目录/Upgrade.command"`，选择原安装目录。不要使用 sudo。

不要把新包的空数据库覆盖旧库，不要删除旧目录的 `data`，不要移动原安装目录。此流程是原电脑、原系统用户下的原位升级，不是换电脑迁移。

## 保留什么

管理员、创作者、业务员账号及其密码和权限保留；原资料、素材、事实、母稿、内容版本、笔记与对话保留；DeepSeek API Key、模型、调用授权、预算、主题、端口和局域网设置保留。

升级器先在原目录 `data/upgrade-backups` 建立备份，再核对已有记录和受保护配置摘要。失败时保留原程序，或尝试自动恢复。异常中断后，按设置里的恢复入口或随包恢复脚本处理，不要删除备份。Windows 凭证继续使用原用户 DPAPI，Mac 继续使用原用户钥匙串。

## 新用户安装

- Windows 10/11 x64：解压后双击「一键安装.cmd」。默认安装到当前用户的本地应用目录。
- macOS 14+（Apple Silicon / Intel）：解压后运行 `Install.command`。默认安装到 `~/Library/Application Support/EcuStudio`。
- 安装器联网准备 Node、锁定版本的生产依赖和 Chromium，并启动服务。安装完成后，在服务器本机创建第一个管理员，再配置自己的 DeepSeek。
- 动图另需 Python 3.10+ 和 Pillow。已有 Python 时，管理员在视觉制作页面点击「安装动图依赖」即可准备独立 Pillow 环境；没有 Python 时先安装 Python，再点击该按钮。网页、PPT 和视频不依赖 Pillow。

## 升级后怎样使用

打开创作项目，保存正文，点击「制作网页 / PPT / 动图 / 视频」。检查桌面、手机或网页演示预览，选择输出，核对后生成。也可从一句话任务管家或素材模板进入同一流程。

PPT 默认包含可编辑文字和基础图形；「外观快照」模式以图片保留页面外观。GIF 可直接加入共享配图，复用于网页、PPT 和视频。带配音视频按真实音频时长安排画面，附 WAV 和场景字幕。修改设计保留旧版，未变台词可以复用配音。

GIF 当前接入政策图卡动效，复杂角色、签名、3D 和完整动画分支尚未全部实现；外部任意网页不能无损转成可编辑 PPT。字幕是场景级，下载 PPT 后的外部修改不会自动回写工作台。
