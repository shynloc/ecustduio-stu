# EcuStudio 0.6.0 验证记录

验证环境：Windows，Node 24，DeepSeek 官方 API，Chromium/Edge。验证时间：北京时间 2026-11-14 至 2026-11-15。

## 已完成的验证

- TypeScript 前后端检查和生产构建通过。
- 66 项现有核心、三角色账户、笔记/探索、媒体、DeepSeek 协议和升级维护回归通过。
- 新工作流专项：实际 Skill 工具调用协议、共用母稿、多格式内容包、预审不改变核实状态、安全重试不重复生成、原文变化关联、引用造假拒绝、销售权限与跨用户任务隔离、哈希批准门禁、真实 MP4 输出通过。
- 11 项升级引擎与签名协议测试通过，包括签名/哈希/路径检查、权限变化中止、原记录保持、失败回滚和中断恢复。
- HTML Creator Studio 原包 beta_doctor 检查与 66 项上游测试通过，仅代表包完整性及其脚本测试结果。
- 已使用本机现有 DeepSeek 凭据，在隔离数据库和明确标注的合成材料上真实执行：ACKS 规划 → 事实提取 → 母稿 → 政策/公众号/口播 → 来源预审 → 两份 HTML 母版 → 内容包。
- 真实调用日志包含两套 Skill 的 read_skill、实际版本与文档摘要；不是仅复制提示词。
- 真实浏览器完成具体文案与视觉批准后，本机逐帧渲染 MP4；ffprobe 确认 H.264、720×1280、15fps、150 帧、10 秒，无音轨。更新后的 ZIP 包含视频和原交付物。
- 真实 DeepSeek 政策对比返回可逐字定位的新旧引文，关联原项目及稿件。
- 工作台新增页面在 1440 和 390 像素视口、书院与曜石主题检查无水平溢出和浏览器脚本错误；HTML 原件另有实际桌面和手机截图。

## 发布与升级验收说明

发布使用原有 Ed25519 签名公钥与稳定更新地址；安装包含校验清单。正式公开包上传后，使用独立目录中的原版 0.5.0 进行设置页一键升级验收，最终结果另随同版本发布为「0.6.0发布验收.json」，避免测试结果写入包后改变已验签包的哈希。

原有账户/资料/配置保留既由迁移测试验证，也由升级引擎在每次实际升级中比较原表记录和受保护配置字节。不把业务数据和凭据随包分发。真实 API 验证结束已删除隔离测试目录中临时复制的加密凭据文件。

## 验证边界

Mac 包含相同业务代码和适配安装器，未在 Mac 实机执行钥匙串、Vision、LaunchAgent 或视频编码。请在 Mac 运行随包 Check.command 和原生自检。

手机检查为真实 390px 浏览器视口，不代表每种实体手机均已验收。视频已验证渲染和媒体参数；本版无声，未做配音/字幕对齐验收。AI 输出的政策准确性仍需人工核实；合成验证不代表真实政策已获确认。

HTML Creator Studio 1.8 为 Development Candidate。本版适配只开放指定规范和受控布局，不宣称完整支持上游任意工具链、个人审美档案或 Remotion/HyperFrames。
