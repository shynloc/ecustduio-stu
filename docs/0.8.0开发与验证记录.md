# 0.8.0 开发与验证记录

本版继续完善 0.7.0 统一视觉项目，不另建互不相通的编辑器。

## 实现

- `shared/visual-edit.ts`：页面编辑契约、版式/动效枚举、来源和素材引用验证、配音句群分段。
- `server/visual-editor.ts`：未保存预览、单页/整套 AI 编辑、两个技能的实际读取、单页全局设计保护、幂等修订恢复。
- `server/visual-renderer.ts`、`visual-slides.ts`：共享网页/动图/视频渲染，原生 PPT 文字、步骤和表格；媒体对象单独保留。
- `server/visual-audio.ts`、`visual-music.ts`：真实配音缓存、变速、实际音频时间戳、停留、四种音乐上传解码与权限。
- `server/visual-web.ts`：复用原有公共 URL 校验和网页导入，将来源、原文、母稿、视觉项目串接；重试恢复检查点。
- `web/VisualWorkbench.tsx`、`VisualSceneEditor.tsx`、`VisualPreview.tsx`：页面操作、撤销重做、即时预览、AI 修改、时间轴、素材及成果播放。

旧视觉数据的新字段均为可选，默认值在读取时补齐。没有数据库结构迁移。原始母稿与旧视觉版本不可被本次编辑覆盖。私有任务和预览保留账号边界，业务员不能调用编辑接口。

GIF Factory 固定提交 bd6bc31a6e0bebe2be5f79838613bd8041052481，保留上游许可与来源记录。宿主适配器允许用户明确选择静止/不透明 GIF，并记录上游贴纸检查状态；没有篡改上游审计为人工视觉通过。

## 验证范围

1. 原有视觉和工作流回归12项通过，包括多格式导出、图像帧复用、模板入口、来源变化、确认记录和三类账号隔离。
2. 新增7项验证：不可变编辑修订与引用约束；预览不落业务版本、过期哈希与内网拒绝；真实 PPT 表格、PDF、序列/静止 GIF、音乐视频；双技能单页编辑；网页流程重试；真实 MP3/OGG/FLAC 解码；两套主题1440/390宽度下的编辑、预览、撤销和保存。
3. 针对后续 PDF 排版检查和时长修正，重新执行受影响的编辑及多格式导出用例。详见 `test-results/visual-editor-export-final.log`。其余新增用例见 `visual-editor-tests.log`，更早的完整新增用例通过记录保存在发布验收摘要。
4. 真实 DeepSeek 调用读取 HCS 与 GIF Factory，修改指定页并保留另一页和整体设计；真实 TTS、1.15倍语速、字幕及 H264/AAC 视频，产出 HTML/PPTX/PDF/GIF/MP4/WAV/SRT/ZIP。测试使用隔离的合成材料，不更改生产业务记录。测试结束删除临时凭据副本。
5. TypeScript 检查与生产构建；Windows 本机部署前备份，并比较账号、资料、笔记、项目、设置、成果资产及凭据的摘要。

真实模型测试视频约6.10秒。字幕为实际音频分段/句群级时间，不宣称逐字对齐；未将文件检查描述为人工听感验收。截图检查覆盖书院与曜石的桌面/手机视口。

## 限制

外部网页导入的是正文和来源，并非任意网站的无损样式克隆。PPT 的文字、表格及基础图形可编辑，图片仍为图片。复杂角色姿态生成、三维动画和真实书写笔顺不在本版现有素材动效能力中。

Mac 安装包包含相同应用代码、Mac 安装升级与自检工具；本轮未在 Mac 实机运行。Windows 和 Mac 的文件包不含数据、账号和凭据，在线升级继续使用原有签名更新协议。
