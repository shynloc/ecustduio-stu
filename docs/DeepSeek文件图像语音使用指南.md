# EcuStudio 0.4.0 · 文件、图像与语音

更新日期：2026-11-14。Windows 和 Mac 安装包使用同一套功能与账号权限。管理员先在「设置 → DeepSeek Agent」保存凭据、允许调用并测试连接；成员共用服务器配置，无需各自在电脑安装 AI 或音频工具。

## 统一入口

左侧新增「文件与语音」，也可从「素材与知识」「导入资料」或「AI 探索」进入。选择处理方式、上传文件并填写要求，点击「发送至 DeepSeek 并处理」。上传到工作台本身不会触发付费接口。

| 处理方式 | 输入与作用 |
| --- | --- |
| 文档解析 | PDF、Word、PPT、Excel、TXT、MD、CSV、JSON；由 Flash 阅读文件，按要求提取信息、比较或整理内容。可选文字模式或结合图表版面。它是 AI 整理结果，不保证逐字覆盖全文。 |
| 云端文字识别 | 图片、扫描 PDF、Word/PPT；逐页输出文字，保留可下载的原始页码与坐标记录。全文识别优先选这一项。 |
| 图像理解 | PNG、JPEG、WebP、GIF；读取截图、图表和画面，区分可见信息与推断。动态图仅处理首帧。 |
| 录音转文字 | 上传 MP3、M4A、WAV 等浏览器支持的录音，或在允许的环境直接录音；在浏览器转为单声道 PCM WAV，服务器自动分段识别。 |
| 文字配音 | 自填文字，或从已保存内容版本、创作笔记、AI 回答进入；海星女声、暗潮男声，可试听并下载 WAV。 |

所有上传文件最大 50 MB，文本文件最大 32 MB，单图最多 4000 万像素。当前文件/图像理解固定使用支持对应能力的 Flash，全局其他创作任务的模型选择不变。接口能力或额度不足时直接显示错误，不自动改用另一项收费服务。

## 从识别到创作

1. 任务结束后，对照「查看原始文件」校正文字、日期、专名和图表数字。
2. 「存入创作笔记」保留校正文本与处理来源；「带入 AI 探索」先存笔记，再自动选择为下一轮上下文。普通笔记仍可反向载入创作。
3. 展开「导入共享素材，继续事实提取与内容制作」，填写地区、年度、学段和读者。
4. 「导入素材并核验」打开资料页；「导入并开始制作」自动选择这份资料和适用范围，进入政策研究模板，可开始候选事实 → 母稿 → 内容 → 文件，也可返回素材与知识选择口播、公众号、PPT等模板。
5. 内容版本保存后，版本导出栏新增「生成配音」。未保存修改时先保存版本；配音任务固定使用启动时服务器保存的文本，来源版本可追溯。
6. 配音结果可在「文件与语音 → 最近处理」再次试听或下载。AI合成音频保持研究草稿，不代表事实核验或发布审核通过。

文件处理和原始上传按账号隔离，管理员可管理全部。**主动导入共享素材后，原文件与校正文本对工作台成员共享**；业务员可查看共享政策资料，不能访问私有处理任务、笔记或执行 AI。导入的 AI 整理内容始终标为待核实，不能替代官方原文证据。

## 录音与配音边界

- 单次录音最长20分钟；自动按110秒切分，符合官方单次120秒、8MiB限制。失败重试保留已识别片段，不重复发送已完成段。
- 显示的是分段时间范围，不是逐字字幕时间戳。语音识别未识别到有效内容时会失败提示，不产生假文字。
- 局域网 HTTP 通常不能打开麦克风，仍可上传已有录音。本机或 HTTPS 可由浏览器征得麦克风权限后录音；Mac/Safari录音和具体设备格式仍需本机验证。
- 每次配音最多10000计费字符，汉字按2个计算，约5000汉字。超限时缩短或分段生成。支持两种官方音色，不提供声纹克隆、调速或视频成片。
- 从分镜或其他长文进入配音时，正文可能包含画面描述。可点击「改为自填文字」，仅保留需要朗读的内容再生成。
- 取消会停止工作台后续操作，已经发送到云端的部分仍可能计费。音频传输中断、接口错误或不完整识别不会作为完整结果保存。

## 数据、费用与故障恢复

文件解析使用官方 Files API，远端副本设为1小时有效；无论分析成功还是失败，工作台都会尝试删除本次创建的副本。删除未确认时显示提示，由到期机制兜底。其他接口的服务端数据规则以 DeepSeek 官方说明为准。

识别与配音会使用管理员配置的同一凭据。用量缺失时显示“未返回”，不推算金额，以官方账单为准。失败可在处理页重试未完成部分；新建任务、修改输入或未拿到结果的网络失败可能再次计费。

保留本机 OCR：原「导入资料 → 上传文件」仍可使用 Windows OCR / Apple Vision，适合不希望上传云端的识别；本页「云端文字识别」使用 DeepSeek，需要联网与调用授权。

## 开发与安装说明

- `server/media.ts`：输入冻结、五类任务执行、结果转笔记/素材、音频范围下载。
- `server/media-provider.ts`：官方文件/识别/语音请求，限制端点、不跟随重定向，凭据仅在服务器进程使用。
- `server/wav.ts`：PCM格式/完整性验证、分段与音频规范化。
- `server/media-access.ts`、`migrations/003_media.sql`：媒体任务和资产归属，兼容既有资料权限，升级自动迁移。
- `web/MediaStudio.tsx`、`web/audio.ts`：统一处理入口、进度、校正、来源、试听、浏览器音频转换；两套主题与窄屏布局。
- 继承既有任务超时、取消、检查点、审计、来源核验、账号和发布权限。任务结果不返回模型思考原文或凭据。

联网安装包包含源码、已构建程序、安装脚本、PRD/开发文档和指南；首次安装联网下载 Node、生产依赖和 PDF 浏览器。升级指定原安装目录，保留data，先做备份。Mac目标macOS14+，Apple Silicon/Intel自动选依赖；当前开发环境为Windows，Mac钥匙串、Vision和登录自启须在Mac本机自检。
