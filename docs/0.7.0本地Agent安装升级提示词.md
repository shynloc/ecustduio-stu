# 交给本地 Agent 的安装/升级提示词

把下面文本与下载的 ZIP 路径一起交给本地 Agent：

> 请在本机安装或原位升级 EcuStudio 教创工作台到 0.7.0。安装包路径：`<填写 ZIP 完整路径>`；已有安装目录：`<填写原目录，不知道则先查找标准安装目录>`。
>
> 请直接完成操作和启动。先确认系统、架构、包内 manifest 版本，并阅读包内「0.7.0发布与升级说明」「先读我.html」和原平台使用指南。完整解压到原安装目录之外；不要覆盖或删除 data，不重建已有账号，不重置 DeepSeek 配置，不上传数据库、日志中的敏感信息或密钥。
>
> 若已有 0.5.0/0.6.0 且服务可访问，优先引导管理员从「设置 → 工作台更新」升级。使用下载包时，Windows 运行「一键升级.cmd」，Mac 在原系统用户下运行 `bash "/解压目录/Upgrade.command"`，选择原安装目录；新安装使用 Windows「一键安装.cmd」或 Mac「Install.command」。Mac 不使用 sudo，不关闭系统安全功能。若系统弹出标准授权对话框，说明原因并由用户处理。
>
> 安装器会准备 Node、生产依赖和浏览器，升级会备份并校验原记录。发现现有任务正在运行时先等待或由用户停止任务，不强行杀死制作进程。保留原目录、原系统用户和原钥匙串/DPAPI 配置。
>
> 动图需要 Python 3.10+。检测是否已有可用 Python；缺失时通过操作系统标准渠道准备 Python，再用安装目录中 `app/scripts/setup-gif-runtime.mjs` 配合本工作台 Node 建立独立 Pillow 环境，或由管理员点击视觉制作页的「安装动图依赖」。不要改动系统 Python 包。网页、PPT 和视频可以先启动使用。
>
> 完成后检查实际实例的 `/health` 返回 0.7.0，核对原管理员可登录、原资料和 DeepSeek 配置仍在，给我本机与局域网访问地址、安装路径、日志和备份位置。只做必要的本机检查，不自动消耗 DeepSeek 额度，不自动发布业务内容。失败时用包内恢复入口处理，保留备份和错误信息；未做的验证要如实说明。
