# EcuStudio 教创工作台 0.8.0 升级说明

本版完成统一视觉编辑流程：逐页编辑、AI 修改单页或整套内容、九种版式、步骤与表格、独立配音稿、更多 GIF 动效、时间轴、语速、字幕、转场和背景音乐。公开网页正文可直接成为创作项目。

HTML、原生可编辑 PPT、演示 PDF、GIF 与带配音 MP4 共用同一视觉项目。保存修改会建立新修订，旧内容与成果保留。

## 已安装 0.5.0 及以上

1. 由管理员登录工作台。
2. 打开「设置 → 检查更新」，确认显示 0.8.0。
3. 点击升级，等待下载、备份、更新和服务重启，期间不要关闭服务端电脑。
4. 页面恢复后刷新，进入创作项目打开「视觉制作」。原有账号继续登录，资料与 DeepSeek 配置继续使用。

升级保留账号、权限、资料、笔记、项目、生成成果及 DeepSeek 配置。更新器会先备份；不要删除原安装目录或重新创建账号。

## Windows 手动安装或升级

[下载 Windows 0.8.0 安装升级包](https://dshdisk.acks.com.cn/ecustudio/0.8.0/EcuStudio-0.8.0-Windows-x64-UpgradeReady.zip)

- 新用户：完整解压，双击「一键安装.cmd」，首次安装联网准备运行环境；在浏览器创建管理员。
- 老用户：将新包解压到原安装目录之外的新文件夹，双击「一键升级.cmd」，选择或确认原安装目录，等待自动备份、更新和启动。
- 请使用原 Windows 登录用户，原账号与 DPAPI 加密的 DeepSeek 凭证会保留。不要手动覆盖 `data`。

## Mac 手动安装或升级

[下载 macOS 0.8.0 安装升级包](https://dshdisk.acks.com.cn/ecustudio/0.8.0/EcuStudio-0.8.0-macOS-UpgradeReady.zip)

- 支持目标为 macOS 14+，Apple Silicon 与 Intel。
- 新用户：完整解压，运行 `Install.command`；也可在终端进入解压目录后执行 `bash Install.command`。
- 老用户：解压到原安装目录之外的新文件夹，运行 `Upgrade.command`，按提示确认原安装位置。
- 默认安装位置为 `~/Library/Application Support/EcuStudio`。使用原 Mac 登录用户，不使用 sudo；保留原数据目录与钥匙串中的 DeepSeek 配置。
- 本轮在 Windows 上完成功能实测与 Mac 包检查，没有 Mac 实机验收记录。包内提供 `Check.command` 与原生自检工具。

## 使用提醒

视觉编辑入口在「创作项目 → 视觉制作」。先编辑和保存新修订，再生成成果。单页 AI 修改不会改变其他页面和全局设计。

GIF 需要 Python 3 与 Pillow，可由管理员安装独立动图依赖。安装包为联网安装版，未包含每个平台的完整运行环境，也不包含业务数据、账号或密钥。

详见随包《0.8.0视觉创作使用指南》和《0.8.0本地Agent安装升级提示词》。
