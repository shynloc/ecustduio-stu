# EcuStudio 0.10.0：从笔记到公众号草稿

这次把知识库、公众号排版、手机预览和微信草稿箱连在一起。管理员连接一次，创作者只需要：**选笔记 → 看预览 → 保存草稿**。

## 老用户升级：优先在页面里完成

1. 在原来的工作台，用管理员账号登录。等正在运行的任务结束。
2. 打开「设置 → 工作台更新」，点击「检查更新」。
3. 点击「一键升级至 0.10.0」，等待工作台自动重启并重新连接。
4. 确认页面显示 0.10.0，原账号能登录，资料和笔记仍在，DeepSeek 显示已配置。

**原账号、密码、资料、笔记、历史成果和 DeepSeek 配置都会保留。**升级前会创建本机备份。不要卸载旧版，不要删除 data 文件夹，不需要重新创建账号或重新填写 DeepSeek 密钥。新功能的公众号连接需要首次配置，与 DeepSeek 配置相互独立。

0.5.0 及以上支持设置页升级。更早版本或无法在线升级，可用下面的安装包方式。

### Windows

把新 ZIP 完整解压到原安装目录之外的新文件夹，运行「一键升级.cmd」，选择原安装目录，按提示完成。升级成功后继续使用原来的启动入口和账号。新用户运行「一键安装.cmd」。

### Mac

使用原来的 Mac 系统登录用户，把新 ZIP 解压到原安装目录之外，运行「Upgrade.command」。默认旧目录是 `~/Library/Application Support/EcuStudio`。如果双击不便，可在终端进入解压目录后运行 `bash Upgrade.command`。不要使用 sudo，不要移动原 data 或重新创建钥匙串配置。新用户运行「Install.command」。

遇到「旧服务仍在运行」时，使用新包中的「Repair-Upgrade.command」，保留原目录和备份。Mac 包面向 macOS 14+，支持 Apple Silicon 和 Intel；本轮没有 Mac 实机，原生钥匙串、启动服务与升级仍需在实际 Mac 上检查。

## 管理员第一次连接公众号

1. 打开工作台「设置 → 连接公众号」，也可以从「公众号排版」点击「连接公众号」。
2. 用公众号管理员身份登录[微信开发者平台](https://developers.weixin.qq.com/)，找到该公众号的开发信息，复制 AppID 和 AppSecret。
3. 在工作台填写公众号名称、编号和密钥，点击「连接并保存」。工作台会先检查草稿箱权限。
4. 如果提示 IP 白名单，按页面给出的公网地址，在微信开发者平台添加白名单，再点连接。如果提示权限不足，在微信后台确认公众号拥有草稿箱和素材管理接口权限。

连接信息加密保存在运行工作台的电脑：Windows 使用本机加密，Mac 使用当前用户的系统钥匙串。密钥不回显给创作者，也不包含在安装包里。不要把密钥发到聊天中。

本版是公众号官方接口连接，需要账号本身具备接口权限。它不是第三方平台扫码授权；没有开通接口权限的账号仍可下载排版，手动使用微信编辑器。

## 创作者日常使用

1. 在「知识库与笔记」整理正文和配图，点击「公众号排版」。也可以直接在公众号页面选择笔记。
2. 点击「生成手机排版」。默认自动准备封面和摘要，配图自动压缩转成微信可用格式。需要修改时展开「调整标题、封面和样式」。
3. 看右侧或手机下方预览，确认文章、封面、摘要和图片。
4. 点击「保存到『公众号名称』草稿箱」。看到「已保存到公众号草稿箱」后，可以打开微信公众号后台继续编辑。

**保存草稿不会发布或群发文章。**发布前仍需在微信后台确认。微信可能调整样式，应在微信后台再看一次最终显示。外部图片若未导入知识库，会在预览中标为「配图待上传」；先回到笔记添加图片再预览。

关闭页面后可从「最近的保存记录」继续查看。普通重试先核对微信结果，不会盲目新增草稿。只有核对微信后台确实没有这篇时，才使用「我已确认草稿箱没有这篇，重新保存」。已成功保存的草稿不会被工作台自动覆盖；编辑笔记后重新预览可以创建新草稿。

管理员管理连接；创作者处理自己的笔记和草稿；业务员不能操作公众号连接、排版或草稿。管理员也可以查看团队相关任务。工作台仍保留 HTML 下载和复制排版入口。

## 本轮验证边界

已完成接口协议、图片上传、自动封面、保存回执、断网恢复、幂等、权限隔离及桌面/手机浏览器验证。模拟服务测试不代表真实微信端保存成功。本轮开始时没有可用公众号凭据，现有公众号插件要求重新登录；真实公众号验收需管理员在本机完成连接后进行。公网安装包和旧版页面升级的最终结果见同目录 Acceptance.json。
