# EcuStudio 0.11.1：新主题与公众号排版

本版包含「晴空」浅色主题与新的书页/创作笔画 Logo，曜石主题仍可切换。公众号编辑器迁入 ACKS 全部 43 款主题、9 套配方，另保留 3 款原有主题，支持预览、搜索、收藏、最近使用和字号行距微调。修复自选封面重复插入，以及普通创作指令误选深色主题的问题。

## 老用户：在设置中一键升级

Windows 和 Mac 都用原管理员账号登录，进入 **设置 → 工作台更新 → 检查更新 → 一键升级至 0.11.1**。

等待正在执行的任务完成后开始升级。工作台会下载并校验安装包、自动备份、停止旧服务、安装并重新启动；页面会短暂断开，完成后自动恢复。

**原有账号和密码、资料、知识库、对话、作品、DeepSeek 配置和公众号连接会保留，无需重新录入。**请在原电脑、原安装目录、原系统用户下升级；不要删除 data 或重新初始化。Mac 不要使用 sudo，原钥匙串仍由原登录用户访问。

本次有新增排版依赖，升级过程需要联网下载。失败时保留原目录与页面显示的备份，按更新页的恢复提示操作。

## 下载地址与安装

- [Windows x64 安装/升级包](https://dshdisk.acks.com.cn/ecustudio/0.11.1/EcuStudio-0.11.1-Windows-x64-UpgradeReady.zip)
- [macOS 安装/升级包](https://dshdisk.acks.com.cn/ecustudio/0.11.1/EcuStudio-0.11.1-macOS-UpgradeReady.zip)：macOS 14+，Apple Silicon 和 Intel 自动识别。

新用户：完整解压后，Windows 双击「一键安装.cmd」；Mac 运行 Install.command，或在该文件夹终端执行 `bash Install.command`。

没有页面升级入口的旧用户：解压到原安装目录之外的新文件夹，Windows 运行「一键升级.cmd」，Mac 运行 `bash Upgrade.command`，选择已有安装。不要把解压文件直接覆盖到 data。

联网安装包首次运行自动安装运行环境，不附带任何人的账号、业务资料或 API Key。

## 公众号复制怎么用

打开公众号编辑器，点击文章主题，试选后点「应用排版」，再点「复制到公众号」。已经连接公众号时自动转存配图；未连接时按提示下载编号配图并在微信正文中插入。保存远端草稿仍需确认，不会自动发布。

本地排版、剪贴板和微信协议夹具已验证；真实公众号后台粘贴仍待已登录账号验收。设备字体、微信清洗及深色模式可能影响最终显示，发布前请在微信预览核对。

随包提供使用指南与本地 Agent 安装提示词。最终公网下载与升级结果见 [发布验收记录](https://dshdisk.acks.com.cn/ecustudio/0.11.1/EcuStudio-0.11.1-Acceptance.json)。
