# EcuStudio 0.11.2 使用指南

## 把网页做成可以打开的文件

1. 打开 **AI 创作对话**，选择需要的资料或笔记。
2. 例如输入“把选中的资料做成可下载的互动网页，分栏目展示，点击标题能切换”。
3. 等待任务完成。内容较长时，工作台会在预算内自动接着写。
4. 在回答下方打开 HTML 附件预览，试点页面中的按钮，或点下载，用浏览器打开保存的 .html 文件。

## 给长任务更多空间

管理员进入 **设置 → DeepSeek Agent → 高级设置**，可选 **使用长任务推荐值**，再点 **保存生成设置**。刷新后可查看已保存的数值。旧安装会保留原值，升级后可按需调整。

新安装默认每次最多输出 32,768 token，每项任务最多请求 12 次，最长运行 20 分钟。请求次数、输入空间、时限和模型实际支持的额度共同决定能完成多长的网页。

## 安装与升级

用原管理员账号进入 **设置 → 工作台更新 → 检查更新 → 一键升级至 0.11.2**。更新后继续使用原账号、资料与 DeepSeek 配置。
