# EcuStudio 0.11.0：从资料到作品，一处完成

本版围绕普通职员的实际操作重新整理界面。原始资料、知识库、AI 创作对话、创作项目和成果库连成一条工作流程。

## 主要变化

- 登录后进入可交互的 3D 工作台，直接输入目标、添加文件或选择知识。可继续上次任务，动效可暂停；书院仍为默认主题，曜石保留。
- 正文编辑统一为所见即所得和图标工具栏。文字导入、笔记、识别结果、项目基础稿及公众号文章直接显示排版；源码放在高级入口。
- 知识库和成果库统一提供卡片/列表、文件夹、标签计数、搜索筛选、多选、批量整理、归档、回收站与撤销。
- 对话历史可搜索、分类、收藏、归档和续聊。可搜索并多选旧知识及原始资料，加入附件或网址。草稿、上下文及阅读位置按账号保存。
- 回答支持流式显示，显示执行过程和实际 token 用量；上下文空间显示估算。网络中断后读取同一任务，避免因刷新重复请求。
- 创作入口按成品命名，包括网页、网页转视频、PPT、文档、公众号、GIF 和配音视频。项目分为「资料、写稿、作品」，基础稿连续编辑，来源、锁定段落和历史版本保留。
- 资料读取、文件识别、资料更新、订阅与日报补充步骤、进度和下一步引导。未知工作量显示阶段，不显示虚构百分比。
- 修复网页视频缺少独立 Chromium 时无法复用 Windows Edge，以及编辑器初始化触发无意保存等问题。

## 旧用户：优先在页面里升级

Windows 和 Mac 的管理员都可打开「设置 → 工作台更新 → 检查更新 → 一键升级至 0.11.0」。等待正在运行的任务完成，再开始升级。升级期间页面会短暂断开，成功后自动恢复。

升级器校验签名和安装包，备份数据库，停止旧服务，安装并检查新版本。原有账号及密码、资料、笔记、对话、作品和 DeepSeek 配置保留。新增分类使用兼容迁移，不要求重新建账号或重新导入资料。

这是原机、原安装目录、原系统用户的升级。不要删除 data，不要把密钥文件从 Windows 复制到 Mac；不同电脑迁移不是原机升级。

## 下载与手动升级

- [Windows x64 安装及升级包](https://dshdisk.acks.com.cn/ecustudio/0.11.0/EcuStudio-0.11.0-Windows-x64-UpgradeReady.zip)
- [macOS 安装及升级包](https://dshdisk.acks.com.cn/ecustudio/0.11.0/EcuStudio-0.11.0-macOS-UpgradeReady.zip)

Windows：完整解压到原安装目录以外的新文件夹，双击「一键升级.cmd」，按提示选择原安装。新用户双击「一键安装.cmd」。

Mac：完整解压到原安装目录以外的新文件夹，用原 Mac 登录用户运行 Upgrade.command；也可在终端进入该文件夹后执行 bash Upgrade.command。新用户运行 Install.command。不要使用 sudo。适用于 macOS 14+，Apple Silicon 和 Intel，安装时自动识别。

首次安装及依赖变化的升级需要联网下载 Node、依赖和浏览器。因此压缩包不包含完整运行环境，也不包含任何人的业务数据或密钥。若更新失败，保留原目录和页面显示的备份路径；先重新打开原工作台，不要删除 data 或反复初始化。
