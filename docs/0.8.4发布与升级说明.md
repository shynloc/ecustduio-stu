# EcuStudio 教创工作台 0.8.4

2026-11-17 · 资料识别、任务执行与创作体验整改第一批。

## 这次解决什么

- 一句话任务管家：必需技能由工作台预装，修复思考模式与强制工具调用的冲突；没选材料时先检索相关资料，无相关资料会提示补充，不拿无关文件凑数。
- 文件识别：保存原文件校验值，支持 PDF 原页预览与识别结果对照。未核对的识别内容可存待复核笔记，进入创作素材前需对照原件确认。
- 长 PDF：文件与语音入口支持最多200MB、2000页；先按10页/20MB分片，遇超时或片段过大继续缩小，已完成片段保留，失败后只补做未完成片段。不能识别的页会明确显示，不能当成全文完成。
- 网页与公众号：兼容正文区域、懒加载配图和表格；调用授权开启后可使用联网读取后备与配图识别。验证页、失效链接仍需打开原文后粘贴文字或导入PDF/截图，不保证绕过平台限制。
- 默认排版阅读，编辑正文使用富文本；支持表格、图片、自动保存已存在的笔记、版本恢复、文件夹、标签和用途。旧Markdown笔记仍保留，含暂不支持结构的内容保留源文编辑。
- 导航分为输入、处理、输出。资料可存入知识库，笔记可带入对话、配音或创作；创作中心根据所选资料带入标题和范围，教学资料采用教学语境。PPT模板可同时输出可编辑PPTX和DOCX讲义。
- 新增公众号排版：选择笔记、选择风格、手机预览、复制图文或下载带图片的HTML。复制到公众号后需核对图片，暂不自动发布。
- 修复右侧输出格式与资料勾选项挤压；书院仍为默认主题，保留曜石。

## 已安装用户

管理员登录原工作台，进入 **设置 → 工作台更新 → 检查更新 → 一键升级至0.8.4**。先等待运行中的任务完成。升级会备份、替换程序并重启，原账号、资料、笔记和DeepSeek配置保留。新版本增加富文本依赖，更新过程中可能需要联网下载依赖。

若页面升级失败，保留原安装目录及data，不要创建新的管理员：

- Windows：将新版ZIP完整解压到原目录以外，运行“一键升级.cmd”，按提示选择原安装目录。
- macOS：将新版ZIP完整解压到原目录以外，以原Mac登录用户运行Upgrade.command；旧服务停止失败时使用Repair-Upgrade.command。不要使用sudo，不要删除钥匙串。默认原目录为`~/Library/Application Support/EcuStudio`。

## 推荐使用路径

1. **输入 → 资料输入**：上传文件、录音，导入网址，或从AI探索开始。
2. **处理 → 文件与语音**：处理后对照原页核对，编辑校正，再存入知识库。长文档显示完成页数和失败片段。
3. **处理 → 知识库与笔记**：阅读排版、编辑、分类；保存后可生成配音、载入AI对话、作为创作素材或公众号排版。
4. **输出 → 创作中心**：选择材料、目标和格式，Agent依次提取候选事实、生成母稿、内容和文件。确认资料后再正式使用或发布。

## 验证范围

Windows已进行真实DeepSeek Flash/V4 Pro的思考开关检查、带资料任务规划、12页扫描教学PDF自动分片识别，以及合成教学材料到可编辑PPTX、DOCX和HTML的流程。桌面1440、平板768、手机390及两套主题做了浏览器检查。

Mac安装包包含相同修复，但本轮没有Mac实机，Safari输入法、Apple Vision、钥匙串和原生升级仍待Mac本机验证。学生原PDF和失败公众号网址尚未取得，本轮使用合成样本和公开格式夹具验证机制，不能替代对原始故障样本的复测。

这不是整个长期整改计划的最终版：完整逐块证据索引、批量分类撤销、统一所有跨页上下文协议、可恢复上传及公众号远端草稿授权属于后续阶段。现有创作与成果引擎继续复用，旧链接和旧数据可继续使用。
