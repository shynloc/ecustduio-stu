# EcuStudio教创工作台

本机教育情报与内容创作应用。资料、核验、选题、母稿、内容版本、文件、日报和任务保存在本机 SQLite 数据库中。AI 使用 DeepSeek API，由工作台自己的有限工具 Agent 执行。

## 启动与停止

本机已安装依赖并完成构建。双击 `D:\EduStudio\Start-EcuStudio.cmd`，或在 PowerShell 中运行：

```powershell
& D:\EduStudio\Start-EcuStudio.ps1
```

访问 <http://127.0.0.1:37891>。脚本复用已运行的 EcuStudio，后台窗口隐藏，日志在 `D:\EduStudio\data\logs`。原拟端口 4317 被本机 Windows 保留，实际采用 37891。停止时双击 `Stop-EcuStudio.cmd`。

关闭浏览器不会停止后台；后台退出或电脑休眠后，定时任务不会执行。中断任务可在任务页重试，已提交结果保留。

另一台 Windows 电脑需要 Node.js 24.15 或更新的 24.x，以及可用于 PDF 渲染的 Edge 或 Playwright Chromium：

```powershell
Set-Location D:\EduStudio\app
npm ci
npm run build
npm start
```

`npm run dev` 启动 TypeScript 后端，前端仍使用 `dist`；修改前端后重新构建。不依赖开发助手、Codex 登录或 WorkBuddy 进程。

## DeepSeek 配置

首次打开先在页面创建管理员；之后登录进入工作台。管理员可在「账号管理」增建管理员、创作者和业务员账号，分配初始密码；新账号首次登录须改密。创作者可研究、对话、写笔记和创作，模型/来源/计划/备份等管理配置由管理员维护。业务员仅可查阅政策、日报和可发布成果。笔记与对话按账号隔离，管理员可管理全部；政策资料和创作项目为工作台共享内容。

1. 打开工作台「设置」，填写自己的 DeepSeek API Key 并保存。不要把密钥写入文档或发到聊天中。
2. 选择模型，也可输入账户支持的模型 ID。默认 `deepseek-flash`，备选 `deepseek-v4-pro`，以账户可用模型为准。
3. 在「调用授权」勾选「允许 DeepSeek 调用」，点击紧邻的「保存并测试连接」。无需再到顶部保存；此操作仅保存 DeepSeek 设置，不会提交监测或推送的改动。已保存时按钮显示「测试连接」。验证会产生一次很小的实际 API 请求。
4. 在资料详情运行 AI 研究；在项目中生成母稿、政策解读、口播、公众号、PPT、分镜，或选定内容块进行改写。

Windows 密钥使用当前用户的 DPAPI 加密，不返回浏览器、不进入备份。也可通过 `DEEPSEEK_API_KEY` 环境变量配置，环境变量优先。启动脚本支持 `app/.env`，但它是明文，通常优先使用设置页。删除界面密钥不能删除进程环境变量。

未配置 DeepSeek 密钥时，真实生成不可用；录入后通过界面的连接测试验证。工具协议和失败处理使用隔离测试替身验证，生产任务没有假模型回退。没有调用现有 OpenAI 凭据。

## 使用路径

界面主题在「设置 → 界面主题」中选择。「书院 · Scholar」为默认，保留暖白墨绿界面；「曜石 · Obsidian」使用深海黑、冰青证据链与琥珀重点。选择后立即切换并自动保存，刷新和重启后保留；保存失败会恢复原主题。主题保存独立于其他配置，导出文件不随界面主题改变。

- **政策情报**：导入网址、原文、图片、文本/扫描 PDF、DOCX、MD/TXT/HTML；图片和扫描页自动本机 OCR，可校正预览后导入。保留原件、页码、原文快照及引用段落。校正范围后，相关事实需重新核验。
- **AI 探索**：选择本地、联网或混合检索，输入对话/搜索要求。DeepSeek Agent 检索共享资料和本人可访问笔记，联网使用官方 Search 接口，回答附实际来源；可继续追问并保存回答为创作笔记。
- **创作笔记**：手动记录或从回答保存，支持编辑、版本冲突保护、反向载入对话。选择「作为创作素材」可加入资料库、已有项目或新建项目；保存固定版本，仍需事实核验。
- **事实与选题**：手动创建或 AI 提出候选，核对原文并填写依据。支持五维评分、收藏、搁置、备注、生命周期，以及地区、区县、学段、年度、来源筛选。
- **创作项目**：建立母稿，再生成不同格式的内容；自动保存工作草稿，提交时创建不可变版本。支持锁定块、局部补丁、版本对比和并发冲突保护。
- **审核导出**：研究草稿允许导出。可发布模式要求事实核实、范围一致、数字检查通过、当前版本确认且依赖未变。实际生成 MD、HTML、PDF、DOCX、PPTX、JSON、CSV。PPT 的其他格式是讲义，不是幻灯片保真转换。
- **项目交付**：选择成果生成 ZIP，附版本及哈希清单。原文文本默认排除，明确勾选后才加入。
- **任务与自动化**：显示真实阶段、工具事件、错误与调用量；支持取消、重试和自定义监测窗口。每日计划默认暂停，可设北京时间 09:00 启动。
- **日报与钉钉**：日报版本固定，无可靠推荐时保留零条。钉钉独立配置和预览，确认目标后才发送；本次没有真实发送。
- **备份恢复**：设置页创建备份、下载、上传校验并确认恢复；恢复前自动备份当前数据，恢复后暂停调度和自动发送。

## 工程与数据

| 路径 | 内容 |
|---|---|
| `server` | API、SQLite、Agent、采集、任务、导出、备份和凭据 |
| `web` | React 中文响应式界面 |
| `shared/schema.ts` | 内容、范围、设置和输入 Schema |
| `skills/educontent-studio` | 本次新建的工作流及五类启动模板 |
| `migrations` | 数据库 SQL |
| `tests`、`scripts` | 隔离测试、真实来源验收和 Office/PDF 检查 |
| `../data` | 生产数据库、资产、备份、加密凭据、日志 |
| `../docs` | PRD、开发设计、验收计划和 DeepSeek 实施补充 |

不要删除 `data` 解决启动问题。已提供三角色账号登录，仍只监听本机，不开放局域网或互联网访问。备份包含账号密码哈希但不包含登录会话和模型凭证；恢复内容时保留当前账号身份，并要求重新登录。

## 验证

```powershell
npm run check
npm run build
npm test
npm run test:e2e
npm audit
```

自动化测试使用 `app/test-results` 下的隔离目录。真实 OCR 与 DeepSeek 验收另在工作台保留明确命名、标注来源的验收样例及项目。基础结论见 `docs/ACCEPTANCE_REPORT.md`；本次 OCR 增量验收见 `docs/OCR_ACCEPTANCE.md`。

AI 探索、笔记、账号增量见 `docs/EXPLORE_ACCOUNTS_ACCEPTANCE.md`。`scripts/live-explore-flow.ts` 使用隔离的数据副本执行真实模型和联网验收，自动暂停副本的定时采集与发送；不会在生产库创建测试账号。其他真实验收脚本需要通过当前进程的 `ECUSTUDIO_USERNAME`、`ECUSTUDIO_PASSWORD` 环境变量登录，请勿将密码写入代码或报告。

## 当前边界

OCR已使用Windows本机引擎接入。上传PNG、JPEG、WebP或扫描PDF后自动识别，支持文本/扫描混合PDF逐页处理；可以强制重新识别、校正预览、从任务页恢复结果，再导入资料。保留原文件、页码、原始OCR记录及校正标记，事实仍需核验。单次OCR最多30页、普通上传最多50MB、图片最多4000万像素；加密PDF需先解密。OCR引擎依赖Windows OCR语言包，本机已验证zh-Hans-CN；没有伪造置信度。

语音、图片和视频生成没有接入；分镜输出为文字方案与提示词。公众号排版复制尚未在公众号编辑器做实际粘贴验收。PPT采用固定深蓝白模板；语义去重、自动冲突判定、跨日报语义差异、政策生效失效与替代关系仍需增强。

调度位于应用后台，没有创建 Windows 计划任务或登录自启动。单个来源每轮最多处理15条候选，自动 AI 分析前5份，超出时显示覆盖提示。费用未由接口返回时显示未知。长讲座建议按主题分批生成。

官方资料：[DeepSeek 接口](https://api-docs.deepseek.com/)、[工具调用](https://api-docs.deepseek.com/guides/tool_calls/)、[Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)。
