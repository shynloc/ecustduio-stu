# 0.8.1 开发与验证记录

## 本次变更

- WorkflowPlan新增并传递slideCount，任务计划界面可编辑页数，执行器取消固定8页。
- AI视觉编辑归一化步骤/比较版式的items；兼容模型写入table.rows的条目，无可见条目时取消无效逐项动效，并在导出前检查。

- 本次不新增数据库迁移，不更换更新源或签名公钥，不修改凭据存储机制。

## 实际创作验证

2026年11月15日使用工作台已导入的正式通知，调用已配置的DeepSeek，完成计划、10条候选事实、母稿、来源预审、视觉编排与多格式导出。生成5页响应式网页、5页原生可编辑PPT、PDF、512×512的3秒循环GIF，以及79.60秒带AI配音和字幕的MP4。

桌面与390像素手机网页检查通过。本机Microsoft PowerPoint实际打开5页，41个原生文本对象与1个原生表格；视频完整解码通过并检查每页抽帧；GIF确认具有不同视觉帧。配音做技术检查，未进行逐字听审或强制对齐。保留来源与研究草稿状态。

针对计划页数及AI步骤字段的回归测试通过，TypeScript检查及生产构建通过。真实业务资料、样片、数据库和密钥不进入软件安装包。
