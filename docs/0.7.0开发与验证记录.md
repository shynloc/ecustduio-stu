# EcuStudio 0.7.0 开发与验证记录

日期：2026-11-15。开发目录：D:\EduStudio\app。本文记录本机实现，不代表已向在线更新源发布。

## 实现

共享结构位于 `shared/visual.ts`，包括冻结正文、可定位场景、事实引用、来源快照、设计、资产和版本。长段落按标点分页，保留每个字符与引用。设计修订创建新的 `visual_drafts` 行，原稿、旧设计与已下载文件不变；复用现有表，不需要新增数据库迁移。

- `server/visual-studio.ts`：HCS 结构化设计、配图访问校验、受保护的网页预览、创建/修订/导出路由。
- `server/visual-document.ts`：宿主编写的响应式网页、演示与可寻址帧。拒绝外部资源与模型任意代码；解码 GIF 后等待指定图片帧就绪，再截图。
- `server/visual-presentation.ts`：原生 PPT 文字与图形、配图、备注；显式快照模式。
- `server/visual-export.ts`：GIF、PPT、PDF、真实配音与 MP4、WAV、SRT、ZIP。审批绑定内容/设计哈希、用户和输出参数；来源变更后拒绝继续生成旧依据成果。
- `server/visual-runtime.ts`：隐藏子进程、超时、取消、独立 Python 发现、浏览器与 FFmpeg。
- `server/workflows.ts`、`server/production.ts`：任务管家与素材模板使用同一个视觉母版。
- `web/UnifiedVisualStudio.tsx`：同一页面内预览、修改设计、选输出、查看成果、复用 GIF。

GIF Factory 固定提交为 `bd6bc31a6e0bebe2be5f79838613bd8041052481`。`skills/gif-factory/provenance.json` 保存来源与文件校验；保留上游许可证。实际调用上游 `export_keyframes.save_and_verify` 和 `review_gif.audit`，不是仅复制提示词。模型使用受控 `read_skill` 获取方法，宿主限制 JSON、文件路径与执行器。技术检查通过与人工视觉认可分开记录。

配音通过现有 DeepSeek TTS 接口，每个场景单独合成，转换为 16 kHz 单声道 PCM，按真实采样数计算时长并留 250 ms 间隔。缓存键包含账户、台词和声音。字幕为场景级；MP4 不会在配音失败时偷偷退为无声成片。单次最多 40 个配音场景、10000 计费字符和 10 分钟实际音频。

GIF/PNG 子步骤包含场景稳定 ID，避免同一任务中的第二张动图误用第一张。已成功的输出和配音在重试时复用。私有导出、截图、配音与预览延续媒体账户权限；管理员可管理，业务员不可进入制作。
