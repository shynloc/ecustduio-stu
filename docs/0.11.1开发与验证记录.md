# EcuStudio 0.11.1 开发与验证记录

本版纳入晴空浅色主题、新 Logo、公众号完整主题目录与复制流程。详细实现见《公众号主题选择器与复制-2026-11-19.md》和 HANDOFF。主题与排版选项保存在既有 JSON 字段中，无新的数据库迁移。

已完成的产品检查：46 款模板与 9 套配方内容保留、安全样式、PNG 装饰、预览/取消/应用、收藏/最近使用、复制三种浏览器能力、图片转存和草稿恢复。桌面 1440px 与手机 390px，两套工作台主题通过；手机为浏览器视口。

发布准备修复普通“写公众号文章”指令误匹配新增深色主题：仅在明确主题/风格/排版指令中识别主题名称，同一系列按用户指定的明暗选择。新增对应回归断言。

安装包使用锁定依赖，包含完整主题资源、MIT 许可证和更新运行器，不包含账号、数据库、API Key、签名私钥或 node_modules。Mac 包保留 command/sh 可执行权限，运行时下载本平台依赖。

最终检查记录在文件站同版本 Acceptance.json：安装包清单与 SHA-256、旧客户端签名兼容、原发布 0.11.0 的设置页升级、原账号/笔记/文件/配置/加密测试凭据保留。包内本文件为签名前记录，公网结果在完成后补记，不提前声明通过。

验收边界：真实公众号后台粘贴仍待登录账号；Mac CI 不能替代实际用户会话的钥匙串授权、Vision OCR、Safari 与 LaunchAgent 验收。升级使用原系统账户和原安装目录，避免改变凭据访问条件。
