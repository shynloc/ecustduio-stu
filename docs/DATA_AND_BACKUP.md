# 数据与备份

生产目录 `D:\EduStudio\data`。数据库为 `app.sqlite`；assets 保存内容寻址文件，backups 保存ZIP，skill-snapshots保存工作流，logs保存启动日志，staging保存导出和恢复暂存。

备份通过 SQLite 在线备份API获取一致数据库，再按其中的资产表收集文件。每份文件记录长度与 SHA-256；密钥与环境变量排除。恢复前限制路径与ZIP规模，校验文件哈希、外键、数据库完整性及引用资产。

设置页上传并预览备份后，由用户确认恢复。替换前生成当前数据安全备份；失败尝试恢复原数据库并保留安全备份。恢复后关闭调度和自动发送，中断未结束的任务；发送结果未知的消息需手工核查。

迁移使用工作台备份/恢复；不要在后台运行时仅复制 app.sqlite 而忽略 WAL。新Windows用户不能使用旧用户的DPAPI密钥，需要重新配置。

当前不自动清理历史、暂存和备份。不要直接删改数据库、资产或凭据文件。测试目录与生产数据隔离。
