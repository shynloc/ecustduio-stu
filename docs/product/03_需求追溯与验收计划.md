## 4 测试环境与证据规范

准备两套隔离数据目录：回归环境使用明确标记的合成政策、假模型与发送替身；真实验收环境使用公开或脱敏资料及已授权服务。合成材料不得出现在真实今日推荐或正式日报中。

每项记录：caseId、需求 ID、代码提交/版本、OS/依赖版本、数据目录、输入或 fixture hash、Skill/模型/规则版本、操作步骤、预期、实际、状态、jobId、结果版本 ID、artifactId、截图/文件证据、错误与复测记录。证据存应用工程测试目录，避免日志包含密钥。通过率只统计实际执行用例，未测项单列。

状态：通过、失败、未执行、待条件验证、不适用。待条件验证必须写明缺什么、谁能补充、补齐后怎样验证；不允许自动计为通过。不适用只能用于明确排除的环境或增强项，不可用于回避核心功能。

真实采集抽查最多 5 条，少于 5 条全部核对；没有可用结果如实记录，不能补造。可用标明年份的历史官方材料验证链路，但不得算作当天新闻。政策链接只作为待访问线索，本套文档未核验任何具体招生政策。

| A05 去重与修订 | 重采同文，随后同 URL 改正文再采 | 同文无重复新增；新快照保留差异；旧日报未变化 | 快照计数、前后 hash、日报版本 |

| A07 Skill 实接 | 导入/构建 Skill，探测并运行真实研究任务 | 来源、版本、hash、执行方式、真实事件、产物可查 | manifest、probe/run ID、工具与结果记录 |
| A08 多成果闭环 | 同一确认母稿生成 90 秒口播、公众号、PPTX、分镜 | 所有成果绑定同版母稿，关键事实一致；PPT 可编辑且有备注 | 内容版本、文件、事实核对表、预览 |
| A09 精确修改 | 人工修改一段；再只改第 5 页标题；之后更新母稿 | 未指定块不变，人工内容保留；受影响成果待复核，旧文件保留 | 补丁、差异、块 hash、过期关系 |
| A10 实际文件 | 同一项目/日报导出 MD、HTML、PDF、DOCX、PPTX | 文件真实可打开；中文、引用、结构与可编辑性正确；渲染逐页检查 | 文件 hash、结构校验、全部页预览记录 |
| A11 长任务恢复 | 运行中刷新、断 SSE、取消、杀 worker 后恢复、重复重试 | 状态真实，安全检查点可恢复，无重复版本或副作用，取消有边界 | 状态与事件序列、attempt、结果唯一性 |
| A12 每日流程 | 可控时钟跨 09:00，双调度进程，24h 内/外漏跑，手动触发 | 时区正确，每时点仅领一次；只补最近一次；日报原子提交，显示真实时间 | occurrence、job、配置、日报与界面记录 |
| A13 钉钉独立性 | 无授权发送、模拟失败、未知超时；获授权后指定群实测 | 未授权零发送；日报不回滚；消息同版；真实测试回执与群内结果对应 | 预览 hash、授权/目标、outbox、回执/群核对 |
| A14 备份恢复 | 活跃写入中备份，临时目录恢复；另用损坏清单测试 | 一致数据库与引用资产齐全，hash 正确；损坏恢复拒绝且原数据不变 | manifest、完整性/外键报告、恢复前后 hash |
| A15 页面操作 | 1440px/390px 执行筛选、返回、编辑、引用、历史、设置、下载 | 操作有结果、筛选恢复、手机可用、键盘焦点可见，无假按钮 | E2E 轨迹、关键页面截图 |
| A16 条件缺失 | 断网、无模型、来源403、解析坏文件、无渲染器、空结果 | 正确区分待配置/受限/失败/无新增；手工流程可用，不误报成功 | 错误码、界面状态、降级产物与限制 |
| A17 输入边界 | 注入指令、危险 HTML、SSRF、ZIP 越界、假引用、恶意下载路径 | 不获得工具权限，不越界读写，不访问受限网络，不泄露密钥 | 拒绝日志、安全断言、服务仍可用证据 |
| A18 版本一致性 | 两标签编辑同版，导出期间修改内容，审核后变更依赖 | 409 冲突；导出固定版本；旧审核不继承；所有文件可追溯 | API 响应、exportManifest、版本/审核关系 |

A10 缺渲染条件时可记录结构子项通过，但视觉子项必须未验证，不能将整项无条件标通过。A07/A08 缺模型授权时，替身接口通过只算接口验证，真实链路仍待条件验证。A13 未获发送授权时只完成前置用例，不执行真实发群。

## 6 补充边界用例

| 编号 | 要点 | 预期 |
|---|---|---|
| B01 角色和分镜 | 保持身份声音，只改服装；指定未核实模型参数 | 角色身份不漂移、参考图可追溯；不虚构模型专属参数 |

| B03 审核门禁 | 直接调用 API 绕过按钮导出未审核/过期成果 | 正式模式拒绝，草稿模式加标识；同版确认才允许正式导出 |

| B08 预算与费用 | 触发调用数上限、重试、供应商不返回费用 | 总预算含重试；安全停止保留草稿；费用显示未知 |

## 7 发布验收门槛

完整 V1 需要 A01—A18 及适用补充用例有真实记录，关键事实错误、无授权外发、数据丢失、越界访问、静默覆盖、虚假文件和重复副作用均为阻断问题。不能以平均通过率掩盖阻断缺陷。

可把“基础功能可用”和“外部链路全部验收”分开汇报：前者允许缺凭据但完整展示限制；后者要求真实模型链路及获授权的通知验证。只提供 macOS 说明不能记为 macOS 实测通过。视觉未验证、来源不可访问和外部平台条件要在交付报告中具体列出。

## 8 文档与实现的接续

开发启动时先核实原 Skill 和工程环境，再把本套建议参数、ADR、表结构与接口转为版本化实现。变更需求时同时更新 PRD 的 R 编号、开发对应章节和本矩阵，不只改一个文件。新增测试不得替代原有核心验收。每次移交写清已实现、已实测、待条件验证、下一步和可复现入口。
