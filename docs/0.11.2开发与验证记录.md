# EcuStudio 0.11.2 开发与验证记录

设置校验与单独保存入口覆盖生成预算。两种对话引擎共用网页生成、续写与附件交付逻辑。浏览器预览隔离执行交互脚本，下载得到完整 HTML。此次发布沿用原有数据库与更新签名公钥。

真实 DeepSeek 验证将单次输出限制为 1,024 token。模型自动续写两次，最终输出总计 2,825 token；生成的 HTML 附件通过了预览与下载后点击切换测试。设置页保存 131,072 后刷新，数值一致。

自动回归见 tests/webpage-delivery.test.ts、tests/deepseek-upgrade.test.ts 和 tests/deepseek-settings.e2e.ts。发布时使用 scripts/verify-release-packages.mjs 核验下载包，使用 tests/online-update-release.e2e.mjs 从原版 Windows 安装包在浏览器内升级，核对账号、资料、已保存的模型设置和加密凭据。

## 发布验收

- 原版 Windows 0.11.1 从设置页触发升级并自动重新连接。三种账号继续使用原密码，笔记及原文件可读，10 项原 DeepSeek 设置逐项一致。加密凭据文件逐字节一致，原测试密钥仍能解密，自动备份存在。
- Windows、macOS Apple Silicon 及 macOS Intel 的构建和自动化检查通过。[运行记录](https://github.com/shynloc/ecustduio-stu/actions/runs/44565193417)
- 两个公开安装包均已下载并逐文件核对清单，Mac 安装脚本具有可执行权限。签名清单经 0.5.0、0.11.1 更新协议验证，并已发布到设置页使用的稳定通道。[发布验收记录](https://dshdisk.acks.com.cn/ecustudio/0.11.2/EcuStudio-0.11.2-Acceptance.json)
- 本机运行版本已更新，升级前后 37 张业务表及加密配置一致。Mac 系统用户登录会话中的整机一键升级未实测。
