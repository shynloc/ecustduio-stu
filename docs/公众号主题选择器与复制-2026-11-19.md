# 公众号排版：主题选择与复制

本次为 0.11.0 之后的源码和本机更新，纳入下一次正式发行。已发布的 0.11.0 安装包及其校验值保持原样。

## 普通用户怎样使用

1. 打开「公众号编辑器」，直接写稿，或从知识库的「公众号排版」进入。
2. 点击「文章主题」。先显示常用主题，点「查看全部主题」可以浏览 **46 款**：ACKS 的 43 款完整模板，加上原有的书院绿、教育蓝、简洁黑白。
3. 点击缩略图即可看当前文章的效果。可搜索名字，筛选浅色/深色、系列、收藏或最近使用。选中喜欢的主题后点「收藏」，下次仍能找到。
4. 想调整文章节奏，用「配方」选择教程步骤、观点评论、数据复盘等。用「微调」调整字号、行距、首行缩进与装饰。
5. 点「应用排版」才会自动保存到当前稿件；取消会保留原来的排版与正文。手机点「看文章效果」预览，再点「返回选主题」继续选择。
6. 点「复制到公众号」，到微信公众号后台的**正文区域**粘贴。标题与封面等公众号独立字段仍在后台按实际需求填写。

### 配图怎样处理

- **已经连接公众号：**复制前自动把正文图片和主题装饰上传到微信图片接口，复制使用微信图片地址。此操作不会新建草稿，也不会发布文章。管理员可在设置连接公众号，创作者使用已连接的账号。
- **尚未连接公众号：**文字和排版可以复制；图片位置会显示「请插入配图 01」等提示。点击「下载配图」，按编号在微信正文中插入，删除提示即可。也可先让管理员连接公众号，再重新复制。
- 「下载 HTML」保存带图片的离线排版文件，适合存档和预览。它不是公众号素材上传接口的替代品；浏览器直接粘贴内嵌图片未必能被微信保留。
- 如果浏览器仅支持纯文字复制，页面会明确提示；不把纯文字复制报告成图文复制成功。
- 「保存到公众号草稿箱」保留原先的账号确认、回执和重试逻辑，不会自动发布或群发。

## 开发接手

- `shared/wechat-theme-catalog.ts`：生成的元数据与配方；`shared/wechat-themes.ts`：含旧 ID 的统一目录。
- `server/wechat-theme-data.ts`：生成的全量主题 CSS、tokens 与 PNG；`server/wechat-theme-render.ts`：内联兼容排版。
- `server/wechat-copy.ts`：连接后的图片转存、短时缓存、未连接的编号配图 ZIP。
- `web/wechat/ThemePicker.tsx`：选择器；`web/wechat/wechat-studio.css`：桌面与移动布局。
- 收藏和最近使用按账户保存在 `workspace_preferences`。稿件的 `format` 保存在原有 JSON 内；无 schema 迁移，不涉及账号、业务资料或 DeepSeek 凭据。
- 后续更新上游：检查新版本后运行 `node scripts/import-wechat-theme-catalog.mjs /path/to/upstream`，再运行 `npx tsx scripts/build-wechat-theme-previews.ts` 生成缩略图。用户安装运行不需要这两个开发脚本。
- 复制的 HTTP 接口逐次检查 owner、role、revision 和当前公众号；传图期间修订变化会拒绝复制过时版本。普通素材仍检查访问权限，只有内置主题清单中的装饰享有内部资源访问。
