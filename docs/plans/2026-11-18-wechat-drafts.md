# 0.10.0 公众号草稿闭环

用户约束：面向普通人，管理员只连接一次；创作者主流程为选笔记、预览、保存草稿。默认自动摘要与封面，额外选项折叠。不把 AppID、素材 ID、任务参数放进创作者主界面。

1. 本机加密保存公众号凭据，固定微信官方 API；管理员管理连接，创作者只保存本人草稿，业务员无权操作。连接检测、地址白名单和权限不足使用可操作中文提示。直接连接需要管理员提供 AppID/AppSecret，不虚构扫码授权服务。
2. 预览冻结笔记修订、格式、摘要、封面及本地图片哈希。自动封面、本地图片压缩转码，远端只发送预览确认过的内容。旧笔记/旧任务保留。
3. 保存草稿使用既有持久任务队列。图片/封面成功后保存检查点；草稿发送前写入提交标记，超时、进程崩溃后进入待确认，不自动重复创建。保留 media_id 后只读取回执。使用精确内容、封面和摘要核对有限分页列表；无法确定时让用户打开微信后台检查，再明确允许重新尝试。
4. 成功回读草稿才显示已保存。失败保留本地预览；重复点击幂等。断开连接、身份撤销、换公众号、笔记变化需重新校验。没有自动发布/群发/删除远端文章的入口。
5. 浏览器桌面/手机、角色隔离、真实 HTTP 协议夹具、图片与断网恢复测试。真实公众号验收需本机配置凭据；若缺少凭据明确记录不把模拟结果称为真实保存成功。
6. 新迁移保留全部旧业务表/凭据；发布0.10.0双平台包，公网下载哈希检查、签名feed和原始0.9.0页面升级验收。Mac实机限制照实记录。
