# EcuStudio 0.6.0 实施设计

用户已授权开发、测试、Windows/Mac 打包及文件站发布；保留 0.5.0 的签名更新通道和原位升级机制。

## 交付与验收

1. 任务管家：自然语言目标 -> ACKS Skill 与本地资料检索 -> 可编辑任务计划 -> 共享事实/母稿 -> 多渠道内容与 ZIP。任务和计划按账号授权，续跑复用检查点。
2. 政策影响：自动发现同来源新旧快照，支持手选跨年对比；列出精确原文变化、受影响项目/版本及本人可访问笔记。AI 解释附可定位引文；修订建立新项目保留旧内容。
3. 来源预审：确定性引用/数字/范围/时效检查，补充模型逐块语义预审；不把 AI 判断写成事实已核实或人工审核通过。整包附预审和来源清单。
4. 技能：完整保留 ACKS 1.0.0 与 HCS 1.8 DC 原包。模型通过受限 read_skill 工具按需读取；不执行模型提供的 shell、脚本或任意文件路径。原始包摘要记录在技能清单。
5. HTML：HCS 根据具体文稿生成布局/CSS，使用绑定文案槽位防止设计阶段改写事实。工作台提供隔离预览、真实桌面/手机截图与下载；默认研究草稿。
6. 视频：用户核对具体文案与视觉版本后，按其哈希授权渲染；Chromium 帧预览 + FFmpeg 输出真实无声 MP4，并附时间轴/源文件。明确不冒充 Remotion 或 Hyperframes 验证。音频仍可通过既有配音入口制作。
7. 更新：只增加新表，不覆盖既有业务记录；0.5.0 原升级器可下载 0.6.0，新增视频依赖通过锁文件安装。签名私钥保留在原发布专用目录，包内不含账户、数据库、密钥、测试资料或缓存。

## 选择

沿用现有作业队列、版本模型、导出器和权限，增加受控任务编排；相比自由 shell Agent，更便于暂停、续跑和来源追踪。HTML 允许模型设计 DOM/CSS，程序负责文案绑定、脚本隔离与渲染，兼顾设计空间与工作台数据保护。图文视频由本地渲染组件提供，不增加新的云端视频凭证。

## 测试

针对权限、引文边界、版本保留、幂等续跑、HTML 隔离、ZIP 文件完备、视频实际编码和迁移做定向检查；使用真实 DeepSeek 完成代表性流程。实际运行原版 0.5.0 -> 0.6.0 在线升级验证账号、资料和凭据保留。Windows 实测；Mac 原生运行限制如实说明。
