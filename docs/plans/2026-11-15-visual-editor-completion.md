# 视觉制作功能完善

用户明确要求继续完善功能，不以打包发布代替开发。基于已认可的共享项目方案继续实施。

1. 逐页编辑：顺序、新增、复制、删除、标题正文、讲者备注、配音稿、页面布局、配图和动效；保留原始内容和来源，保存为新修订。
2. 实时预览：未保存编辑可预览，网页/手机/演示共用受控渲染；视频时间轴可播放和定位，生成后可直接试听/播放成果。
3. AI 编辑：自然语言修改当前页或整套场景；读取真实 HCS/GIF Factory 技能，生成受约束的数据，保留人工编辑、来源和版本权限。
4. 动态素材：标题揭示、逐项步骤、图片平移、序列帧等动效；可手动选动作和循环时长，不再每次必须让模型选三种编号动作。
5. PPT：页面版式、图片、步骤、对比、表格和备注与共享场景一致，文字图形保持原生可编辑。
6. 视频：逐场景时长、停留、转场、独立配音稿与语速，句群级真实配音时间戳、字幕开关、背景音乐及成果预览；按真实音频长度排布，不裁掉台词。
7. 外部网页：复用现有安全导入和来源流程，将网页正文建立为可编辑创作项目，再进入统一视觉制作。
8. 验证：编辑/AI/引用/权限与版本回归，真实多格式文件，桌面与手机操作。优先测受影响路径，避免重复全量验证。

不另建互不关联的编辑器，不执行模型任意代码，不把图片快照称为可编辑 PPT。复杂角色新姿态仍需素材或图像模型；已有角色序列可以作为动态素材进入统一流程。
