# macOS 适配 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 提供Apple Silicon/Intel自动识别的macOS联网安装包，继承模板制作、LAN、账号，并适配凭证、OCR和启动管理。

**Architecture:** 保留现有React/Fastify/SQLite核心；macOS通过系统security CLI访问登录钥匙串、osascript/JXA调用Vision OCR，不依赖Homebrew/Swift编译器；安装脚本下载并校验官方Node，安装锁定生产依赖和Playwright浏览器，通过用户LaunchAgent管理后台。

**Tech Stack:** macOS14+、Node24.15、Keychain、Vision、JXA、launchctl、Bash。

1. `server/secrets.ts`：macOS钥匙串读写，密钥通过stdin，不进入命令参数/文件/备份；状态标记按安装目录隔离。
2. `scripts/macos-ocr.js`、`server/ocr.ts`：Vision图片识别和语言探测，复用逐页PDF渲染与现有事实/母稿/制作链。
3. `deployment/macos`、`scripts/macos-service.mjs`：自动识别架构、Node校验、依赖/PDF浏览器安装、独立data、端口避让、LaunchAgent/后台启动、停止/状态、自检和LAN地址。
4. 更新能力提示、运行环境诊断、备份排除说明；保留Windows路径。
5. 必要类型检查和构建，不重跑整轮测试。当前Windows环境无法完成macOS实机OCR/钥匙串/LaunchAgent验证，随包明确该边界及用户自检步骤。
6. 生成保留Unix可执行权限、无密钥/数据库的macOS联网ZIP，附产品说明、Mac指南、本地Agent安装提示词及SHA256，上传文件站。
