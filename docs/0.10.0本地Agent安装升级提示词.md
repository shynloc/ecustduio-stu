# 给本地 Agent 的安装升级提示词

请在这台电脑安装或升级 EcuStudio教创工作台 0.10.0。安装包路径：在这里填入用户下载的 ZIP 路径。

先读取包内“先读我.html”和“0.10.0发布与升级说明.md”，识别 Windows 或 Mac 和已有安装目录。已有安装必须升级，保留原账号、密码、资料、笔记、历史成果、DeepSeek 配置和公众号连接。不要删除、移动原 data，不创建空库替代原库，不打印密钥。

0.5.0 及以上正常运行版本优先用管理员页面“设置→工作台更新→检查更新→一键升级”。离线入口：把新包解压到原目录之外，Windows 运行“一键升级.cmd”，Mac 运行“Upgrade.command”。Mac 使用原系统用户，不用 sudo，不关闭系统保护；旧服务停止失败时按新包 Repair-Upgrade.command 恢复。

新用户：Windows 运行“一键安装.cmd”，Mac 运行“Install.command”；自动检测下载缺失环境并启动服务。首次账号由用户在本机创建，不预设通用密码。局域网部署只在服务电脑安装，其他人通过浏览器登录。

检查 /health 显示 0.10.0，原账号和资料存在，DeepSeek 显示已配置。公众号管理员在“设置→连接公众号”填写 AppID/AppSecret，不要求用户把密钥发到聊天或文档。若微信提示白名单或权限问题，按页面指导处理。

用合成教学笔记做“知识库→公众号排版→预览”的测试，确认封面、文字和图片可见。只有用户已授权保存到目标公众号时，才实际保存一篇明确标注的验收草稿，并回读确认；不要发布、群发或删除其他草稿。模拟接口验证必须与真实公众号验证区分。升级失败保留备份和日志，不卸载清空。报告实际完成项目和未验收项目；Windows 验证不能代替 Mac 实机验证。
