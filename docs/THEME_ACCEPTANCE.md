# 书院与曜石主题接入验收

日期：2026-11-08。

书院（scholar）继续作为默认；旧配置不含theme字段时自动采用书院。曜石（obsidian）现已覆盖工作台、政策情报、选题、项目编辑器、素材、成果日报、任务、设置及弹窗。首页证据链节点可直接进入真实资料、项目及成果页面；所有数量继续取实际数据库。

设置页增加两套主题选择卡。点击即时切换，通过独立PATCH /api/settings/theme事务保存，只有主题和设置revision变化，不提交其他未保存的配置。保存失败恢复原主题及本机缓存，并显示错误；保存期间防止重复切换。刷新和后台重启后保留已保存主题。启动脚本提前读取本机主题缓存减少亮色闪屏，以服务端持久设置为最终依据。

配色采用语义变量及原色回退，书院保留原有颜色。PPT画布预览、导出文件继续采用成果本身的版式。曜石使用高对比正文、冰青选中/按钮、琥珀待复核和柔红错误提示。编辑器保持静态；桌面首页及统计卡有短暂进入动效，减少动态效果时停用；手机取消立体旋转。

## 实际检查

- TypeScript检查、生产构建通过；31项后端回归通过。
- 独立浏览器测试在1440×1000与390×844通过；无页面脚本错误，无横向溢出。
- 验证默认书院、曜石自动保存、仅保存主题、未保存模型草稿保留、刷新保留、后台重启保留、切回书院。
- 验证资料、选题、项目、素材、成果、任务、设置、资料详情、编辑器和导入弹窗的深色覆盖。
- 验证保存失败时服务端状态不变，界面和localStorage均恢复原主题。
- 验证证据链导航、手机菜单、减少动态效果；检查桌面/手机截图、文本和表单的可读性。

测试位于tests/theme.e2e.ts；证据位于test-results/themes/result.json及同目录截图。测试使用独立数据库和合成资料，没有调用DeepSeek。

生产更新只安装主题代码。真实资料、项目、DeepSeek凭据及非主题配置在更新前后核对。最终保留书院为当前默认，用户可在设置中随时选择曜石。
