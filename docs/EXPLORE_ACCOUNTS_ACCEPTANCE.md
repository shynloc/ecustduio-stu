## 真实 DeepSeek 完整闭环

使用现有生产资料和加密凭证的**隔离副本**，暂停副本采集和发送，实际执行：

**本地 + 官方联网检索 → 带来源回答 → 保存创作笔记 → 笔记载入新对话 → 转为项目素材 → 研究提取 9 条候选事实 → 母稿 → 60 秒口播 → 真实 DOCX。**

本地命中已导入的考试院资料；网络返回考试院、市政府、区教育机构等真实 URL。第一轮回答检索了本地与网络资料；第二轮选择「仅本地资料」并读取选中笔记，未调用联网工具。没有将生成结果自动核实或发布。

记录在 `test-results/explore-live/result.json`，包含实际来源、模型调用量、消息/笔记/项目/母稿/口播 ID 和浏览器检查结果。`scripts/live-explore-flow.ts` 执行真实验收；`--resume-last` 可在隔离测试副本中复核已生成结果和页面，不重复模型生成。验收账号不写入生产库，临时随机密码不进入报告。

本次实测并修复：AI 回答转笔记标题包含换行和 Markdown 标记；新增表单下拉框标签不够准确；研究模型遗漏必要数组时直接失败；手机顶栏拥挤。现已提供单行标题、明确标签、预算内结构校正（不跳过引用校验）和移动布局调整。

## 升级和使用

升级前已创建生产数据备份，启动后自动补齐新表。保留原资料、项目和加密凭证，书院仍为默认主题，定时采集保持原来的关闭状态。首次打开正式工作台由用户创建管理员，再从「账号管理」分配其他账号。

正式实例升级后已复核：原有 2 份资料、3 个项目 ID 全部保留，加密凭证文件哈希未变；迁移版本 2，匿名数据访问被拒绝，桌面/手机均显示首次管理员设置页，浏览器错误 0。升级前备份为 `EcuStudio_backup_59ca39b5-5909-4150-aff2-183b03d926e6.zip`，位于 `D:\EduStudio\data\backups`。验证记录见 `test-results/accounts-production/result.json`。

政策不全来自自动抓取：目前配置两个考试院监测来源，也有手动/OCR 导入。当前自动计划关闭，点击「立即更新」才会主动采集，管理员可在设置启用每日计划。采集来源覆盖、联网搜索覆盖和 AI 回答都不等于事实已核实。

角色边界：创作者可研究和创作但不能管理账号、全局凭证、计划、推送或备份；业务员只读政策/日报/可发布成果。政策和项目共享，笔记和对话按账号隔离，管理员可访问全部。主动转为素材的笔记进入共享资料。

联网搜索复用 DeepSeek 凭证并产生实际服务调用，可能受到服务额度、限流、网站可用性或搜索覆盖影响。失败会在页面显示。当前本地搜索使用关键词/汉字片段排序，处理最近 2000 份资料、最多 1000 篇可访问笔记；没有向量语义检索。仍只监听本机地址。

其他历史真实验收脚本通过进程环境变量 `ECUSTUDIO_USERNAME`、`ECUSTUDIO_PASSWORD` 登录；不在代码或报告中保存密码。
