# EcuStudio 0.4.0 · DeepSeek 能力升级

更新日期：2026-11-14。适用于 Windows 和 macOS 工作台服务器；局域网内电脑、手机仍通过浏览器使用。

## 怎么使用

### 深度事实提取、母稿和内容制作

管理员打开「设置 → DeepSeek Agent」，选择 `deepseek-flash` 或 `deepseek-v4-pro`，将「默认思考强度」改为轻量、深度或最强思考，点击「保存 DeepSeek 设置」。随后新建的事实提取、母稿、定向修改、一键制作任务使用这个设置。已经排队的任务保留创建时的模型和预算。

旧配置升级后仍使用快速模式，已有密钥、授权和账号无需重建。连接测试只验证快速连接，不代表完整创作或联网能力已经验证。

### 官方联网探索

打开「AI 探索」，选择本地 + 联网或仅联网，再选择「官方搜索（Flash）」。可在这一轮单独选择思考强度。

- 搜索与整理：例如“查找北京教育考试院近期招生通知，按对象、时间和需要家长完成的事项整理，附官方来源”。开启思考后，DeepSeek 可多步搜索、阅读网页并交叉核对。
- 仅阅读输入的链接：粘贴一个或多个公开网页地址，要求摘要、比较、列清单。不会同时开启广泛搜索；可继续追问网页细节。
- 本地 + 联网：先检索共享资料和当前账号可访问的笔记，再与联网信息整合。手动勾选的笔记也会作为上下文发送。
- 仅本地资料：只开放工作台本地检索，不声明联网工具；不回传此前联网轮次的回答协议。所选笔记中的已有网络摘录仍属于用户主动选中的资料。

官方联网工具要求 Flash。全局使用 Pro 时，系统会使用原有工作台检索，并在回答中注明；要单独阅读链接请改用 Flash。选择「工作台检索」仍可执行本地/搜索/阅读已检索网页的受控工具循环。

### 把结果继续用于创作

回答中的 `[S1]` 等编号对应下方来源卡片。官方引用依据 Unicode 码点映射到正文，不把模型生成的摘要标成原文摘录。

点击「添加到创作笔记」，会保留正文和来源。笔记可载入下一轮对话，也可转为共享素材、关联项目，再执行事实提取、母稿和内容生成。联网回答及其转入的笔记仍需核验，不会自动认定为已核实事实。

首轮官方探索会尝试生成简短会话标题。拿不到标题时使用问题开头作为标题。查看回答下方「用量与检索步骤」，可查看 token、缓存命中、思考和已返回的计费搜索/抓取次数。

## 时间和费用

思考 token 计入输出预算。默认输出预算仍为 8192，管理员可在高级设置中调至最高 65536；更高思考强度可能增加耗时，预算太小可能在答案完成前用尽。

官方搜索的一次请求可以包含多个内部步骤，它们由 DeepSeek 管理，不受工作台「最多工具调用」限制。需要限制工具次数时使用工作台检索（每轮最多 4 次搜索、3 次网页阅读，且受总工具预算约束）。官方请求仍受工作台任务超时和取消控制；取消前已消耗部分可能计费。不会在官方搜索失败后自动换引擎重复付费。

用量缺失时显示“未返回”，不虚构金额。价格可能随时段和官方政策变化，请以 [DeepSeek 官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/) 和账单为准。

## 开发说明

- `server/deepseek.ts`：请求、错误处理、思考参数、协议消息和用量统计。
- `server/agent.ts`：结构化创作启用 JSON Output，并在工具循环、格式修复、结构修复时保留 reasoning_content。
- `server/native-explore.ts`：官方搜索/链接阅读、引用映射、协议历史、首轮标题。
- `server/explore.ts`：按权限检索、选择引擎、冻结单轮参数、提交笔记可用的回答。
- 协议状态保存在服务器 `messages.context.providerMessages` 和任务私有检查点，前端消息 API、任务结果和创作笔记不返回思考原文或网页签名；下一轮向 DeepSeek 原样回传必要字段。
- 输入和输出的内容审核失败、HTTP 200 携带错误、截断均按失败处理，不把不完整内容提交为成果。官方探索的内容审核开关在管理员设置中提供。
- 新参数纳入设置版本冲突控制和任务幂等比较；沿用三角色、资料权限、来源验证和人工发布审核。

## 文件、图像与语音

0.4.0新增「文件与语音」入口，接入Files、云端OCR、图像理解、ASR与TTS。结果可存笔记、带入探索、导入共享素材并开始制作；保存的口播/内容版本可直接配音。详细操作与限制见《DeepSeek文件图像语音使用指南》，本次真实验证见《DeepSeek媒体验证记录》。原本机OCR入口继续保留。

## 安装及验证

完整解压对应系统的联网安装包后运行安装入口，安装器保留原数据目录。首次安装需要联网下载 Node、生产依赖和 PDF 浏览器。Mac 原生 Keychain、Vision、登录自启仍需 Mac 实机自检；本次开发环境为 Windows。

协议回归使用明确的模拟响应，不冒充真实政策或真实 API 验证。真实检查仅使用公开资料和简短要求；详细记录见同包的「DeepSeek升级验证记录」。用户可按以上步骤验证自己的额度、网络和文档任务。
