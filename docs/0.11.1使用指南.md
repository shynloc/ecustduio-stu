# EcuStudio 0.11.1 使用指南

## 新界面

默认浅色为「晴空」，冷白背景配蓝色按钮，新 Logo 表达书页和创作。原来的浅色选择自动沿用，不需要重新设置。喜欢深色的用户可在「设置 → 外观」选择曜石。

## 公众号：五步完成

1. 从知识库选一篇笔记进入「公众号排版」，或打开公众号编辑器直接写稿。
2. 点击「文章主题」，查看缩略图。点「查看全部主题」可搜索、按明暗或系列筛选，也可找回收藏和最近使用。
3. 点击主题先预览；「配方」调整文章结构，「微调」调整字号、行距、缩进和装饰。手机点「看文章效果」预览，再返回选主题。
4. 点击「应用排版」才会自动保存。取消不改原排版，也不改变文章正文。
5. 点击「复制到公众号」，在微信后台正文区粘贴，最后用微信自己的预览核对。需要存档可下载带图 HTML。

管理员已经连接公众号：复制会自动将配图转存到微信，随后可直接粘贴。

尚未连接：正文会显示配图编号，点「下载配图」，在微信后台按编号插入并删除提示；也可以让管理员先到设置连接公众号。复制不会创建远端草稿或发布文章。

需要直接保存草稿时，核对目标公众号，再点击保存并确认。不要在结果不明时重复创建，先查看页面回执。

## 升级与原数据

原管理员打开「设置 → 工作台更新」，检查后选择升级至 0.11.1。原账号、资料和 DeepSeek 配置保留。安装与恢复步骤见《0.11.1发布与升级说明》，原有资料输入、知识库、对话和多格式创作方法可继续参考《0.11.0使用指南》。
