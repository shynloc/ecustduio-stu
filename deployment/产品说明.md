# EcuStudio 教创工作台 0.6.0

适用于教育内容研究、政策梳理与多形式创作。由一台 Windows 10/11 x64 电脑提供后台服务，同一局域网中的电脑、手机通过浏览器登录使用；客户端不需要安装 Node、OCR 或 AI 开发工具。

## 本次交付

- **直接开始制作**：素材与知识的五个模板提供「开始制作」，无需复制到其他软件。选资料、项目和参数后，受控 DeepSeek Agent 自动执行「候选事实 → 母稿 → 目标内容 → 文件」。过程在任务页记录，文件在工作台下载。
- **产物**：政策解读文档、真人口播稿、公众号文章及HTML、真实PPTX及讲义、文字分镜和JSON。可生成官方音色的AI合成配音；不提供视频成片或图片生成，分镜的画面提示可作为后续制作素材。
- **资料**：网址、粘贴原文、PDF、DOCX、MD/TXT/HTML；PNG/JPEG/WebP及扫描PDF可使用Windows本机OCR，校正后进入事实与创作流程。
- **探索和笔记**：AI本地/联网检索、多轮对话和来源引用；回答存笔记，笔记回填对话或作为创作素材。
- **组织工作**：政策监测、选题、版本编辑、审核导出、日报、任务、备份恢复。默认书院主题，另有曜石主题。
- **三类账号**：管理员拥有全部功能；创作者可研究、写笔记、制作与导出；业务员只读政策、日报和可发布成果。权限同时在后端实施。

## 部署与数据

完整ZIP包含构建产物、源码、Windows x64 Node运行环境、生产依赖、PDF浏览器、安装启动脚本、原有PRD和开发文档、本说明和使用指南。正常安装不需要先安装Node、Python、Office、Codex或WorkBuddy。DeepSeek调用需要安装用户自己的API Key及额度，首次使用在界面配置。

业务资料与项目在服务器共享；对话和未转成共享素材的笔记按账号隔离，管理员可访问全部。密钥由服务器当前Windows用户DPAPI加密保存。交付包不附带开发者的密钥、账号、业务数据库或备份。

首次管理员只允许在服务器本机创建。局域网模式监听服务器网卡，校验访问地址、同源、CSRF及私网客户端；防火墙只放行该程序端口和本地子网。使用可信的办公室/家庭局域网；默认HTTP没有传输加密，不是公网部署方案。

后台服务在安装后启动，可随服务器Windows用户登录自动启动。服务器应保持开机、登录及正常联网；退出、休眠、关机期间不执行定时任务。不提供Windows系统服务账号或免登录开机服务。

## 边界

自动提取和生成的内容保持待核实/研究草稿；一键制作不会绕过发布审核。PPT的PDF是讲义而非逐页幻灯片保真PDF。OCR需Windows识别语言包，单次最多30页，上传最多50MB，单图最多4000万像素。识别日期、数字和版面应人工校对。本地搜索为关键词/汉字片段排序，不宣称向量语义检索或全网穷尽检索。

## DeepSeek 0.4.0 文件、图像与语音

左侧「文件与语音」支持文档解析、云端文字识别、图像理解、录音转写和文字配音。校正后可存笔记、载入AI探索、导入素材并开始制作；已保存的口播版本、笔记和AI回答提供「生成配音」。音频支持试听及WAV下载。完整步骤、数据共享、20分钟录音/配音字符限制与验证边界，见同包《DeepSeek文件图像语音使用指南》《DeepSeek媒体验证记录》。


## 旧版一键升级（upgrade1）

新包完整解压到原安装目录之外的新目录；Windows运行「一键升级.cmd」，Mac运行Upgrade.command。自动识别原位置、备份、更新和校验，保留账号/密码、资料、笔记、DeepSeek凭据及设置；失败自动回滚。使用原电脑、原系统登录用户和原安装目录，Mac不使用sudo。操作与中断恢复详见同包《升级指南》《升级验证记录》。局域网客户端只需刷新页面。
