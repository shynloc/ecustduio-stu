# 旧版升级到 EcuStudio 0.6.0

本包为 **0.6.0 / online-update1**。0.5.0 可直接从设置页在线更新；更早版本首次手动升级接入，后续可在「设置 → 工作台更新」直接升级。详见「在线升级使用指南.md」。

## 升级操作

只需在提供工作台服务的那台电脑操作。局域网创作者、业务员的电脑和手机不必安装升级包，服务器升级完成后刷新网页即可。

1. 使用**原电脑、原系统登录账号**，下载对应系统的新版完整ZIP。
2. 完整解压到一个新的临时文件夹，必须位于旧安装目录之外。不要先覆盖旧版文件，不要卸载旧版，也不要移动data。
3. Windows双击 **一键升级.cmd**；Mac双击 **Upgrade.command**。Mac也可在终端执行 `bash Upgrade.command`，不要用sudo。
4. 默认位置会自动识别。Windows也会检查D:\EduStudio、已有启动快捷方式和运行服务；发现多个安装时需选一个。Mac非默认安装位置可按提示输入。选择的必须是包含app、data、ecustudio.json的旧目录。
5. 保持升级窗口打开。脚本自动校验包、准备依赖、停止服务、备份、替换程序、迁移、检查旧数据、启动并打开工作台。
6. 用原账号和密码登录，检查页面版本为0.6.0，左侧出现「一句话任务管家」与「政策影响追踪」。DeepSeek已有凭据和授权无需重填；仍可在设置中自行测试连接。

Windows自定义目录：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Upgrade-EcuStudio.ps1 -InstallDir "D:\EduStudio"
```

Mac自定义目录：

```bash
ECUSTUDIO_INSTALL_DIR="/你的原安装目录" bash Upgrade.command
```

若存在排队或运行中的制作任务，升级器会停止，请先在工作台完成任务后再运行。升级期间成员会短暂看到维护提示；完成后恢复服务。

## 保留哪些内容

| 内容 | 升级行为 |
| --- | --- |
| 管理员、创作者、业务员账号 | 保留账号ID、身份、密码哈希与状态，不创建一套新账号 |
| 原文、文件、图片、录音、创作资料 | data/assets原位保留，数据库引用不重建 |
| 事实、母稿、项目、内容版本、笔记、对话 | 保留原记录，并校验原有字段的数量与内容摘要 |
| DeepSeek Key | Windows原DPAPI加密文件不变；Mac原钥匙串条目不迁移、不导出，继续使用原目录对应的服务名称 |
| DeepSeek模型、调用授权、预算 | 保留数据库设置 |
| 主题、端口、局域网、登录自启 | 保留原配置和启动位置，不重新申请防火墙或创建额外启动项 |
| 依赖与运行环境 | 相同锁文件依赖优先复用；依赖变化或缺失时先联网准备新依赖，再停止旧服务 |

**保留凭据不等于跨电脑迁移。** Windows DPAPI绑定原Windows用户/电脑，Mac依赖原登录钥匙串和原安装路径。换电脑、换系统账号、改安装路径属于迁移，需要另行处理凭据，不能仅复制加密文件保证可用。

## 备份与恢复

升级前在旧安装目录的 `data/upgrade-backups/时间戳-编号/` 自动保留一致的SQLite数据库、配置/加密标记副本及旧程序。原素材文件不重复复制、不搬移、不删除，仍在原data/assets中。依赖相同时会移到新程序继续使用；失败回滚时移回旧程序。

启动失败、迁移错误或数据校验不符时，自动恢复旧程序和数据库，再尝试启动旧版。不要删除备份，也不要手动覆盖正在运行的数据库。

如断电、强行关窗导致升级未完成：重新打开**同一个新包目录**，Windows双击 **恢复未完成升级.cmd**；Mac运行 **Recover-Upgrade.command**。它只处理未完成升级；检测到另一个升级进程仍在运行时会拒绝操作。它不是“任意回到历史版本”的按钮，不会在用户继续创作后盲目覆盖新数据。

完成记录在原目录 `upgrade-result.json`；每次备份的 `journal.json` 记录步骤与状态。记录不包含API Key明文。升级目录可能含私有数据库/配置备份，请只留在原电脑，不上传文件站或发送给他人。

## 安装还是升级

新用户运行「一键安装.cmd」/Install.command。安装器发现目标目录已有工作台数据库时会转入升级流程；旧用户仍建议直接选择升级入口，避免把新工作台装到另一个空目录，误以为旧资料丢失。

本包无需再次配置付费模型，升级器不发起DeepSeek调用。新安装需要联网下载Node、生产依赖和PDF浏览器；升级依赖齐全且未改变时可复用。安装用户可按随包指南自行验证真实模型、局域网和手机使用。

Windows升级与回滚在隔离测试安装验证，不向用户业务库写入测试账号或材料。Mac使用同一跨平台升级引擎，但钥匙串、LaunchAgent和Mac安装升级入口仍需Mac实机验收。
