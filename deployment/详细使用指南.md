# EcuStudio 教创工作台详细使用指南

版本0.6.0。先完成服务器安装，再分配创作者和业务员账号。

## 1. 安装与首次启动

1. 将ZIP完整解压到普通文件夹。不要直接在压缩软件里运行，不要只复制单个CMD文件。
2. 双击 `一键安装.cmd`。默认安装到当前Windows用户的 `%LOCALAPPDATA%\EcuStudio`。自选位置可在PowerShell运行：`powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-EcuStudio.ps1 -InstallDir D:\EcuStudio`。
3. 安装程序复制完整产品、使用随包Node、检查SQLite/图片处理/PDF浏览器，缺失依赖按锁文件补齐。完整包正常安装无需下载这些核心依赖；修复损坏文件时可能需要联网。
4. 默认启用局域网并配置本地子网防火墙。Windows询问系统权限时，允许安装程序修改此端口规则；不修改全局防火墙开关。取消权限时，本机可以继续用，其他设备可能无法连接，请右键 `Enable-Lan.cmd` 以管理员身份运行。
5. 缺中文OCR语言包时安装程序会尝试调用Windows可选功能安装；需管理员权限和Windows Update。如未完成，其余功能仍可使用，稍后运行 `Repair-OCR.ps1` 并重启工作台。
6. 默认端口37891，遇占用会选择后续空闲端口。安装完成查看 `installation-result.json` 中的 `localUrl`，不要一直猜端口。
7. 安装后后台启动并打开浏览器；默认配置Windows用户登录后自动启动。需要禁止登录自启时加 `-NoAutoStart`，禁止打开浏览器加 `-NoBrowser`。`-NoFirewall` 用于已有管理员配置好网络或隔离安装测试，不代表防火墙已配置成功。

首次启动后无需保持命令窗口。日常双击安装目录中的 `启动工作台.cmd`，停止用 `Stop-EcuStudio.cmd`。关闭网页不会停止后台。不要删除data文件夹解决启动问题。

## 2. 创建账号与模型配置

1. 在**服务器电脑本机**打开安装结果给出的127.0.0.1地址，创建管理员。账号名3–40位，字母/数字/点/横线/下划线；密码至少10位。无预置通用密码。
2. 管理员进入「账号管理 → 新建账号」，填写显示名称、账号、身份和初始密码。将初始密码通过自己的安全渠道交给成员，成员第一次登录需修改密码。
3. 身份、停用、重置密码会使旧会话失效。至少保留一个有效管理员，不能停用或删除当前自己。忘记密码由其他管理员重置；单管理员密码请自行妥善保管。
4. 进入「设置 → DeepSeek Agent」，录入自己的API Key并保存；勾选「允许DeepSeek调用」，点击「保存并测试连接」。只保存密钥不会自动开启模型调用。无需把密钥贴进安装Agent对话。
5. 模型、最大请求/工具数、超时和输出预算由管理员配置。更大篇幅/更多PPT页需要更多上下文和调用量；先用短篇、小页数验证。

| 功能 | 管理员 | 创作者 | 业务员 |
|---|---|---|---|
| 查看政策和原件、日报 | 是 | 是 | 是 |
| 资料导入、OCR、事实与选题 | 是 | 是 | 只读政策 |
| AI探索、创作笔记、制作与编辑 | 是 | 是 | 否 |
| 下载成果 | 全部 | 全部 | 仅可发布成果 |
| 账号/模型/凭证/来源/计划/备份/推送管理 | 是 | 否 | 否 |

## 3. 让其他电脑、手机连接

1. 服务器与成员设备连接同一可信局域网；访客Wi-Fi或开启客户端隔离的无线网络可能阻止互访。
2. 在服务器运行 `ipconfig`，选择实际WLAN/以太网IPv4地址，配合安装结果的端口，例如 `http://192.168.1.20:37891`。不要给成员127.0.0.1地址：它指向各自设备，不是服务器。
3. 成员在自己的浏览器打开该地址，使用分配的账号登录。手机不需要安装App。
4. 主机IP由DHCP变化时，应重新通知成员新地址。长期使用可在路由器给服务器固定DHCP租约。
5. 默认普通HTTP限可信内网使用，不能把它直接端口映射到互联网。没有部署HTTPS反向代理或公网认证系统。
6. 连接失败依次检查：服务器网页本机能否打开 → 地址/端口是否正确 → 是否同网 → 防火墙是否放行 → 服务器是否休眠。VPN/虚拟网卡地址通常不是成员应使用的地址。

## 4. 从一份资料开始

进入「政策情报 → 添加研究资料」，可输入公开网址、粘贴正文或上传文件。请补充准确的地区、区县、学段、年度、受众和来源性质。资料未知时不要冒充正式文件或填写臆测的发布日期。

图片/扫描PDF自动排队OCR；识别后在提取预览里校正日期、数字、阅读顺序，再导入。文本/扫描混合PDF按页处理，也可选择全部页面重新识别。关闭窗口后可从任务记录恢复识别结果继续导入。加密PDF先解密，超30页先拆分。

资料详情保留原件和段落页码。可单独运行AI研究，提出候选事实与选题；核验时对照原文、适用范围和理由逐条确认。候选不自动成为已核实事实。

## 5. 模板直接制作：无需复制提示词

1. 打开「素材与知识」，选择政策研究、真人口播、公众号图文、讲座PPT或视频分镜卡片，点击**开始制作**。
2. 在制作页选择新建项目，或选择已有项目。新建项目填写名称和范围，再勾选资料；已有项目自动采用项目资料和范围，保留历史版本。
3. 调整「制作要求」。卡片原来的提示词现在已经带入，复制仅是辅助选项，不需要粘贴到外部AI。
4. 口播/分镜设置目标秒数和角色模板；PPT设置页数和讲座分钟数。第一次建议60–90秒口播或3–10页PPT。
5. 选择成果格式，点击**开始制作并生成文件**。任务跳转到执行轨迹，Agent依次提取候选事实、生成母稿、制作目标内容、生成下载文件。
6. 成功后在任务右侧直接下载，或进入制作项目继续编辑。口播产物是稿件，保存版本后点击「生成配音」可制作WAV；分镜产物是文字方案，不生成视频成片。PPTX是真实可编辑幻灯片，PDF是讲义。
7. 生成结果为研究草稿。若要让业务员下载，需完成事实核验、内容审核，再以「可发布」模式导出。不要将草稿直接当作正式通知。

失败时看轨迹的具体错误：未配置密钥/授权请联系管理员；额度或网络问题处理后从安全位置重试；已完成的版本和文件会保留。制作过程中项目被其他操作更新时会停止，以避免覆盖别人修改，请查看项目后从模板重新开始。取消后后台已完成的素材不会丢失。

长篇讲座或大量材料建议按主题拆分，不要一次勾选全部资料。每阶段遵循管理员预算，整条制作任务也受超时限制。

## 6. AI探索与创作笔记

- 在「AI探索」输入问题、搜索要求或整理指令，选择仅本地、仅联网、本地+联网。本地命中的共享资料、本人可访问笔记以及所选上下文会用于DeepSeek回答；联网会发送检索词。
- 回答附来源编号、摘要、原网页或本地资料入口。搜索无结果或失败会明确提示；模型推断不等于官方事实。
- 回答下点击「添加到创作笔记」保存。也可以在笔记页直接写内容，保存后再执行后续操作。
- 「载入AI对话」将笔记选为上下文；每轮最多8篇、合计4万字，发送时固定版本。
- 「作为创作素材」可加入资料库、已有项目或新项目。会明确共享到资料库并生成固定快照，后续改笔记不会静默改旧素材。
- 创作者看不到他人私有笔记/对话；管理员可访问全部。主动转成素材后则属于工作台共享资料。

## 7. 编辑、审核、成果与日报

项目中切换母稿和不同内容类型，编辑自动保存的工作草稿；提交时生成版本，历史版本保留。可锁定内容块，使用局部改写和版本对比。多人同时修改的版本冲突需要重新载入，不能靠反复点击强行覆盖。

研究草稿可以导出；可发布导出须满足事实、适用范围、数字、当前版本审核和依赖检查。业务员仅能下载可发布成果，不能经直接链接读取草稿或私有笔记。

政策并非全自动抓取：目前有两个考试院来源，也支持手动/OCR导入。默认每日自动计划关闭，点击「立即更新」手动运行；管理员可开启每日计划。来源、关键词与时间窗口限制采集覆盖，后台关机/休眠期间不执行。日报保留来源和覆盖提示，零推荐不代表采集错误，也不应编造推荐。

钉钉推送需管理员单独配置，先预览并确认目标；安装与自检不发送钉钉消息。

## 8. 备份、升级和密钥

管理员从设置创建、下载备份；恢复前查看预览，系统保留安全备份并暂停调度/自动发送。备份不含模型凭证和有效登录会话，恢复内容会保留当前账号身份并要求重新登录。

升级时先备份，再从新版本完整ZIP运行安装到**原安装目录**，不要把旧data覆盖为交付包空库。安装脚本只更新产品和运行环境，保留data和既有配置；端口与网络模式在ecustudio.json。

DPAPI凭证绑定服务器的Windows用户；换电脑或换Windows服务用户后请在设置重新录入密钥。交付包不携带开发者密钥或已有业务数据。

## 9. 自检与常见问题

- 双击 `Check-EcuStudio.cmd`：检查Node、SQLite、原生图片模块、PDF浏览器及OCR语言包。
- 双击 `自检与修复.cmd`：缺依赖时按锁文件修复，并在独立临时数据库测试登录、三角色权限、笔记隔离、资料导入和实际网卡IP访问；不修改正式业务库、不调用付费AI、不发送消息。
- 自检结果在 `data\selftest\run-*\result.json`；服务日志在 `data\logs`；安装结果在根目录 `installation-result.json`。
- 如完整运行环境损坏，优先重新解压原ZIP并重装同一目录。自动联网修复受用户网络、代理和Windows权限影响，失败会报具体问题，不应删除数据库。
- 出现端口被占用，重跑安装程序或修改ecustudio.json中的port后启动，更新给成员的地址。
- 关掉浏览器后台仍运行；停止请用Stop脚本。服务器睡眠后无人能访问，恢复后再检查任务状态。
- 密钥存在但不能调用，确认「允许DeepSeek调用」已经保存，并检查模型、余额和网络。

## 10. 用户电脑验收清单

本次按加速交付要求没有重复整轮测试。请在实际电脑按顺序验证：

1. 全新目录安装、自动启动，重跑安装仍保留data；退出Windows再登录检查登录自启。
2. 管理员创建创作者和业务员，各自在其他电脑/手机登录并首次改密。
3. 业务员只有政策/成果日报，无法导入、生成、查看账号；创作者不能管理全局配置或读取他人笔记；停用账号后旧登录失效。
4. 导入一份真实文档或图片，校正OCR；从素材模板开始制作，查看四阶段、下载文件并检查内容与格式。
5. 运行探索，保存笔记，载入对话，再转素材制作；检查来源和核验状态。
6. 制作中关闭网页再回来，检查任务继续；模拟缺额度后补齐再重试；改动项目时检查不会覆盖其他版本。
7. 检查草稿业务员不能下载，管理员审核并以可发布模式导出后业务员可见。
8. 创建备份、下载校验，并在测试安装中恢复。不要为了验收直接覆盖唯一正式数据库。

需要本地Agent协助安装时，把完整ZIP路径和同包《本地Agent安装启动提示词》一起交给它。不要另外发送现有密钥或个人账号密码。

## DeepSeek 0.4.0 文件、图像与语音

左侧「文件与语音」支持文档解析、云端文字识别、图像理解、录音转写和文字配音。校正后可存笔记、载入AI探索、导入素材并开始制作；已保存的口播版本、笔记和AI回答提供「生成配音」。音频支持试听及WAV下载。完整步骤、数据共享、20分钟录音/配音字符限制与验证边界，见同包《DeepSeek文件图像语音使用指南》《DeepSeek媒体验证记录》。


## 旧版一键升级（upgrade1）

新包完整解压到原安装目录之外的新目录；Windows运行「一键升级.cmd」，Mac运行Upgrade.command。自动识别原位置、备份、更新和校验，保留账号/密码、资料、笔记、DeepSeek凭据及设置；失败自动回滚。使用原电脑、原系统登录用户和原安装目录，Mac不使用sudo。操作与中断恢复详见同包《升级指南》《升级验证记录》。局域网客户端只需刷新页面。

## 0.6.0 更新

新增一句话任务管家、政策影响追踪、整套内容包与来源预审，内置 ACKS 和 HTML Creator Studio。支持 HTML 预览及核对后本机制作无声 MP4。0.5.0 用户在设置里检查更新并升级，保留账号、资料和 DeepSeek 配置。新版本的完整流程、范围及限制详见《0.6.0使用与升级指南》，开发资料与验证记录一并随包提供。
