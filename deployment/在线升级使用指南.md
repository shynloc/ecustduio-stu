# EcuStudio 0.7.0 · 设置页在线升级

0.5.0 / 0.6.0 用户可直接在设置页升级到 0.7.0；升级优先复用已安装的依赖，缺失时联网准备；动图的 Python/Pillow 按视觉制作页指引安装。完整操作及新增功能详见《0.7.0发布与升级说明》。

## 管理员怎样升级

进入「设置 → 工作台更新」，点击「检查更新」。发现新版时可查看版本说明，点击「一键升级至…」。工作台自动下载官方更新包、核对签名与 SHA-256、准备依赖、备份、安装并重启；页面会自动重连并刷新。

只需升级提供服务的服务器电脑。局域网成员的电脑和手机无需安装升级包，完成后刷新页面即可。创作者和业务员没有检查更新、升级或恢复权限。升级不会调用 DeepSeek，不消耗模型额度。

请等待排队或运行中的任务完成，保持服务器开机并联网。升级期间不能执行制作、导入、修改设置等操作。浏览器关闭不会中止已经开始的后台升级，可重新打开设置查看进度。

## 0.4.0 及更早版本如何接入

旧版尚无设置页更新组件，首次需下载 0.7.0 的 UpgradeReady 包，在原安装目录之外解压。Windows 运行「一键升级.cmd」，Mac 运行「Upgrade.command」，选择原安装目录。完成这一次接入后，后续版本直接在设置页升级，无需每次手动下载解压。

新用户安装 0.7.0 后即具备在线升级功能。

## 原数据与配置

- 保留管理员、创作者、业务员账号、身份、密码和状态。
- 原素材文件留在 data/assets，事实、母稿、内容版本、创作笔记、对话等记录保留。
- 保留 DeepSeek API Key、模型、授权和预算设置；保留主题、端口及局域网配置。
- Windows 使用原电脑、原系统登录用户的 DPAPI；Mac 使用原登录钥匙串和原安装路径。此功能是原位升级，不是跨电脑迁移。

升级前在原目录 data/upgrade-backups/时间戳-编号/ 保存数据库、旧程序、配置及加密标记副本。原素材不重复复制或删除。新程序启用前比较原有记录和配置摘要，异常时尝试自动恢复旧版。

## 异常处理

下载失败、签名无效、包校验失败时，原程序继续保留，可再次检查更新。服务重启时页面短暂断开属于正常现象。

若进程中断且服务仍可访问，设置页会显示「恢复未完成升级」。若页面完全无法访问，请在服务器使用新包的「恢复未完成升级.cmd」或「Recover-Upgrade.command」，也可把本机缓存与下述提示交给本地 Agent。不要删除 data、备份目录或更改原安装路径。

升级状态在 data/updates/current.json；临时缓存和日志位置记录在该文件的 workdir。缓存不位于原 app 目录，避免替换程序时中断更新进程。保留本机日志即可，不要把包含数据库和加密凭据的备份上传文件站。

给本地 Agent 的恢复提示：

> 请读取原安装目录中的 data/updates/current.json、data/upgrade.lock 和相应备份 journal.json，先确认是否仍有升级进程在运行。在原电脑和原系统用户下使用缓存目录的 upgrade.mjs --source [缓存/package] --target [原安装目录] --recover --no-browser 恢复未完成升级，使用原 Node 24 运行环境。不要清空 data、重建账号或重置 DeepSeek 凭据，不要上传数据库或密钥。恢复后检查 /health、原账号登录和资料。

## 发布通道与适用范围

稳定版清单：https://dshdisk.acks.com.cn/ecustudio/releases/stable.json 。清单使用 Ed25519 签名，客户端内置公钥；更新包仅允许从固定官方文件站下载，禁止重定向，必须匹配签名清单中的大小与 SHA-256。签名私钥不随源码或安装包分发。

支持标准目录安装的 Windows x64、macOS 14+（Apple Silicon/Intel）。Mac 与 Windows 共用升级引擎；本次开发环境为 Windows，Mac 原生钥匙串、LaunchAgent 与安装器仍需在 Mac 实机自检。
