# Mac安装与使用指南

## 1. 安装

1. 在macOS 14+电脑完整解压ZIP。Apple Silicon和Intel共用一个包，不要拷贝Windows版的node_modules或运行环境。
2. 双击 `Install.command`。如果系统提示无法打开，请在Finder右键→打开；或在终端执行 `bash "/实际解压目录/Install.command"`。不要使用sudo，不需要关闭Gatekeeper。
3. 安装器自动识别芯片，下载并校验官方Node，安装锁定的生产依赖与PDF浏览器。首次需联网，耗时主要取决于下载速度；依赖失败会停止，不会用假结果替代。
4. 默认安装到 `~/Library/Application Support/EcuStudio`。安装器保留data及已有配置；覆盖更新前会停止本安装实例。业务数据请先从工作台备份。
5. 默认局域网模式和用户登录自启。安装后自动启动并打开浏览器，在**这台Mac本机**创建管理员；再分配创作者和业务员账号，成员首次登录需改初始密码。
6. 管理员在设置保存自己的DeepSeek API Key，再勾选允许调用并测试连接。钥匙串若请求授权，请确认是本次工作台操作后允许；不要把Mac登录密码或API Key发送给Agent。

安装脚本可指定环境变量，例如：

```bash
ECUSTUDIO_INSTALL_DIR="$HOME/Applications/EcuStudio" bash "/解压目录/Install.command"
ECUSTUDIO_NO_AUTOSTART=1 ECUSTUDIO_NO_BROWSER=1 bash "/解压目录/Install.command"
```

默认端口37891；遇占用自动尝试后续端口。实际地址和安装信息在安装目录 `installation-result.json`。网络模式/端口在 `ecustudio.json`。

## 2. 日常启动与停止

打开**安装目录**中的 `Start.command` 启动并打开网页；`Stop.command` 停止本实例并保留数据；`Status.command` 显示地址、运行状态和LaunchAgent路径。请不要一直从原解压目录启动，这里尚未安装运行环境。

关闭浏览器不会停止后台。LaunchAgent随当前Mac用户登录启动，不是无需登录的系统Daemon；关机、休眠、注销用户时不可提供稳定服务。作为团队服务器使用时请保持Mac开机并避免休眠。

首次钥匙串访问需要当前图形用户登录、登录钥匙串已解锁。纯SSH会话可能无法弹出授权或加载GUI LaunchAgent；请先在Mac桌面会话完成初始化。

## 3. 其他设备连接

从 `installation-result.json` 或 `Status.command` 查看实际WLAN/以太网地址，例如 `http://192.168.1.20:37891`。同网电脑、手机在浏览器打开该地址登录即可；127.0.0.1只用于服务器本机。

macOS若询问是否允许Node接收传入连接，请允许。连接受阻时查看系统设置→网络→防火墙→选项，允许本安装目录的Node；不要关闭整个防火墙。访客Wi-Fi隔离、VPN或选错虚拟网卡IP也会阻止互访。

默认HTTP用于可信局域网，不提供公网端口映射或HTTPS部署。首次管理员禁止从远端创建。业务员只读政策、日报和可发布成果，不能研究/制作/访问笔记或管理账号。

## 4. 完成一次制作

1. 政策情报→添加资料：导入网址、正文或文件，填写地区、区县、年度、学段、来源性质和受众。
2. 图片/扫描PDF自动本机识别，检查OCR预览中的日期、数字、段落再导入。加密PDF先解密，超过30页先拆分。设置页显示实际Vision能力和识别语言；不可用时请先自检。
3. 素材与知识→选择模板→**开始制作**。选择已有项目，或新建项目并选择资料。
4. 调整制作要求、口播/分镜时长、角色、PPT页数，以及成果格式。原来的提示词已带入，不用粘贴到外部软件。
5. 点击**开始制作并生成文件**。任务页记录研究、母稿、目标内容和导出四阶段；完成后直接下载，或进入项目继续编辑。
6. 失败先查看轨迹。额度/网络恢复后可安全重试，已完成版本保留。任务中项目被别人修改时会停止保护现有内容，应检查项目后重新开始。

自动事实保持待核实，生成文件为研究草稿。需要给业务员下载时，请完成核验、内容审核，再按可发布模式导出。PPTX是真实幻灯片，PPT的PDF为讲义；口播/分镜不是音视频文件。

## 5. 探索和笔记

在AI探索输入问题，选择本地/联网/混合范围。回答附实际来源；本地命中资料和所选笔记会用于模型回答，联网会发送检索词。结果不等于政策已核实。

回答下点击添加到创作笔记。笔记保存后可载入新对话；或选作为创作素材，加入资料库/已有/新建项目。转素材会共享固定快照，后续修改笔记不改变历史素材。创作者不能读他人私有笔记和对话，管理员可访问全部。

## 6. 数据、升级与迁移

安装目录data包含数据库、资料、资产和日志，请勿删除。钥匙串条目不在数据库备份中，也不能从Windows的DPAPI凭证迁移过来；换电脑、换Mac用户或移动安装目录后，请重新录入模型凭证。

升级先备份，再运行新包Install.command并指定原安装目录；安装器保留data和配置。不要用空数据库覆盖旧data。恢复备份前会保留安全备份，恢复后需重新登录，并检查调度和发送配置。

不要通过随意移动安装目录来升级，LaunchAgent及钥匙串作用域与安装路径有关。需迁移时先停止旧实例、备份数据，在新位置安装后恢复并重新配置凭证。

## 7. 自检与修复

在安装目录执行：

```bash
bash Check.command
ECUSTUDIO_REPAIR=1 bash Check.command
ECUSTUDIO_DEEP_TEST=1 bash Check.command
```

普通自检检查Node、SQLite、图片模块、实际PDF渲染和Vision语言探测。修复模式重新安装锁定依赖和PDF浏览器，需联网。深度自检另在隔离数据库中验证三角色权限、局域网地址和导入，并用临时钥匙串条目及实际图片验证原生适配，结束时删除该临时凭证；不调用付费AI，也不改正式业务库。

诊断结果在data/logs/runtime-check.json，深度自检证据在data/selftest，服务日志在data/logs/mac-service-stderr.log。当前电脑不具备Mac实机测试条件，本版原生能力需要你在Mac执行这些检查。

用户验收：分别验证Apple Silicon/Intel实际安装、首次改密与权限、图片/两页扫描PDF、真实DeepSeek完整制作、文件下载、手机访问、停止再启动、退出再登录的自启、备份恢复。请勿把旧版本Windows通过的测试数量当作Mac验收结果。


## DeepSeek 0.4.0 文件、图像与语音

左侧「文件与语音」支持文档解析、云端文字识别、图像理解、录音转写和文字配音。校正后可存笔记、载入AI探索、导入素材并开始制作；已保存的口播版本、笔记和AI回答提供「生成配音」。音频支持试听及WAV下载。完整步骤、数据共享、20分钟录音/配音字符限制与验证边界，见同包《DeepSeek文件图像语音使用指南》《DeepSeek媒体验证记录》。


## 旧版一键升级（upgrade1）

新包完整解压到原安装目录之外的新目录；Windows运行「一键升级.cmd」，Mac运行Upgrade.command。自动识别原位置、备份、更新和校验，保留账号/密码、资料、笔记、DeepSeek凭据及设置；失败自动回滚。使用原电脑、原系统登录用户和原安装目录，Mac不使用sudo。操作与中断恢复详见同包《升级指南》《升级验证记录》。局域网客户端只需刷新页面。


## 0.5.0 在线更新

管理员进入设置的「工作台更新」区域检查新版并一键升级，自动备份并保留账号、资料与 DeepSeek 配置。0.4.0 及更早版本首次需要运行本包的升级入口接入，后续直接在页面操作。详见「在线升级使用指南.md」。


## 0.6.0 更新

新增一句话任务管家、政策影响追踪、整套内容包与来源预审，内置 ACKS 和 HTML Creator Studio。支持 HTML 预览及核对后本机制作无声 MP4。0.5.0 用户在设置里检查更新并升级，保留账号、资料和 DeepSeek 配置。新版本的完整流程、范围及限制详见《0.6.0使用与升级指南》，开发资料与验证记录一并随包提供。


## 0.7.0 视觉创作更新
