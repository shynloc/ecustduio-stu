# EcuStudio 教创工作台 0.11.0

为普通职员提供资料输入、知识整理、AI协作和多格式创作。Windows 10/11 x64或macOS 14+（Apple Silicon/Intel）作为服务端；同一局域网的电脑和手机用浏览器登录。

## 功能

- 输入网址、文字、文档、图片、扫描PDF、录音；保存原件、出处和识别覆盖，自动拆分长PDF。
- 知识库与成果库：卡片/列表、搜索筛选、分类文件夹、标签、多选、批量、回收和撤销。
- AI创作对话：DeepSeek Agent、资料上下文、本地/联网检索、流式回答、持久历史和精确文件改版。
- 作品：网页/互动HTML、可编辑PPT、Word、PDF、GIF、音频和带配音视频。沿用HTML Creator Studio和GIF Factory能力；网页可直接转视频。
- 项目：资料、写稿、作品三段式；连续正文编辑、版本保留、来源核对和更新提示。
- 公众号：富文本写稿、手机预览、主题、图文复制/HTML下载、授权账号的远端草稿保存。
- 计划：订阅抓取、资料变化、成果日报和可恢复任务。
- 全局图标编辑器、书院默认/曜石可选、可操作3D首页、手机适配。

## 安装和数据

联网包包含源码、构建结果、安装/升级脚本、文档和自检，不包含用户数据、凭据和完整依赖。首次安装按锁文件下载运行环境。DeepSeek及外部识别/语音服务需要用户配置；本机Office分页等依赖可按需安装。

旧用户优先在设置检查更新并一键升级，保留账号、资料、对话、笔记、作品和原机DeepSeek配置。Windows凭据使用DPAPI，Mac使用钥匙串。原机升级保持原系统用户和安装路径；不要删除data或用sudo迁移钥匙串。

管理员管理成员/连接/更新；创作者研究和创作；业务员只读开放的政策、日报和成果。私有知识和对话按账号隔离。

具体步骤见《0.11.0使用指南》和《0.11.0发布与升级说明》。测试范围见本版验证记录；自动识别仍需核对原件，真实公众号连接和Mac原生会话能力按实际环境验收。
