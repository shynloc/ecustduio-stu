# 给安装用户本地 Agent 的提示词

请将下面提示词和已下载压缩包的完整路径一起交给本机 Agent。

```text
请帮助我安装或升级 EcuStudio 教创工作台 0.11.0。压缩包路径：[填写路径]。

先读取包中的先读我.html、0.11.0发布与升级说明.md和升级指南。识别 Windows x64 或 macOS 14+（Apple Silicon/Intel），检查原安装和服务。

有旧安装：优先让原管理员在设置的工作台更新里检查并一键升级。若需要离线入口，完整解压到原安装目录之外的新文件夹：Windows运行一键升级.cmd，Mac用原登录用户运行bash Upgrade.command。保持原安装路径、data、ecustudio.json及凭据位置；使用安装器内置备份和迁移，不能删库、重建账号或复制覆盖data。

无旧安装：Windows运行一键安装.cmd，Mac运行bash Install.command。首次联网自动安装运行环境与依赖，使用官方脚本。Mac不使用sudo，不更换钥匙串服务名，不用禁用系统安全保护来绕过问题。

服务启动后访问实际输出地址，检查健康状态、界面版本0.11.0和登录页面；旧用户用原账号登录。API Key和公众号密钥只让用户在设置页填写，不读取或打印已有明文。记录安装目录、数据目录、启动停止方式、备份位置和未通过的检查。确认账号、资料和配置保留后交付。
```
