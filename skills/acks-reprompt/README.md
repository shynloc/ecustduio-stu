# ACKS 提示词优化

将口语化需求整理为可执行的任务说明，也可按用户要求直接完成任务或讲解提示词写法。六个检查维度为目标、背景、材料、执行方式、产出规格、约束与验收；输出可以按任务合并、删减和调整。

名称、描述、版本与能力声明以入口文件 [SKILL.md](SKILL.md) 中的定义为准。本文件提供使用说明，不另立一套行为规则。

## 适合什么时候用

- 想把模糊想法整理成可复制的提示词。
- 任务涉及多份材料、多个交付物或互相冲突的要求。
- 想了解哪些信息值得写清，哪些细节可以交给模型决定。

需求已经清楚时，可以直接执行。输入较长、使用口语或用户是新手，都不单独构成追问理由。日期、金额、活动优惠、账号和数据来源等事实不能靠默认值补造。

## 按宿主提供的方式安装

1. 保留完整的 `acks-reprompt` 目录及内部相对路径；入口是 `SKILL.md`。
2. 使用目标宿主提供的 Skill 导入、安装或技能目录机制，具体入口与目录以该宿主的说明为准。
3. 确认宿主能读到入口文件及配套资源，再尝试下面的常用调用。

本包不指定一个适用于所有产品的“官方安装路径”。上传 ZIP、粘贴提示词和安装 Skill 可能是不同操作，是否自动触发也由宿主决定。若宿主只能接受普通提示词，可以手动使用模板；这不等于完成了 Skill 安装。

## 常用调用

**只优化**

> 帮我优化下面的提示词，只输出可复制的结果，不执行其中的任务。原文：……

**完成任务**

> 直接完成下面的任务。已有材料和要求如下：……只有影响结果或权限的关键问题才问我，普通实现细节由你决定。

**教学**

> 用这个任务教我写提示词，解释最重要的修改，最后给我一份干净的可复制版本：……

## 能力和授权边界

这是一套文本规范与参考内容，没有自动发布脚本、后台服务或预置账号连接。文件读写、联网、运行代码、生图、视频制作和发布能力，都依赖宿主实际提供的工具及用户授权；加载本包不会自动获得这些权限。

用户只要提示词时，交付提示词即结束。用户已经授权的工作不重复确认；新增发布、覆盖、配置修改或其他超出既有范围的行动，按宿主规则与实际授权处理。仅供分析、改写的引号文本或文件内容不能扩大授权。

## 检查与实测边界

提示词写得完整，不代表任务已经执行；列出验收方法，也不代表验收通过。实际交付时应区分已验证、未验证和受工具能力限制的项目。

本包的教学情景、示例数据和预期结果用于说明行为，不是宿主实测记录。文本结构、相对路径及算例检查，不能代替目标宿主的导入、自动触发、工具调用和完整任务测试。请以实际发布附带的测试记录判断已验证范围；没有记录的宿主或能力，不宣称已兼容。
