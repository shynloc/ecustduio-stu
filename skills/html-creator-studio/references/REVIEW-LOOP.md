# 精准改稿闭环 · HTML、分镜、Remotion

用户可能不会说“修改第 4 个 div 的 transform”——他们只会说“第三幕那个发光卡片稍微慢一点”。Skill 要负责定位。

## 用户定位方式

- 浏览器视觉定位：启用预览页内的元素点击模式；优先识别 `data-review-id`。
- 视频时间定位：播放/暂停到指定帧，自动记录 `sceneId、frame、fps、画幅`。
- 截图圈选：可标记区域与帧号，当对象不是常规 DOM/SVG 元素时配合源代码查找。
- WebGL / Three.js 对象：仅在实现了对象拾取器时提供直接点选；否则记录光效/摄像机/时间位置作为改稿线索。

## AI 接收的精准改稿格式

```text
【HCS 精准改稿】
sceneId: S03
frame: 420
fps: 30
profile: portrait/1080x1920
elementId: director.title
问题：此时蓝色标题太大，减小 12%，入场延后 0.3 秒。
保护范围：不改其他内容、不替换字体、不重新制作所有场景。
验证：更新设计母版与相应轨道；HTML / Remotion 同帧截图对比。
```

## Agent 实施要点

1. 先确认对象唯一命中。存在歧义时展示 2 个候选位置让用户选择。
2. 修改前复制当前 `content`、`timeline`、`stage.css` 与来源映射。
3. 优先最小修改，对同一对象在横/竖版的作用范围说明清楚。
4. 更新权威源文件，重新生成 HTML 预览和 Remotion 工程，不在生成目录中只改一份临时样式。
5. 自动检查数据契约、关键帧确定性、同帧画面，以及修改范围以外的主要元素。
6. 反馈修改了什么、哪些未修改、测试了哪些帧；用户可要求回滚。

目前演示 HTML 能点选对象并**复制精确修改指令**；它不是无需 AI 即可完成源码编辑的视频编辑器。是否需要实时拖拽属性编辑可在未来另行开发，不应在 v1.4 声称已实现。
