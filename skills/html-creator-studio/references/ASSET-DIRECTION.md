# Asset Direction｜原创视觉素材与版权/隐私计划（v1.6）

## 核心目标

用户反馈“网页平庸”时，根因往往不在 CSS，而在**缺少有语义的视觉主体**。根据每幕内容判断哪些信息应该由字体呈现、哪些由信息图承载、哪些需要真实摄影、原创 SVG、插画、局部 3D、材质图或音视频素材。不得在任何项目中用随机霓虹球体、假统计 HUD、无意义 3D 装饰填空。

## 每幕必须填写的资产说明

| 字段 | 说明 |
|---|---|
| scene_id / asset_id | 可稳定定位的场景/素材 ID；便于改稿与 Remotion 交接 |
| purpose | 这个素材传达什么事实、情绪或关系；如果不能回答就删除 |
| origin | `original-svg`、`original-css`、`provided-by-user`、`commissioned`、`licensed-stock`、`generated-local`、`generated-external`、`public-domain`、`unknown` |
| source_or_license | 来源/授权；第三方、用户提供、生成外部服务必须记录 |
| composition | 构图、镜头焦距/机位或 SVG 几何设计；横竖版分别说明 |
| materials & palette | 一致的素材语言（纸张、金属、胶片、布料、精线图）及色彩 |
| rights / privacy | 是否包含商标、人像、企业秘密；是否需要外传与批准 |
| fallback / alt_text | 低性能、关动效、丢失素材时仍可理解的替代内容 |
| editable | 可重新编辑 SVG/DOM/模型，还是预渲染位图，不可夸大能力 |

先产生 **asset-plan.json**，然后生成或导入素材。示例见 `templates/ASSET-PLAN.json`。可用 `python scripts/validate_asset_plan.py --plan asset-plan.json` 检查字段；正式发布运行 `--production`，含授权疑点的素材不得自动通过。

## 素材生产优先级（依内容选择，不是所有项目都这样排）

1. 真实的信息图、图表与关系图（优先 DOM/SVG 保留可读性与可编辑性）；
2. 原创参数化视觉 / SVG（构图与数据语义关联，清晰可复制、无需大资源）；
3. 用户自带/已授权品牌、产品、摄影素材；
4. 正当授权的商业/公有领域摄影与插画；
5. 经过用户允许的生成式插画、摄影、3D 模型，保留来源及使用条件。

图片、视频、外部字体、模型**不因网页可访问就自动有再利用许可**。禁止在未经授权情况下把用户附件发给第三方素材服务。不得伪造学校/公司 LOGO 或无来源数据图表。

## 让素材有“主题专属感”的四步

- 从文档中提取名词、动作、关系、张力、实物或专业图纸语言；
- 在 `design-direction.md` 写一个跨章节重复出现、可变化的专属视觉母题；
- 规定统一的材质、线重、阴影、视角与运动方式，禁止每一幕随机换风格；
- 先出主视觉 + 1 个高密度区真实截图；如果把标题换成其他主题仍毫无违和感，说明素材语义太泛。

## Video Ready 必须补的内容

- 横竖版独立视线焦点、人物/图表安全区、字幕空间；
- 资源独立命名和宽高、分辨率、色域、透明通道；
- 动画/粒子随机种子确定，按帧可寻址；不能复用无限 CSS 动画当视频帧状态；
- 每个素材明确允许音视频渲染和商业传播的授权范围；
- 遇到需要栅格化的 SVG、WebGL 或 3D 场景，记录保真度与可编辑性损失。

**交付前必须人工复核实际图片**。工具检查只能发现来源字段缺失、坏图片或布局异常，不能替人判断素材是否美观、文化恰当和具有商业权利。
