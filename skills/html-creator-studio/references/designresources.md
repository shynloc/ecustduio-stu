# HTML Creator Studio｜设计资源与创意选型手册 v1.6

> **必须按需读取**：适用于网页、演示、动态 HTML、Video Ready、Remotion 及 3D 视觉设计。此文件是创意选型知识库，不是把全部项目统一套用“流行趋势”的模板。
>
> **资料研究截点：2026-10-18**。2026 部分包含公开报告与真实案例；2027 属于尚未发生或未被充分验证的**前瞻假设**，不得称“全球公认的 2027 趋势”。外部风格名、作者、网址均为灵感参考，不能复制第三方代码、字体、品牌资产或作品设计。定期更新研究日期与来源。

## 0｜执行规则：设计前先取证，再呈现可看的真实样稿

1. **读取**：理解目标受众、材料语义、情绪、观看设备、品牌规范、是否需要旁白、是否要转成视频。禁止拿「最新潮流」替代用户明确品牌身份。
2. **检索**：优先查此文档的来源库；具备联网能力且已获允许时，每次新项目选择 2–5 个相关的**最近两年**的参考案例，记录 URL、日期、能借鉴的设计原则，不下载或复刻作品。若不能联网，使用本文件已注明日期的离线结论，并告知用户参考可能过时。公开网站搜索不得输入未脱敏的用户附件。
3. **发散**：至少构思 3 套**在布局、字体、构图、动效语言上都不同**的候选方案：稳健型、差异化型、实验型；不把“同一页换三种颜色”称三方案。用户已有明确路线时不强制重新提案。
4. **推荐**：每案注明「适合本资料的原因 / 画面长什么样 / 最能发挥作用的 1–2 个章节 / 性能与制作代价 / 不适用情况」；给明确推荐，而非把专业判断全部推给用户。
5. **艺术指导**：把选中的方案固化为 `design-direction.md`（见 `templates/DESIGN-DIRECTION.md`），为整站定义**至少三条独特的视觉签名规则**，以及明确的“不做清单”。创意方向先于框架选择。选择结果要反映到 `design-tokens.json`、场景分镜、布局 CSS、插画策略和运动曲线，而不是只写在报告里。
6. **对照审查**：完成首屏及 1 个内容密集场景后真实截图（桌面 + 手机，视频则横版 + 竖版），按本文件的反平庸量表复核；没达到标准就先重做，不要急着量产其余章节。
7. **不滥用**：趋势是启发不是标准。允许安静、专业、克制的作品；但不能用默认渐变背景 + 统一圆角卡片 + 同一淡入动效当作“精致设计”。不保证任何设计可获得设计奖项。

## 2｜创意方向库（可组合，不机械照搬）

每项的 `Web / Graphic / Illustration / Motion / Video` 五栏是**制作指引**，不是原文报告逐字结论。带 `2026` 的趋势关联在文末来源表可查。方向编号可写入任务卡 `design_archetype`。

### A01｜Editorial Monument｜大型编辑排版（E3；参考 Canva Opt-Out、Codrops Exat）
- **Web**：巨大但经过精细字距调整的核心标题，罕见比例的留白，细线与精细列网格，纵向文章与横向信息装置交替；不堆玻璃卡片。
- **Graphic**：一本封面或报纸头版的版式秩序；用一段醒目引语、对比层级，而不是十个信息块抢视觉中心。
- **Illustration**：抽象书页、裁切文字、几何纸张，必要时使用真实材料影像。
- **Motion**：行内揭示、字距合拢、页面排印重组；一幕最多一个主动作。
- **Video**：大标题必须有读屏停留时间；竖版重排为独立标题与正文节奏。
- **适合**：研究、企业策略、教育、报告；**慎用**：需要大量独立操作按钮的功能型工作台。
- **视觉签名示例**：衬线标题 + 无衬线注释；极窄左索引；突破网格的一张大图。

### A02｜Tactile Atelier｜触感工坊（E1 Canva Texture Check；E2 Codrops Stamp Library）
- **Web**：纸张、压印、粗纹、实体层次；采用可点击的物件式内容而非通用彩色卡片。
- **Graphic**：丝网印刷/纸张颗粒/浮雕阴影，素材少而真实。
- **Illustration**：纸雕、拓印、邮票、织物与手制拼贴；版权和素材来源清楚。
- **Motion**：材质翻转、微距细节、拖拽惯性；低性能端保留静态纹理。
- **Video**：建立材质灯光和相机运动的可复现关键帧。
- **适合**：博物馆、品牌工艺、文化教育；**慎用**：要在高密度数据表中保持无装饰的场景。

### A03｜Kinetic Type Laboratory｜字体动态实验室（E2 Exat/Figma Motion）
- **Web**：文字作为可操作的几何对象，用节奏、字宽变化、断裂和再组合演绎概念。
- **Graphic**：瑞士式不对称网格 + 具有识别度的字形安排；字体需具备合法使用许可及中文字符覆盖。
- **Illustration**：用字形本身生成几何插画，少量清晰图标。
- **Motion**：字形顺序、行列布局、流向变化，使用逐帧可寻址控制而非无法暂停的循环。
- **Video**：关键语句不要过快消失；按 16:9 / 9:16 分别排版。
- **适合**：产品发布、品牌、创意科普；**慎用**：需要长篇静态阅读的正文区域。

### A04｜Cinematic Data Architecture｜电影化信息建筑（E2 Codrops Spark；E3 综合）
- **Web**：把真实时序、关系、比较结构变成空间层级；深色可用，但不是强制暗色蓝光。
- **Graphic**：像建筑图纸般的有序标注，大尺度数字，独立图形代替重复卡片。
- **Illustration**：抽象建筑与高精度数据装置，严禁用无来源装饰数字。
- **Motion**：镜头推进、序列揭示、线条构建、从概览到细节；穿插静态阅读章节。
- **Video**：共享场景/元素 ID 和可寻址动画帧；复杂 WebGL 使用帧驱动或预烘焙并说明差异。
- **适合**：科技原理、系统说明、复杂政策结构、产业关系；**慎用**：纯情感散文或极短文本。

### A05｜Imperfect Zine｜刊物拼贴（E1 Canva Zinegeist / Notes App Chic）
- **Web**：杂志手帖、剪贴图层、注释、手写辅助；即使不对称，也有稳定阅读顺序。
- **Graphic**：扫描边缘、复印颗粒、彩纸块、标记笔与精确的大字对比。
- **Illustration**：手绘线条、Riso 网点、不规则剪纸；注意信息真实性。
- **Motion**：纸片滑入、翻页、遮罩、影像切换；避免所有元素随机漂浮。
- **Video**：转场使用纸片/杂志镜头语言，保障字幕可读。
- **适合**：文化、艺术、年轻人传播、活动企划；**慎用**：法律告知、严格财务报表。

### A06｜Quiet Editorial Premium｜克制高端编辑（E1 Canva Opt-Out；E3 综合）
- **Web**：奶油白/暖灰/墨黑，精确排版、微妙分割线、优雅留白与材质克制。
- **Graphic**：极少而有质量的配色，摄影具有主导地位；避免“卡片化 SaaS”刻板印象。
- **Illustration**：植物轮廓、手绘版画、微几何，不让插图干扰阅读。
- **Motion**：慢但不拖沓的细节反馈；主要使用进入、遮罩和微尺度位移。
- **Video**：可以更静，靠摄影剪辑与构图变化建立高级感。
- **适合**：精品产品、人物故事、教育内容与专业品牌。

### A07｜Generative Geometry｜生成几何（E2 Figma 2026 code/shader；E3 综合）
- **Web**：参数化形态围绕主题数据生成；让公式和可视化表达一一对应。
- **Graphic**：海报级几何形态、可重复生成但可控的形状与结构。
- **Illustration**：程序生成网点、线束、拓扑等；每种形态要有内容理由。
- **Motion**：确定性种子 + 帧输入；禁用 uncontrolled random/random-on-render。
- **Video**：同帧同图；16:9/9:16 重新设定摄像机与安全区。
- **适合**：数学、工程、创意编程、音乐与数据；**慎用**：缺少技术意义的泛科技装饰。

### A08｜Surreal Editorial / Reality Warp｜超现实编辑图景（E1 Canva Reality Warp；Adobe Surreal Silliness）
- **Web**：真实摄影与少量不合常理的空间物体形成张力；中心信息保持稳定。
- **Graphic**：超现实尺度、拼接透视、非日常颜色，但事实和艺术表达分离。
- **Illustration**：手绘 + 合成摄影、错视与戏剧性物理规则。
- **Motion**：局部扭曲、镜头错位、物体转义；屏幕阅读区不能持续变形。
- **Video**：镜头化而不是持续抽象循环。
- **适合**：概念产品、创新与幻想题材；**慎用**：高风险政策与严谨结论。

### A09｜Cultural Archive / Local Flavor｜地域文化档案（E1 Adobe Local Flavors）
- **Web**：以文化真实素材为主角，语言、版式、建筑与当地视觉传统相结合。
- **Graphic**：具有出处的纹样、印章、碑刻、地方色谱；谨慎处理文化挪用。
- **Illustration**：现场物件、手工图案、文献图像和原创重绘。
- **Motion**：档案展开、章节入画、镜头游历；不套用“古风飘雪粒子”。
- **Video**：旁白尊重历史/文化事实，出处放于片尾/说明，不打断观众叙事。
- **适合**：地方文化、博物馆、文学历史。

### A10｜Narrative Mini-Museum｜叙事式微展馆（E2 Codrops Spark/Stamp）
- **Web**：几幕微型展览，每幕空间结构不同；一套主视觉隐喻贯穿。
- **Graphic**：展品铭牌、收藏编号、摄影展墙、静态阅读台。
- **Illustration**：根据内容制作的原创装置、分解图或场景，不使用泛用抽象球体。
- **Motion**：滚动/手势驱动镜头转换，用户可自由跳章，有减少动画替代。
- **Video**：场景与镜头轨迹可转换为固定时间线；鼠标选择转化为事先确认的剧本事件。
- **适合**：课程、历史、品牌叙事。

### A11｜Soft Playful 3D｜轻量趣味立体（E1 Adobe Surreal/Canva Prompt Playground）
- **Web**：少数角色或几何器物，提供可理解的空间手势；不是每张卡片都添加 3D 旋转。
- **Graphic**：柔软材质、鲜明主角、克制背景。
- **Illustration**：绒毛、陶泥、软塑与夸张简单形态；由内容导出主角。
- **Motion**：表现态度和反馈，局部动画高质量优先于大面积乱动。
- **Video**：模型与相机动作按帧驱动，适配字幕与 UI 遮罩区。
- **适合**：儿童科普、教育、轻娱乐。

### A12｜Info-Utility Precision｜信息工具主义（E3 综合；参考 Canva Opt-Out）
- **Web**：强导航、清晰表格、交叉筛选和双栏对比；用高质量数据字体与严密栅格形成美感。
- **Graphic**：数据图表和章节索引优先；单色加一个语义强调色。
- **Illustration**：专业示意图、流程框架或无插画。
- **Motion**：只强调状态和因果；图表过渡必须数据准确。
- **Video**：将复杂图表拆成按节奏出现的可读层，不能直接缩放整个仪表板。
- **适合**：医学教育、财务解释、专业训练、决策资料。

## 3｜内容类型 → 推荐初始组合（不代替用户决定）

| 文档与用途 | 优先提出 | 应避免 |
|---|---|---|
| 科普/教育政策/严肃报告 | A01 / A12 / A04 | 过度超现实造成误读 |
| 品牌/产品发布 | A06 / A03 / A08 | 通用 AI 紫蓝渐变、假奢侈感 |
| 文化/艺术/档案 | A09 / A02 / A10 | 随机拿复古纹理做噪声 |
| 创新科技与 Agent 技术 | A07 / A04 / A03 | 无关粒子、虚构数据 HUD |
| 年轻传播/活动 | A05 / A11 / A08 | 内容结构全被装饰遮住 |
| 数据分析/商业提案 | A12 / A01 / A04 | 卡片拥挤、图表无单位 |
| 视频脚本与知识解说 | A01 / A10 / A06 | 直接把大段文案塞入每帧 |

**跨类借鉴**：网页从平面设计获取视觉秩序，从插画获取独特图形语言，从电影与动效获取节奏，从交互设计获取反馈；不能因为“科技”主题就必选深蓝和霓虹。

## 4｜2027 前瞻假设（F1；仅供有意识实验）

这些不是已发生事实，也不应被写入对外宣传为“国际公认趋势”。在 2026 信号上可试验：
1. **有意图的自适应叙事**：相同内容面向听讲/阅读/视频时呈现不同信息密度，必须尊重用户控制与隐私。
2. **可寻址动态设计系统**：动画从网页视觉点缀转为与设计 Token 一样可版本化的资产（依据 Figma 2026 Motion 的方向延伸）。
3. **人类质感与计算图形混搭**：真材质、手工痕迹与生成图形的混合，不盲目滤镜化。
4. **无障碍驱动的高级动效**：视觉表达力与 `prefers-reduced-motion` 同时成为设计目标。
5. **稳定艺术指导压过套模板速度**：用户拥有视觉母版，网页/视频复用而不是 AI 每次重画。

每一条均为本 Skill 的推测性创作方向，需定期复核，缺少证据时不得标记为趋势共识。

## 5｜视觉设计自检：不平庸，也不牺牲传达

在发布前审查：

| 检验项 | 权重 | 正确的判断问题 |
|---|---:|---|
| 内容与隐喻绑定 | 12 | 关键视觉是不是只能用于这个主题？ |
| 版式辨识度 | 12 | 去掉配色以后，布局仍有原创性吗？ |
| 字体与中文排版 | 12 | 标题/正文/注释有清楚层级，中文换行自然吗？ |
| 结构与信息可读性 | 12 | 不看动效也能理解关键事实吗？ |
| 图像/插画一贯性 | 10 | 是否是同一视觉语言而非随机素材拼贴？ |
| 动画意图 | 10 | 每个动作为何存在，能否对应叙事或反馈？ |
| 场景与情绪节奏 | 10 | 是否有高潮、停顿、阅读区，避免平均用力？ |
| 响应式/视频构图 | 8 | 9:16 和手机是否重排，而非裁切文字？ |
| 交互反馈与动效安全 | 7 | 易操作、可跳过、支持 reduce motion？ |
| 视觉实现细节 | 7 | 字体、间距、阴影、线宽、过渡、材质是否打磨？ |

总分 100。内部建议：**≥82 且「结构与信息可读性」≥9/12** 才进入全站量产；分数是团队自评工具，不是客观艺术排名。首屏及中间高密度章节要有真实截图，不能仅由代码描述给高分。评分不足时从构图、字体与独特的内容装置重构，不能只叠加 Shader。

**模板化警报（出现 3 项以上先重做视觉方向）**：紫蓝大面积渐变；每幕相同的四张浮卡；全部使用相同的入场淡入；无意义旋转球体；玻璃拟态无材质逻辑；假统计数据；每场景居中的同等字号标题；Web 上交互不可操作；视频纵版仅裁切；字体全用系统默认且从未调字距/行高。

**必须提供的设计交付证据**：`design-direction.md`、3 套方向摘要、选择理由、至少 3 条视觉签名规则、设计 Token 片段、关键视觉截图、低性能/无动效回退说明。
