# Visual Pitch｜先让用户看到方案，再全面开发（v1.6）

## 启动条件与交互边界

设计入口 **必须阅读** `references/designresources.md`；用户没有锁定视觉路线时，默认拿出 2–3 套**可观看的真实 HTML 首屏 + 高信息密度内页试样**。不允许仅提供风格名称、调色板或图片查询结果便称为视觉提案。用户已有明确品牌指南时，可只做 1–2 个针对性样稿；用户明确要求跳过提案，记录委托范围，可先做一个原型，仍需实际截图复核。Quick 模式减少沟通轮数，不能跳过观众成品文案审批。

**两个独立确认：** ① 用户选择视觉方向或授权 AI 决定；② 用户批准准确的观众文案（标题、正文、数据标签、旁白、字幕）。第一项不构成第二项，亦不构成公开部署授权。

## 最小提交物

- `visual-pitch/brief.json`：本项目主题、经用户提供或确认的事实/占位语、首屏候选文案、两个以上有意义的章节摘要；**未批准的文字必须在预览上清晰标识“草稿”**，不得宣称正式成品。
- `visual-pitch/index.html`：并排候选/可切换观看的实际 HTML 原型，至少可查看桌面与手机（支持截图），不是静态陈述。
- `visual-pitch/{direction}.html`：不同风格实际渲染，推荐一个。
- `visual-pitch/pitch-manifest.json`：结构、字体、色彩、插画、动效、性能、可读性、适用性及选型理由。提交前手工完善“为什么与该文档有关”。
- `visual-pitch/SCREENSHOT-REVIEW.md`：真实首屏与一个内容密集章节的桌面/手机截图、问题与修复。
- `visual-pitch/DECISION.md`：用户反馈、所选方案与版本，或“用户明确委托 AI 选择”的文字依据。**无用户决定不可写已批准**。

### 三套方案的差异要求

至少在以下 4 个维度中具备 3 个实质差异：
1. 版式构图：纵向/非对称/分屏/沉浸空间/实验网格；
2. 字体语言：文字大小、粗细、衬线/无衬线、阅读尺度、排版节奏；
3. 素材/主体：原创插画、信息结构图、摄影、几何装置、文化元素；
4. 动效与交互：静态排印、文本动效、视差/滚动叙事、逐帧场景等。

**只换颜色不算新方案**。禁止从第三方作品复制代码、未授权字体、LOGO 或整套版式。

## 可运行的提案参考生成器

`python scripts/build_visual_pitch.py --brief visual-pitch/brief.json --out visual-pitch/rendered`

- 参考简报结构见 `templates/VISUAL-PITCH-BRIEF.json` 与 `examples/visual-pitch-demo/pitch-brief.json`。
- 生成器可离线输出 3 个独立 HTML、一份可切换/手机预览的 `index.html` 和 `pitch-manifest.json`。所有样稿使用系统字体及内联原创 CSS/SVG，不向第三方上传资料。
- **重要：** 生成器内的三套风格只是一个 *起点*，不是每个项目强制套这三套。AI 必须基于源材料与 12 条风格谱系重新构思布局与内容专属视觉主体；当标准生成器无法表现项目独特性时，应直接编写本项目专属样稿，不得偷懒套默认模板。
- 使用真实素材需要提前经过用户隐私与素材使用授权；有疑义时仅在本地使用脱敏占位元素，禁止上传外部图像搜索/生成服务。
- `index.html` 的“复制选择说明”供用户带回对话，不是对 HTML 文件进行自主确认或修改持久存储。**样稿只是可见视觉候选，不是可复用的正式页面生产模板。**

## 呈现给用户的固定格式

> 我做了 X 套可以实际打开的提案。A 采用……，适合……；B 采用……，适合……；C 采用……，适合……。推荐 B，因为文档中……。请你看实际页面决定 A/B/C 或指出具体修改。文案仍是草稿，选择外观不等于批准内容。

每个方案至少有一个大视觉页面、一块内容密集区。视频任务增加横/竖两个构图及三个关键帧（开场/中段/结束）预览，未必要求整段渲染。若用户已经明确选定视觉语言，仍须呈现一个已指定风格的真实可看样稿，再进入长篇开发。

## 质量门槛与失败回路

生成后运行 `visual_qa.py` 按至少桌面 1440×900、手机 390×844 检查；条件允许另查 1920×1080、1080×1920 视频关键帧。必须**亲眼检查截图**，尤其是字体、内容密度与主题独特性。发现普通 SaaS 玻璃卡片堆砌、重复淡入、无关霓虹数字、中文断行等问题时，先重做样稿，再全站量产。不能拿工具“无 JS 报错”当设计品质证明。
