2. 分开展示 `OBSERVED`（确实看见/听到）、`INFERRED`（推测）、`CONFIRMED`（我具体批准）的审美线索，明确局部好恶、可信证据 ID 与不确定处；不要推断我的人格、财富、敏感属性。用 2–3 个具体审美假设向我确认。

7. 做真实桌面/移动端截图、键盘和交互验收；无法启动浏览器时报告 `BLOCKED` 而非 `PASS`。离线四种简历布局仅供技术参考，最终视觉仍应为这次真实材料重新设计。

4. 生成真实 asset-plan.json：说明每幕素材的语义、原创/版权来源、授权状态、视频改编可用性和低性能替代；运行 validate_asset_plan.py。不要以没有内容根据的装饰球体充当主视觉。

6. 获得文案明确批准后，再执行 HTML 生产、逐帧 Video Ready 与 Remotion 适配；关键视觉和动画具有稳定 ID，保留精准改稿。若采用无声视频，明确标记，别宣称完成旁白。

8. 在具备 npm 的环境运行 Remotion CLI compositions/still/render；检查真实 MP4 分辨率、总帧数和主要关键帧。如果官方 CLI 不可用，保持未验证并交源码、命令、失败日志；不要混同 Chromium+FFmpeg 与 Remotion 的实测。
